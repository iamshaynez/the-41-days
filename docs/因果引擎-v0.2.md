## 8. 对子因果弧线（迁移后全量）

人物设计-v0.2 §5 的"有戏的对子"全部弧线化，阶段迁移由 CY-11 信任弧驱动：

| 对子 | 弧线与关键迁移 |
|---|---|
| 薄姑 × 大柯 | 共事 → **门版对峙**（触发点）→ 和解（修窗→"数清楚，量平"→过命）/ 恶化（冷战→一人离队） |
| 文简 × 石大 | 共事 → 深夜对话"你做的是对的" → 过命（两个替别人算账的人互认） |
| 素徽 × 阿走 | 共事 → 渡口"她数他走" → 过命（此后他守夜她陪坐） |
| 辛夷 × 石大 | 共事 → "账都记在自己头上" → 托付（重伤时只许对方处理自己） |
| 江鳅 × 薄姑 | 互不信任（开局）→ 共事 → "你封的检里有我劫的船" → 托付（物流×检的黑市改革线） |
| 白简 × 逄灶 | 共事 → 老纪对峙同框 → 过命（纸×火，还师双子） |
| 文简 × 阿禾 | 教学 → "记在心里，心不死" → 类父子（账本传承线的数值地基） |
| 老甑 × 大柯 | 共事 → "都是伺候人的手艺" → 敬重（互相优先修/先盛饭） |
| 阿禾 × 逄灶 | 教学（烽燧传承）→ "火会熄吗？会，所以有人看着" → 过命（还师线的第三双手） |
| 阿禾 × 任何人 | 教学镜像：他学谁就像谁，目击账 ×1.5 加权 |

- **CY-50** 对子弧线迁移事件是 A 层手作卡，不进随机堆。
- **CY-51** 玩家不是对子弧线的旁观者：你对其中一人的行为会被另一人
  按 CY-03 加权读取——拆散或成全他们，都是你的因果。

## 9. 回放示例：一局 25 天长出来的因果树（荆州版）

> 队伍：文简、辛夷、石大、阿禾。种子节选，括号内为引擎内部状态。

**D3** 逃兵敲门，玩家让他去别处（refuse_help, w=2, 见证：全员）。
辛夷读数 -2×1.5；文简 -1；阿禾目击账 +1（"大人会关门的"）。
（玩家不知道：这扇门是铁证 #039 离他最近的一次。）
**D4 晨**：辛夷自主行为——她把自己的熟食省下半份追了出去（她疲劳+1，
晨报一句话："辛夷的黑眼圈重了一层。"玩家不知道发生了什么）。
**D5** 寒流，玩家下令烧简册（burn_book, w=1）。文简 -2，触发 P-03 抗议：
"烧一枚是一枚。你们烧的不是竹，是有人写过字的时间。"
玩家强制执行。文简把你从生日账里划掉（自主行为，无演出——
你只会在很久以后的生日那天发现没有牍削的小马）。
**D8** 阿禾偷喝浊酒事件，玩家选"坐下来聊"（teach, w=1, target=阿禾）。
石大见证 +1（×1.5 关系加成：阿禾是他教破门的学生）。
文简没划掉阿禾的名字（心结弧：名单厚薄 +1）。
**D12** 袭击夜。守夜的石大连续第三夜值班（guard_night 累积 ×3，无人替换）。
他力竭，"没听见"——失窃 25%。晨报只写"夜里来的手很轻"。
玩家此时有两个选择，每个都在记账。
**D14** 玩家开始轮换守夜并给石大道歉式地多分一脯（feed+keep_promise 链）。
石大的「没人被留下」弧正向累积——他什么都没说，
但 CY-41：这笔账 D19 才发芽。
**D16** 湘关米事件市语，全员 -3。辛夷心结弧"被触碰"（小满）。
**D19** 微事件：石大夜里修好了辛夷坏掉的药囊扣（人物间自主行为，
不经玩家——石大的账：辛夷 D4 追出去时，他在门后看见了）。
辛夷 × 石大 信任弧 → 共事+。
**D21** 驿亭死信：文简女儿的信（人物线）。玩家抉择：给他看。
（若不给：文简心结弧"发作"→ 他开始把账目交给阿禾——他准备自己去公安。
若给：文简「名单」弧全开，寻女主线激活。）
**D25** 取药夜：文简高热，需有人穿水门渡。引擎按因果账排志愿顺序：
石大第一（「没人被留下」弧满、"他把命交给你"阈值已过）、
辛夷第二（她的心结弧要求她必须去）、阿禾想报名（被石大按住）。
阿走不在此局——**若他在且与素徽同局，"她数他走"会是另一棵树**。

这棵树里，玩家直接种的只有 5 条；人物之间自己长出 4 条；
而 D25 的志愿顺序——整局最有分量的一刻——**没有一个随机数**。
