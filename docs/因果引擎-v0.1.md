## 1. 因果条目（CY）

现有事迹账本（GDD §10.2）记录"你做了什么"，是**清单**。
因果引擎记录"谁在场、谁在乎、多重"，是**账**。

- **CY-01** 每个有叙事重量的行动/事件生成一条因果条目：

```
causal_entry {
  id, day, phase,
  actor:      charId | "player" | "world",
  verb:       枚举（见 CY-05），
  target:     charId | npcId | location | faction | null,
  witnesses:  [charId],          // 在场且能感知的人
  weight:     0.1 ~ 10,          // 重量，见 CY-04
  decay:      "7d" | "never",    // 琐事衰减，重事永久
  tags:       [care|truth|food|threshold|violence|promise|...]
}
```

- **CY-02** **情绪读数不存进条目**。条目只存事实；每个见证者按自己的
  伦理向量（M-10）× 与 target 的关系（CY-03）**现场解算**读数。
  同一行为，十年后换新角色旁观，读数不同——账是活的。
- **CY-03 关系加权（人物间因果的核心机制）**：
  `读数(见证者w, 事件e) = 基础读数(w.伦理向量, e) × (1 + 关系加成(w, e.target))`。
  你饿尤拉三天——全队都看在眼里，但**教过尤拉解剖的布罗**读数是别人的两倍。
  玩家对 C 做的事，会被 A 按 A 和 C 的账来读。这就是"人物之间的因果"。
- **CY-04 重量档**：琐事 0.1~0.5（让烟、留半块糖）/ 常事 1~3（拒助、烧书、公平分食）/
  重事 4~7（救命、见死不救、背叛承诺）/ 灭失 8~10（杀无辜、抛下濒死队友）。
  灭失级一条顶一百条，不设钝化——M-03 的麻木机制只管心情，**不管因果**。
- **CY-05 动词枚举**（节选，全表入 content）：
  `feed / deny_food / heal / refuse_help / burn_book / steal_civ / kill_civ / kill_armed /
  spare / rescue / abandon / teach / keep_promise / break_promise / trade_evidence /
  listen_radio / play_music / guard_night / volunteer / sacrifice / witness_death ...`
  新动词 = 新枚举值，不改引擎。
- **CY-06 见证规则**：同屋、同场景、或事后被告知（对话可传递条目副本，
  标 `hearsay: true`，权重 ×0.6——听来的事打折扣，但会传播）。
  **人物不在场就不知道**：隐私是真的可以保住的，秘密是真的可以烂掉的。

## 2. 关系加权：同一件事，每个人读出的不一样

示例：玩家下令"烧书取暖"（verb=burn_book, weight=1, witnesses=全员）。

| 见证者 | 基础读数 | 关系加权 | 实际 | 为什么 |
|---|---|---|---|---|
| 安东 | -2（烧书=烧他坚持的东西，P-03） | ×1 | -2 | 触发抗议事件 |
| 薇拉 | -1（毁纸=毁证据的可能） | ×1 | -1 | 记在私人账本 |
| 尤拉 | 0（不懂） | ×1 | 0 | 但进**目击账**（§4.7）：他学会了"冷的时候可以烧纸" |
| 埃米尔 | -0.5（书不能当柴，饭可以多做） | ×1 | -0.5 | 当晚多烧一把柴的微事件 |

一周后你送伤员去医院（verb=heal, weight=3）：安东读数 +2×1.0；
但**安东的女儿若在失踪名单上**（target=他的关系人），玛尔塔读数 +2×1.5——
她救了一辈子人，看见别人肯救，比谁都疼。

## 3. 累积与弧线（ARC）

- **CY-10** 单条因果是噪音，**同向累积**才是信号。引擎为每对关系、每个人物
  维护"弧线状态机"，由累积条目数 + 关键事件推进。
- **CY-11 三条轴**：

| 轴 | 挂在 | 阶段 | 推进依据 |
|---|---|---|---|
| **信任弧** | 每对关系（玩家↔角色、角色↔角色） | 陌生→共事→托付→过命 | 同向条目累积 + 关键事件（共战、救命、守诺） |
| **心结弧** | 每名角色自身 | 潜伏→被触碰→发作→和解/恶化 | 其心结相关条目（安东的"女儿"、布罗的"被困者"） |
| **敬重弧** | 角色→玩家 | 观察→认可/失望→追随/离心 | 玩家行为的道德模式（按该角色伦理向量解算） |

- **CY-12** 推进规则：阶段迁移需 `同向 weight 累计 ≥ 阈值` 且 `≥1 个标志性事件`。
  只刷小事无法推进（100 块糖买不来"过命"），但没有小事铺垫，标志事件不发生。
- **CY-13** 倒退同样累积：信任弧有反向条目区，反向累积超正向一半即降级，
  且**降级事件必有演出**（一顿没说话的晚饭、一次没叫你的守夜）。
- **CY-14 弧线非线性**："过命"之后仍有账——背叛一个过命的人，
  读数 ×3（期望越高，账越重）。

## 4. 人物间因果：见证 → 评价 → 弧线 → 自主行为

这是本引擎的灵魂。四步闭环：

- **CY-20 见证**：条目按 CY-06 落到每个在场角色头上。
- **CY-21 评价**：按 CY-02/03 现场解算读数，写入该角色的关系账。
- **CY-22 弧线**：角色之间的关系弧（不只对玩家）按 CY-11 推进——
  薇拉看着格里高利三天把省下的木料先修了寡妇的门，她对"征用"两个字的恨
  第一次有了具体的反例；这段关系的演化**不经过玩家**。
- **CY-23 自主行为**：弧线过阈值后，角色会**自发行动**，消耗自己的资源，
  晨报或微事件里浮现（玩家只看得见结果）：
  - 玛尔塔夜里自己起来，照顾你拒绝收留的逃兵（她疲劳 +1，你次日才发现）。
  - 达尼洛把你拒之门外的孩子领到沟鼠那儿（他私货 -1，什么都不说）。
  - 安东把你的名字从生日账里划掉（你再也收不到折纸）。
  - 薇拉把你每次来路不明的交易记进私人账本（灯塔/调查线的伏笔）。
  - 布罗连续三夜替你守你排给他的班（直到他力竭倒下你才明白他在还什么）。
- **CY-24 对玩家的反哺**：人物间弧线改变他们**对玩家行为的读数**
  （CY-03 的关系加成），并解锁对子事件（§8）。
  闭环完成：玩家 → 人物 → 人物 → 玩家。

## 5. 兑现点：因果在哪里爆炸

- **CY-30 对话**：演员 LLM 的上下文注入"该角色与玩家的弧线阶段 + 最强 3 条因果条目摘要"
  ——他们说话带账，但**不念账**（CY-40）。
- **CY-31 事件**：弧线过阈值触发专属事件（对峙、托付、和解、离心）。
  事件池因此从"随机牌堆"长出"应然牌堆"——这一局的事件有一大半是**你自己种出来的**。
- **CY-32 危机兑现**（最锋利的兑现，全部走内核检定，数值由弧线阶段修正）：
  - 袭击夜：守夜人若被玩家长期克扣（deny_food 累积）→"没听见"概率上升；
    被厚待者 → 提前半拍叫醒你。
  - 崩溃链（M-14）：安抚效果 = 基础值 × 与该角色的信任弧系数，
    陌生人的话 +1，过命的人一句话能拉回崩溃边缘。
  - 志愿时刻（狙击路口取药、火场救人）：**志愿顺序由因果账决定**，不随机。
  - 入桌提议（GDD §12.3）：法比安开价时，每名队友按与玩家的敬重弧表态——
    有人会替你拒绝，有人会替你收拾行李。
- **CY-33 后日谈**：EPI-01 未来种子自动引用"该角色最强的 3 条因果链"——
  他成为谁，引用的是你做的事，不是随机模板。
- **CY-34 档案馆**：灭失级条目必入"这座城记得"；人物间弧线的终态写入
  人物真相词条（"薇拉和格里高利后来怎么样了"，跨周目可考）。
- **CY-35 正典防火墙**：因果引擎只组织**已发生的事实**，永不改写正典（RND-08）；
  它是确定性的——同种子同输入，因果树完全相同（RND-06）。

## 6. 不透明原则：因果不报账

- **CY-40 没有 karma UI**。不设善恶条、不显示关系数值。
  玩家只能从人的行为里读账：他喊你名字的语气、他留没留你那半勺饭。
- **CY-41 延迟兑现**：小额累积 3~7 天后才以微事件浮现；大额只在危机点（CY-32）。
  即时反馈是交易，延迟反馈才是因果。
- **CY-42 部分可见**：透明模式（RND-07）可见弧线阶段名（"共事"/"离心"），
  但永远不显示"还差几条升级"。
- **CY-43 衰减与遗忘**：琐事条目 7 天衰减（人活着要往前看）；
  重事以上永久。尤拉的目击账例外：他**什么都记得，永不衰减**（§4.7 人物设定）。

## 8. 对子因果弧线（升级 REL）

人物设计 §5 的"有戏的对子"全部弧线化，阶段迁移由 CY-11 信任弧驱动：

| 对子 | 弧线与关键迁移 |
|---|---|
| 薇拉 × 格里高利 | 共事 → **门板对峙**（触发点）→ 和解（修窗→"数清楚，量平"→过命）/ 恶化（冷战→一人离队） |
| 安东 × 布罗 | 共事 → 深夜对话"你做的是对的" → 过命（两个替别人算账的人互认） |
| 佐菲亚 × 帕维尔 | 共事 → 路口"她数他走" → 过命（此后他守夜她陪坐） |
| 玛尔塔 × 布罗 | 共事 → "账都记在自己头上" → 托付（重伤时只许对方处理自己） |
| 达尼洛 × 薇拉 | 互不信任（开局）→ 共事 → "你盖的章里有我劫的车" → 托付（物流×章的黑市改革线） |
| 卡佳 × 阿列克谢 | 共事 → 维克托对峙同框 → 过命（内容×管道，灯塔双子） |
| 安东 × 尤拉 | 教学 → "记在心里，心不死" → 类父子（账本传承线的数值地基） |
| 埃米尔 × 格里高利 | 共事 → "都是伺候人的手艺" → 敬重（互相优先修/先盛饭） |
| 尤拉 × 任何人 | 教学镜像：他学谁就像谁，目击账 ×1.5 加权 |

- **CY-50** 对子弧线迁移事件是 A 层手作卡（GE-02 天然满足），不进随机堆。
- **CY-51** 玩家不是对子弧线的旁观者：你对其中一人的行为会被另一人
  按 CY-03 加权读取——拆散或成全他们，都是你的因果。

## 9. 回放示例：一局 25 天长出来的因果树

> 队伍：安东、玛尔塔、布罗、尤拉。种子节选，括号内为引擎内部状态。

**D3** 逃兵敲门，玩家让他去别处（refuse_help, w=2, 见证：全员）。
玛尔塔读数 -2×1.5；安东 -1；尤拉目击账 +1（"大人会关门的"）。
**D4 晨**：玛尔塔自主行为——她把自己的熟食省下半份追了出去（她疲劳+1，
晨报一句话："玛尔塔的黑眼圈重了一层。"玩家不知道发生了什么）。
**D5** 寒流，玩家下令烧书（burn_book, w=1）。安东 -2，触发 P-03 抗议：
"烧一张是一张。你们烧的不是纸，是有人写过字的时间。"
玩家强制执行。安东把你从生日账里划掉（自主行为，无演出——
你只会在很久以后的生日那天发现没有折纸）。
**D8** 尤拉偷抽烟事件，玩家选"坐下来聊"（teach, w=1, target=尤拉）。
布罗见证 +1（×1.5 关系加成：尤拉是他教破门的学生）。
安东没划掉尤拉的名字（心结弧：名单厚薄 +1）。
**D12** 袭击夜。守夜的布罗连续第三夜值班（guard_night 累积 ×3，无人替换）。
他力竭，"没听见"——失窃 25%。晨报只写"夜里来的手很轻"。
玩家此时有两个选择，每个都在记账。
**D14** 玩家开始轮换守夜并给布罗道歉式地多分一罐（feed+keep_promise 链）。
布罗的「没人被留下」弧正向累积——他什么都没说，
但 CY-41：这笔账 D19 才发芽。
**D16** 圣米尔桥事件广播，全员 -4。玛尔塔心结弧"被触碰"（伊利亚）。
**D19** 微事件：布罗夜里修好了玛尔塔坏掉的听诊器扣（人物间自主行为，
不经玩家——布罗的账：玛尔塔 D4 追出去时，他在门后看见了）。
玛尔塔 × 布罗 信任弧 → 共事+。
**D21** 邮局死信：安东女儿的信（人物线）。玩家抉择：给他看。
（若不给：安东心结弧"发作"→ 他开始把账目交给尤拉——他准备自己去下城。
若给：安东「名单」弧全开，寻女主线激活。）
**D25** 取药夜：安东高烧，需有人穿狙击路口。引擎按因果账排志愿顺序：
布罗第一（「没人被留下」弧满、"他把命交给你"阈值已过）、

## 11. 测试与平衡

- **单元**：entry → 读数解算表（伦理向量 × 关系加成全组合）；弧线迁移阈值表。
- **场景**：连续拒助 ×3 → 玛尔塔自主救治事件必触发；烧书后安东生日账划名断言；
  对子弧线"薇拉×格里高利"全阶段走查（对峙→两种终态）。
- **属性**：因果账守恒——任意时点所有弧线状态 = entries 序列 fold（复用现有 fold 测试基建）。
- **隐私**：hearsay 传播的折扣与范围断言（不在场者读数恒 0）。
- **sim**：机器人策略接因果引擎，KPI 门禁不变（因果改人事，不改经济守恒）；
  新增 KPI：单局弧线迁移事件 2~6 次（少了人物死，多了玩家被账淹没）。
- **平衡护栏**：CY-23 自主行为的资源消耗设单人日上限（防玛尔塔把自己累死的极端链）。
