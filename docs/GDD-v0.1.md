## 0. 一句话概述

你操纵一队被困在围城中的平民，白天经营避难所，夜间冒险外出搜刮，
用自然语言告诉游戏"你想怎么做"——LLM 负责当裁判和叙事者，
一个不掺假的数值内核负责让你饿、让你冷、让你付出代价。
而在一次次的死亡与重来之间，你会发现这场战争本身，就是假的。

**副标题口号**：*战争不是被打输的，是被续约的。*

## 1. 设计支柱

所有后续设计决策都对照这五条：

1. **自由但有边界**：玩家可以说任何话、做任何事，但世界按硬规则回应。
   LLM 是翻译官和叙事者，**不是**上帝。数值内核是唯一的上帝。
2. **挫折是内容，不是惩罚**：饥饿、疾病、抢劫、崩溃都服务于体验。
   玩家死亡是常态，死亡也推进认知（见档案馆）。
3. **道德有重量**：偷窃、杀戮、见死不救都有真实代价；
   但游戏不审判玩家，只呈现后果。原作式的克制与沉重。
4. **谜底藏在重复里**：单局像原作一样是"无名者的生存"；
   跨周目才显形的是这座城市 25 年的真相。玩家的元知识是真实资产。
5. **文本即玩法**：一切数值都翻译成可感的文字（干呕、发抖的句尾、沉默），
   一切文字都锚定在数值上。没有纯装饰的叙事，也没有裸露的数值。

## 2. 世界观

### 2.1 表层：一场"普通"的内战

- **国家**：斯托利亚联邦（虚构，东欧气质，约 1990 年代技术水平）。
- **城市**：别列佐夫（"白桦城"），河谷工业城市，人口约 40 万。
  战争爆发第 3 天铁路中断，第 9 天被合围。
- **交战双方**：
  - **城防军**（政府军）：守城，控制上城区与电台。
  - **灰隼旅**（叛军）：围城，控制城郊与码头外围。
- **你**：谁也不是。平民。城里的水电、药品、秩序正在逐日崩坏。

### 2.2 暗层：三层真相（跨周目揭示）

游戏有一份固定的**正典（Canon）**——世界的真实历史是写死的，
任何一局游戏都不会改变它，只会改变你看到多少。

**层 1 ——「这仗打得有点怪」（单局内即可察觉）**
- 前线三个月没移动过 500 米，但炮击从未停止。
- 炮弹 80% 落在平民设施上，军事目标完好无损。
- 城防军的公文纸和灰隼旅的征用令，是**同一个造纸厂的货**。
- 停火传闻出现过三次，每次都在 48 小时内"恰好"发生屠杀事件，谈判崩掉。

**层 2 ——「有人在两边同时供货」（跨周目浮现）**
- 城里的行脚商法比安，是"军需官"网络的最末端——一个横跨双方的物资组织。
- 电台的"政府广播"其实产自中立区的录音棚（代号**回声站**）。
- 狙击手路口的狙击手代号"灰雀"，是爱乐乐团的小提琴手，被强征的。
  他的枪法有节奏——那是乐句。**他是幸存者池里小提琴手佐菲亚的哥哥。**
- 医院院长塔玛拉医生偷偷收治双方伤员，她的伤亡统计指向一个结论：
  这场炮击有清单，清单是按"战后重建利润"排的。

**层 3 ——「战争是一份合同」（档案馆 + 关键证据解锁）**
- **《白桦协议》**：真正的停火协议在**开战第 14 天**就已经在圣米尔桥签署。
  双方签字代表在回程路上遭"伏击"身亡——第三方干的，两边都以为是对方。
- 操纵战争的是**长桌会**（The Long Table）：军火商、重建承包商、
  双方阵营里的代理人，在中立区长桌上分账。
- **关键谜面**：过去 50 年，这座城市经历的三次围城，全部在**第 41～43 天**结束。
  因为长桌会的供应合同以 40 天为一个结算周期——到期，收钱，停火。
  **而这一次，有人下了更大的订单：合同续约到了第 60 天。**
- 本局战争若无人干预，会打到第 60 天。正常玩到底的"随机"停火
  （第 30～45 天）是长桌会内部有人提前砍单——历史注定大多数人等不到真相。

### 2.3 局势时间轴（内核用，玩家只能看到表象）

| 天数 | 内核事件 | 玩家可见表象 |
|---|---|---|
| D1 | 开局 | 围城第 9 天，物资尚可 |
| D5-8 | 第一次假停火传闻 | 收音机流言、心情波动 |
| D10-14 | 疫情苗头 / 冬季窗口开启（随机） | 药品涨价、开始下雪 |
| D14 | （暗线）白桦协议签署 | **无任何表象**——永远只能在文档里找到 |
| D16-20 | 假停火二次传闻 + 屠杀事件 | 广播、邻居议论、心情 - |
| D25-35 | 停火真窗口（若触发）/ 袭击升级 | 前线炮声变化（懂行角色可解读） |
| D41 | 「41 天魔咒」之日 | 老人们说"上次战争就是 41 天" |
| D45-60 | 未干预则物资枯竭期 | 极限生存压力 |
| D60 | 长桌会合同到期，战争强制结束 | 全城停火，后日谈 |

## 3. 游戏循环总览

### 3.1 局内循环（单局，约 30-60 个游戏日）

```
┌─ 破晓 ──── 夜间结算（袭击/外出结果）、状态衰减、晨报
│  白天 ──── 行动点分配：建造/制造/吃饭/治疗/交谈/交易（自然语言驱动）
│  黄昏 ──── 决定：谁出门、去哪、带什么、留谁守家
│  深夜 ──── 外出者：LLM 主持的探索场景（对话/潜行/战斗/逃跑）
│           守家者：袭击检定（后台）
└─ 凌晨 ──── 归队、卸货、自动睡眠、日计数 +1
```

### 3.2 局外循环（跨周目）

```
一局结束（全灭 / 战争结束 / 灯塔 / 入桌）
        ↓
结局结算 → 后日谈 → 档案馆存档（文档、人物真相、结局记录永久保留）
        ↓
开启新局（新的幸存者组合 / 季节 / 局势切片，但正典不变）
        ↓
玩家带着元知识重新进场 → 能问到新的问题 → 挖到更深的层
```

## 4. 内核 A：幸存者

### 4.1 五条状态轴（每名幸存者独立维护）

**饥饿**（离散 5 级）：`饱足 → 正常 → 饥饿 → 严重饥饿 → 濒死`
- 每天凌晨自动 -1 级（饱足只跌到正常）。
- 进食：生食 +1 级；熟食 +2 级；罐头 +2 级；厨师的高级餐 +2 级且心情 +1。
- 严重饥饿：劳动/战斗效率 -1 档，每晨心情 -1。
- 濒死：每天 50% 转为重病，无法执行重体力行动。

**伤病**（两条独立 4 级轴）：`无 → 轻伤/微恙 → 重伤/重病 → 危重`
- 轻伤：休息 3 天自愈；绷带 + 休息 → 1 天。
- 重伤：需绷带 + 卧床，3-5 天恢复；不治每天 30% 恶化。
- 危重：需绷带 + 药品 + 卧床，且**必须有医护角色照料**才稳定，否则每天 50% 死亡。
- 微恙：休息 2 天 或 草药药 1 天。重病：药品（或草药药×2）+ 卧床。
- 冬季夜间无取暖：每夜 25% 患微恙（老弱角色 40%）。

**心情**（点数制，映射 4 级）：`坚定 → 低落 → 抑郁 → 崩溃`
- 事件增减心情点（见 §10），每级阈值 5 点，向下取整。
- 抑郁：拒绝部分行动（LLM 按人设演出），效率 -50%，夜间有独走检定。
- 崩溃：进入 1-2 天的**预警事件链**（失眠、独语、藏刀），
  其间可安抚（交谈 + 满足需求 + 陪伴守夜）；无人干预则离队或自伤。

**疲劳**（3 级）：`正常 → 疲惫 → 力竭`
- 不睡觉 +1 级/天，睡地板 -1 级，睡床 -2 级（外加小幅回血）。
- 力竭：强制昏睡半天，战斗大弱。

**温度**（冬季启用）：室内温度 = 取暖设施 - 天气严酷度；不足则按上条生病检定。

### 4.2 幸存者池（12 人，每局随机 3-4 人）

每人 = 属性倾向 + 特长 + 心结 +（部分人为**正典钥匙**）。

| 角色 | 背景 | 特长（机制） | 心结 / 私欲 | 正典关联 |
|---|---|---|---|---|
| 安东 | 退休数学教师 | 制造高级物品；谈判小加成 | 女儿在下城区，想去找她 | 无（但账本类文档他读得快） |
| 玛尔塔 | 退役护士 | 治疗效果 ×2，卧床者稳定 | 心软：拒绝求助 = 大量心情损失 | 与塔玛拉医生是旧识（医院线引子） |
| 布罗 | 消防员 | 背包 14 格；破门；近战强 | 救过人也在火里丢下过人 | 无 |
| 卡佳 | 前电台记者 | 谈判 +15%；能听出广播异常 | 职业本能：想搞大新闻 | **正典钥匙**：收音机内容她能识伪 |
| 帕维尔 | 短跑运动员 | 逃跑检定大加成；背包 10 | 怕黑（夜间独处检定） | 无 |

首次游戏固定抽到含 1 名正典钥匙角色的组合，保证暗线可被第一次触碰。

## 5. 内核 B：物品与经济

### 5.1 物品（v0 清单，价值点为交易基准）

| 类别 | 物品（价值点） |
|---|---|
| 食物 | 生食(4)、蔬菜(3)、肉(5)、罐头(14)、糖(8)、水(1) |
| 药品 | 绷带(25)、药品(30)、草药药(18)、烟草(6) |
| 嗜好品 | 香烟(12)、咖啡(12)、私酿酒(16)——硬通货性质 |
| 材料 | 木板(2)、零件(1)、部件(3)、电子件(8)、化学剂(10)、火药(12) |
| 燃料 | 柴火(3)、燃料(6)、书(可读可烧，4) |
| 工具 | 撬棍(10)、铲(8)、锯(8)、斧(15)、刀(12)、开锁器(9) |
| 武器 | 手枪(40)+子弹(6/发)、步枪(55) |
| 贵重品 | 珠宝(20)、名酒(18)、乐器部件(9)、**文档**（只对玩家有价值） |

### 5.2 制造（示例配方，工匠/格里高利 -20% 材料）

| 产物 | 配方 | 需设施 |
|---|---|---|
| 熟食 | 生食×1 + 水 + 燃料 | 炉灶 |
| 私酿酒 | 糖×1 + 水 + 燃料×2 | 蒸馏器 |
| 香烟 | 烟草×2 | 工作台 |
| 绷带 | —（不可造，只能搜/换/医院） | — |
| 草药药 | 草×3（草药园产出） | 工作台 |
| 开锁器 | 部件×1 | 工作台 |
| 刀 | 木板×1 + 部件×2 | 金属台 |
| 子弹 ×5 | 火药 + 部件 | 军工台 |

### 5.3 交易规则

- 行脚商**法比安**每 2-4 天来访一次（他本身是暗线 NPC，见 §12）。
- 收购价 = 基准 ×0.5~0.7；出售价 = ×1.2~1.5；卡佳/薇拉 ±10~15%。
- **供需事件调价**：冬季燃料类 ×2；疫情期药品 ×2；停火传闻期食物 ×1.5。
- LLM 谈判在核心给定的价格带**内**浮动；试图"用 1 块木板换 5 卷绷带"
  直接被核心驳回（LLM 负责把拒绝演得像人）。
- 部分地点可交易（医院、码头、超市后期），各有价格带。

## 6. 内核 C：避难所

**默认开局**：槐树街 21 号，半塌的联排别墅——客厅里有一架**走音的钢琴**。
（佐菲亚修好它 → 演奏心情加成翻倍 + 暗线回响；它也是多次游玩后的情感地标。）

| 设施 | 功能 | 升级线 |
|---|---|---|
| 床×N | 睡眠质量、回血 | 简易床铺 → 像样的床 |
| 炉灶 | 烹饪 | → 节能炉灶 |
| 取暖炉 | 冬季保温 | 火盆 → 铁炉（烧书/柴/燃料） |
| 工作台 | 基础制造 | 一级 → 二级（高级配方）→ 三级 |
| 金属台 | 刀、斧、加固件 | — |
| 集雨器 | 产水 | — |
| 捕鼠笼 | 偶得生食 | — |
| 草药园 | 产烟草/草（需水） | 菜园（产蔬菜） |
| 蒸馏器 | 私酿酒 | — |
| 门/窗加固×3 | 防袭击防御 +2/级 | 铁皮加固 → 工字钢 |
| 收音机 | 新闻/天气/音乐（心情） | **阿列克谢可改发报机（终局）** |

建造消耗材料 + 行动点（见 §7）。设施状态（如炉火是否点着）由内核记账，
LLM 只描述，不发明。

## 7. 内核 D：日循环与行动点

### 7.1 阶段与行动点

- **白天**：每名幸存者 3 点行动力（重伤/重病/抑郁 → 1 点；轻伤 2 点）。
  常见耗时：吃饭 0；交谈/安抚 1；治疗他人 1；制造 1-2；建造 2-3；
  修钢琴 2（佐菲亚专属，共 3 次）；白天守卫 0（占用此人其他行动 -1）。
- **黄昏**：指派 1 人外出（装备背包与工具/武器），其余人可安排
  睡觉 / 守夜 / 继续白天未完的低强度事。
- **深夜**：外出场景（见 §8）；留守者进入袭击结算。
- **凌晨**：状态衰减（饥饿 -1、伤病/心情 tick）、日计数 +1、晨报生成。

### 7.2 日常委托（省心机制 ★）

文本游戏里天天点"吃饭、烧水"会腻。玩家可设定**日常策略**，内核自动执行：
- 饮食策略：如"布罗隔天吃熟食，其他人饿了才吃生食"；
- 自动守卫轮换、自动烧水、自动喂炉子。
- 内核执行后在晨报里一句话交代；任何自然语言指令可临时覆盖。
- LLM 只需处理玩家**主动说出口的**非常规动作。

## 8. 内核 E：夜间探索

### 8.1 地点卡（每局从地点池抽取可用子集，共 14 个）

每张地点卡是一份结构化数据 + LLM 演出层：

### 8.2 探索场景规则

- 地点被建模为：**房间图 + 容器（含工具门槛：锁/瓦砾/栅栏）+ NPC 表 + 时间槽**。
- 深夜共 **10 个时间槽**。移动 1 格、搜 1 个容器、撬 1 把锁、一场对话、一次战斗
  各耗 1-3 槽。槽耗尽时强制天亮前撤离判定。
- 玩家用自然语言行动；LLM 解析 → 核心校验（物品存在？工具在手？时间够？）
  → 核心掷骰 → LLM 叙述结果。
- **检定**：2d6 + 修正 vs 难度带（6- 失败 / 7-9 代价成功 / 10+ 干净成功）。
  骰子永远由内核投，LLM 只拿到结果枚举（成功/代价/失败 + 具体代价项）。
- 战斗：先手 - 武器/状态修正 - 骰点 → 结果档位（完胜/受伤获胜/两败/重伤败逃/死亡）。
  枪声会消耗额外时间槽（引来搜查）。

## 9. 内核 F：事件与局势

### 9.1 白天事件表（按权重抽样，LLM 包装演出）

- **邻居求助**（每 3-5 天）：药品求援 / 借工具 / 求人驱赶暴徒 / 代看孩子 / 求带信去邮局。
  帮 = 心情 +3~5 + 有时报酬 + 邻里声望；拒 = 视角色心结扣心情。
- **法比安来访**（每 2-4 天）：交易窗口；多周目后他的言行可被审出破绽。
- **奇访者**：逃兵求收留一夜（收 = 风险+心情，拒 = ?）/ 受伤陌生人 / 走失的孩子。
- **内部事件**：争执（资源分配分歧，LLM 按人设生成）、病情恶化、庆祝（生日/雪停）、
  尤拉偷抽烟被抓（管教选择）。
- **广播**（需收音机）：新闻（真假混杂，见 §12.4）/ 天气 / 音乐（心情 +1）。

### 9.2 夜间袭击（留守结算）

- 威胁值 `T = 2 + 天数/3 + 家产价值/50 + 恶名`，恶名由你抢过谁、杀过谁累积。
- 防御值 `D = Σ武器值 + 守卫人数×2 + 门加固等级×2`。
- 结算带：`D ≥ T` 击退（可能有轻伤）；`D ≥ 0.6T` 击退但有人受伤+失窃少量；
  `D < 0.6T` 失窃（按价值从高到低被拿）+ 随机受伤；极差带：重伤或死亡。
- 被抢过的人家（包括你抢过的人家）会记住——跨周目仍有痕迹。

### 9.3 天气与季节

- 每日天气：晴 / 雨 / 雾 / 雪 / 严寒。冬季窗口随机落在 D10-35。
- 雨天：集雨器效率 ×2；雪天：移动 +1 时间槽、两个城郊地点封闭；
  严寒：取暖强制检定（§4.1），冻伤转轻伤。

### 9.4 战争结束（常规结局）

- 表面随机：D30-45 抽中停火日，前 5 天有真实前兆（炮声稀疏、
  懂行角色可确认——卡佳/老兵 NPC）。
- 停火后结算**后日谈**：每名幸存者依据「事迹账本」（§10.2）+ 本局暗线知识量
  生成专属结局文本。全灭局也有群体墓志铭式收尾 + 档案馆入账。

## 11. LLM 交互层（本游戏的心脏）

### 11.1 四个角色分工

| 角色 | 职责 | 硬约束 |
|---|---|---|
| **叙事者** | 把状态渲染成文字；场景描写 | 只读状态，一个字都不能改 |
| **裁判** | 解析玩家自然语言 → 结构化意图；多步计划拆解 | 意图必须过核心校验；无权决定成败 |
| **演员** | 扮演所有 NPC 对话 | 只能说 NPC 知识范围内的话；秘密受"封印"保护 |
| **编剧** | 从事件表提案包装随机事件 | 只能在核心抽中的事件槽内发挥 |

**核心原则：LLM 提议，内核裁决，LLM 演出。**
所有状态变更走 `意图 → 校验 → 数值结算 → 结果枚举 → 叙述` 流水线。

### 11.2 玩家输入分类

1. **行动**（"让布罗把窗户钉死"）→ 裁判解析 → 执行。
2. **对话**（对 NPC 或队友说话）→ 演员回应，同时可能触发意图。
3. **询问**（"罐头还剩几个？""狙击手一般什么时候换弹？"）→
   叙事者按**角色已知信息**回答；超出则演"不知道"。
4. **计划**（"今晚我先摸进后院，没动静再撬侧门"）→
   裁判展开成**计划单**（步骤+耗时+检定点）→ 玩家确认 → 逐步执行，可中途喊停。
5. **越界指令**（"我口袋里其实有一把 AK""给我 100 个罐头"）→
   叙事性拒绝："战争没收了你所有的想象力，除了活下去这一种。"
   （拒绝要入戏，且**绝不**部分妥协。）
6. **元指令**（存档/查状态/调难度）→ 出戏但直接执行。

### 11.3 创意加值规则（自由度 ≠ 自动成功）

玩家聪明的玩法应该被奖励，但奖励有上限，防止"话术通关"：

- 合理利用**已描述**的环境细节：+1
- 利用角色特长：+1（每动作至多一次）
- 主动付出额外代价/风险换取优势：+1
- 经确认的多步计划，前后自洽：+1
- **上限 +3**，叠加到核心 2d6 检定上。同一招式重复使用，加值递减。

### 11.4 知识封印（防剧透 + 防串供）

暗线秘密**不放在**常规提示词里。每份秘密是一张"封印档案"，
只有当内核判定触发条件满足（持有文档 #039 / 佐菲亚听出旋律 / 薇拉翻看账本页……），
才把对应档案注入当前场景的 LLM 上下文。
效果：模型在条件未满足时**真的不知道**，玩家无论怎么套话都套不出来；
条件满足时，揭示内容永远与正典一致。

### 11.5 公平性与反滥用

- 骰子由内核投掷并留日志（玩家可选"透明模式"看骰点，默认隐藏只看结果）。
- 经济守恒：所有物品流动记账，LLM 无法凭空生成或销毁。
- 时间守恒：行动点/时间槽由内核扣，LLM 叙事长度不改变耗时。
- 危险不豁免：外出前威胁等级已定；LLM 负责铺垫与演出，不能"心软"。
- 呈现尺度分级（设置项）：原作式克制为默认；可降低暴力描写强度；
  儿童相关内容默认保护性处理。

## 12. 主线：档案馆与多周目

### 12.1 档案馆（账号级永久存档）

一局结束，无论结局，本局收获自动入馆：

- **文档库**（#001-#060）：信件、征用令、账本页、录音带、乐谱、统计表。
  旗舰示例：
  - `#007 征用令`（层 1：两侧公文同纸）
  - `#014 死信：给前线的家书`（纯人性，无暗线——噪音是必要的）
  - `#021 塔玛拉医生的弹道统计`（层 2）
  - `#028 灰雀的乐谱碎片`（层 2，狙击手线）
  - `#033 法比安账本缺页`（层 2，商人身份）
  - `#039 《白桦协议》抄本`（层 3：停火早已签署）★铁证
  - `#045 回声站录音带`（层 3：广播造假）★铁证
  - `#052 长桌会合同残页`（层 3：续约至第 60 天）★铁证
  - `#058 圣米尔桥伏击弹壳报告`（层 3：第三方灭口证据）
- **人物真相**：每位正典 NPC 一份档案，逐条解锁（"法比安为什么总在周三来？"）。
- **这座城记得**：你历代角色的结局与事迹账本。浏览旧文档时，
  会看到"当年也见过这份纸的人"留下的批注——包括已经死去的那些角色。
- **进度门槛**（解锁矩阵）：
  - 层 1 显形：累计任意 8 份文档
  - 层 2 显形：累计 20 份 + 任 3 位 NPC 真相
  - **灯塔行动**（层 3 终局剧本）：层 2 已解锁 + 当局内集齐 3 件铁证
    + 阿列克谢在场（或已说服电站工程师）+ 一名"知晓者"存活

### 12.2 灯塔行动（真结局剧本）

- 触发后，当局新增目标线：**在长桌会"续约日"（约 D55）之前，让真相上广播**。
- 路线：取得电台废楼准入（强攻 / 说服守军里的厌战者 / 贿赂 / 里应外合）
  → 阿列克谢修复发射机 → 卡佳（或任意知晓者）念出证据 → 全城听到。
- 广播后 3 天的连锁叙事：前线自发停火、双方士兵哗变调查、长桌会仓促收场
  → **战争在 D+3 结束**（远早于 60 天）。
- 结算升级为**全城后日谈**：不止你的小队，还有神父、塔玛拉、法比安、
  沟鼠们、甚至灰雀——他的结局由你在狙击手线的处置决定。

### 12.3 第四种结局：入桌（隐藏黑暗结局）

持有 #033 或 #052 时，法比安会在某个黄昏带来一个提议：
**长桌会买你的证据**——离开这座城的通行证 + 一箱物资，代价是沉默。
- 接受 → 黑暗结局：「你活到了第 41 天。战争也是。」
  档案馆解锁特殊词条，且此后**每周目**法比安都会认出你（新开局的隐藏事件）。
- 拒绝 → 法比安此后不再来访，交易渠道变窄（真实代价）。
- 这给暗线装上了牙齿：发现真相之后，你还要**选择**配不配得上它。

### 12.4 正典不变量 vs 周目随机量

| 每局随机 | 永不改变（正典） |
|---|---|
| 幸存者组合、季节、天气序列 | 暗线全部事实（谁、为何、何时） |
| 地点可用子集、事件抽样顺序 | 正典 NPC 的身份与秘密 |
| 袭击/物价波动骰运 | 三场历史战争的"41 天"模式 |
| 你的选择与结局 | 圣米尔桥、白桦协议、回声站的存在 |

玩家的元知识 = 唯一跨周目增值的资产。二周目起，部分对话会出现
「你已经知道结局」专属选项（灰色小字），点了会有真实的叙事回报。

## 13. 呈现与节奏

- **界面三段式**（网页）：
  顶部状态栏（日期/天气/阶段 + 人物卡横排）；中部叙事流（正文 + 对话）；

- **声画点缀（可后置）**：极简——雨声、远炮、收音机杂音、钢琴单音。宁缺毋滥。

## 14. 示例流程（第 1 天，节选）

> **破晓 · 槐树街 21 号 · 围城第 9 天 · 雨**
> 炮击在凌晨四点停了，雨接管了城市。玛尔塔在楼梯下生了火，
> 布罗把门厅的柜子又推了半寸。冰箱断电第三天，里面的味道开始变得诚实。
> 你们有：木板×6、零件×4、罐头×2、生食×1、水×3、绷带×1。
> 状态：全员「正常/坚定」，安东微恙。

**玩家**：先把二楼那间房的床架拆了当木板，让布罗干。
然后玛尔塔给安东看看病。我下午想去隔壁面包师家里问问能不能换点面粉——听说他们上周就走了。

**裁判解析**（内部）：
`布罗: 拆床架 → +木板×3, 耗时2` ✓
`玛尔塔: 治疗安东 → 微恙→明日痊愈, 耗时1` ✓
`玩家(以谁的身份?)去面包师家 → 需指派角色 + 1行动` → 反问确认

**叙事者**：布罗的撬棍在床架关节处发出三声闷响……（略）
你要亲自去隔壁？这会用掉你整个下午，而且雨还没停。

**玩家**：让卡佳去吧，她嘴甜。带两块零件当见面礼，但如果人还在家，别提交换，先听听他们要什么。

**叙事者**（执行 + 编剧掷中「邻居求助」事件槽）：面包师没走。他妻子在。
她隔着门缝听完了卡佳的来意，很久没说话。然后：
"零件我有用。但如果你们有药……我婆婆的腿在发黑。你们有吗？"
（她盯着卡佳的眼睛。卡佳知道家里有且仅有一卷绷带。）

**黄昏指派** → **深夜 · 被炮击的超市**（布罗外出，携撬棍）：
> 货架像被巨兽舔过。冷柜后面有声响——人，活的，带着枪。

**玩家**：我不出声，先退回冷冻室门口，听他的动静规律。要是他只是翻东西，我就等他离开这个区域再动手搜。

**裁判**：潜行检定 2d6（+1 利用环境已描述的冷柜噪音掩护）……核心掷出：代价成功。
**叙事者**：你贴着冷柜挪了两步，脚下的碎玻璃替你出了声。那人端枪转过身来——
是个和你差不多年纪的男人，军大衣是偷来的，饿得手都在抖。
他喊了一旬别列佐夫土话："出去！这是我的！"

**玩家**：我慢慢举起手，用另一只手从包里拿出那罐午餐肉，放在地上，退后两步。

**叙事者**：男人的枪口在你和肉之间摆了三次。……"一半。"他用刺刀把罐头撬开，
真的掰了一半推回来。"超市是我的。但……下城区的邮局没人搜过。我发誓。"
（你获得了：半罐午餐肉。你记住了：**下城区邮局**。）
（布罗心情：这个人没有开枪。他也不好过。心情 +1。）

**玩家**：趁现在，我口袋里其实还有一把手枪，我拿出来指着他说把军大衣脱下来。

**裁判**（越界驳回 → 叙事性拒绝）：你没有枪。战争爆发第九天，
这座城里像你这样两手空空的人，唯一的武器就是还在喘气这件事。
