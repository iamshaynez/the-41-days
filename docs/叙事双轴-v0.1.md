## 1. 需求映射与总原则

| # | 需求 | 本卷落点 |
|---|---|---|
| 1 | 开局前的三国大背景 → 围城引入 | §2 幕一「天下」＋幕二「围城」（固定文本，不走 LLM） |
| 2 | 主角前传，随机组合要有因果 | §2.3 幕三「入局」：前传四拍 ＋「被剩下的」合流律 |
| 3 | 主文字轴靠左，右侧地图可视化 | §3 舆图（`map.json` ＋ 地点坐标，纯视图无交互） |
| 4 | 右侧贯穿全局的历史故事轴，日终双更新，LLM 驱动 | §4 主线日步引擎 ＋ §4.5 史官（annalist） |
| 5 | 主线关键元素特殊标注 | §6 标注协议（人／地／物／事／决／伏六类） |
| 6 | 历史轴用演义熟面孔，人物要足、可随机 | §5 历史轴三层（锚固定，闲笔抽样，不触锚） |
| 7 | 更多文本、更多伏笔、两线真交织 | §7 伏笔登记 ＋ 玩家作为投影为闲笔 |

**总原则（先立三条，全卷不许破）：**

1. **锚不动，纹理动。** 正史锚点与大剧本骨架零随机（RND-08 / GE-10 全文有效）；
   LLM 与闲笔只准在骨架的缝里长肉。玩家的选择改不了史书，但史书的**角落**会照出玩家的作为。
2. **文本即玩法（GDD 支柱 5 的延伸）。** 大事轴不是装饰性播报：
   轴上的每一条高亮，要么指向可去的地、可拿的物、可问的人，要么指向已埋未发的伏笔。
   玩家读轴，应当像读一份藏着路线图的露布。
3. **LLM 可拔插。** 序章与大事轴骨架是手作定稿；LLM 缺席时直读模板完整可玩（GE-13 模式），
   只少了当日文本的新鲜感。

## 2. 开局序章：三幕

现状：序章已有五张卡（`p1_water`～`p5_dawn9`，围城头九天），回答了"你们为什么没走"，
没有回答"这是什么世道"与"你们是谁"。三幕制补齐这两问，并把既有五卡收进幕二幕三之间。

```
幕一「天下」   固定文本三段＋一句转轴       （约 300 字，无选择）
幕二「围城」   固定引文两段 → 序章卡 p1/p3/p4 （选择入账，旗标沿用）
幕三「入局」   前传 N 段（本局出场者）→ 合流段 → p2（写名上墙）→ p5（第九天早晨）
```

### 2.1 幕一「天下」——众所周知的部分

- 全固定文本，不掷骰、不生成。它是锚：玩家带着《演义》进场，
  幕一就用《演义》的语言讲一遍天下——黄巾、官渡、赤壁、三分——
  然后讲到这一年七月围樊、八月水淹七军。
- 收轴句落在正史与露布的分界上："史书写到这里，都是真的。史书没写的，从这个秋天开始。"
- 幕一是全游戏唯一一处**全知叙述**（说书人顿挫），此后叙事权交还第二人称。
- 定稿全文见附录A。二周目起默认折叠为一行（「天下，你已听过——建安二十四年，秋。」
  点开可重读），不占重玩节奏。

### 2.2 幕二「围城」——为什么是围城

- 引文两段（附录A）：大胜第三天降卒进城、米价翻倍；江陵没有敌人，
  江陵是胜利者的后方——**这座城自己围住了自己**。
- 随后接既有 `p1_water`（降卒与"没走"）→ `p3_shelling`（第一次征发）→ `p4_door`（敲门）。
  三卡文本微调去重（引文已交代降卒，p1 收窄到"渡口最后一夜"的追忆）。
- 幕二立起本作的第一层反讽：**胜仗是灾殃的账单**（层 1 暗流的第一次心跳）。

### 2.3 幕三「入局」——为什么是这几个人

回答设计问题：**每局随机 3–4 人（十二人池，见 GDD §4.2），随机不等于无因果。**
因果分两层：

**个人层：前传四拍。** 每人一段（150–250 字），四拍结构（模板与十二人要点见附录C）：

1. **来处**——一技一业，落到两个具体物件上（字帖、断弦琴、火镰……）。
2. **裂缝**——心结事件（人物设计的 knot），只写现象，不写真相。
3. **困局**——为什么这个秋天人在江陵、为什么没走：一个被截断的具体动作
   （排到一半的队伍、塌了半面的台、等一封没来的信）。
4. **落点**——收进橘里九号，一句收束。

**前传不泄封印律（硬边界）：** 前传只写角色**自知**的过去。
素徽不知道哥哥卖过更籍，薄姑不知道检署流向券局，逄灶不知道同期老纪在誊什么——
暗线真相一字不入前传。前传的钩子只指向心结，不指向答案；
答案属于夜行、封印与多周目（兰台进度门槛不改）。

**合流层：「被剩下的」。** 三四个人为什么同住一屋，不做天选解释——
围城不挑人，围城**剩下**人。合流段一段（附录A），通用版＋组合变体：

- 通用版：三条路一扇门，名字上墙（衔接 `p2_house`）。
- 组合变体（手作，触发即插播）：素徽在队 → 宅子是她家的旧宅（她第一个进门，谁也不争了）；
  江鳅＋薄姑同队 → 两人隔着门槛互相看了一眼（互不信任开局，GDD §4.2）；
  白简在队 → 他认出门版削痕，半天没说话。
- 首局保底含一名正典钥匙角色（GDD §4.2 既有规则），前传因此必有一条线"有来路"。

### 2.4 数据与流程

- 新内容文件 `content/base/prelude.json`：
  ```json
  {
    "heaven":  [ { "id": "h1", "text": "……" } ],            // 幕一段落
    "siege":   [ { "id": "s1", "text": "……" } ],            // 幕二引文
    "prequels": {
      "zofia":  { "title": "素徽 · 断弦", "line": "单句版（二周目幕三用）", "paras": ["……"] },
      "alexey": { "title": "逄灶 · 半面台", "line": "……", "paras": ["……"] }
    },
    "confluence": {
      "default": "……",
      "variants": [ { "requiresChar": ["zofia"], "text": "……" } ]
    }
  }
  ```
- 内核：run 起始新增 `phase:'prelude'`；序章卡沿用事件系统（`kind:'prologue'` 已有），
  前传与合流为纯文本幕（`PRELUDE_TEXT` 事实记账，可回放）。`advance` 逐幕翻页。
- 跳过策略（拍板 v4，取代 v2 首局门）：**每一局都从「开场二选一」开始**——完整三幕 or 精简版，
  与账号通关与否无关；选择本身就是入场礼。拣精简进单句版（幕一折叠为一行，幕三降为
  `prequels.*.line` 只播本局出场者，「翻全卷」可展开全文、「翻过序章」一键直达 D1）；
  拣完整则三幕全量、**不可跳**——选了完整的人，三幕就是入场礼。
  反设计清单（长线体验 §5）禁的是跳天数，不禁跳已读的引子。
  （快局「围城切片」系长线体验 §4.1 规划局型，尚未实装；落地之日直接继承开场二选一规则。）
- sim／bots：序章阶段自动 `advance`，delegate 策略口径不变。

## 3. 舆图：右侧的江山

### 3.1 图层（新内容文件 `content/base/map.json`）

- **底图**：江陵城手绘风 SVG——城垣轮廓、三面水势（长江、汉水、城濠）、
  四门（北津、水门、江津、南市缺口）、里坊肌理（橘里在深处）。
  底图零依赖：路径数据住 JSON，前端原生 SVG 渲染。
- **地点层**：九个地点（`locations.json` 全部）补 `geo: { x, y }`（0–100 相对坐标）＋
  `kind`（城内／城外／水上）。郢都废墟、纪南大仓等未实装地点**不上图**——
  图上只画玩家此局可能踏到的土地（留白也是诚实）。
- **家**：橘里九号，图上的原点。

### 3.2 状态（server 现算纯视图，不入账）

| 状态 | 呈现 |
|---|---|
| 未闻 | 不显示（连名字也不给——地名不剧透） |
| 已知（knownLocs） | 淡墨点位＋名字 |
| 今夜在场（夜间指派） | 亮色＋人物小标（外出者谁在哪） |
| 白日 | 全员在橘里九号，一点如灯 |

- 黄昏指派后、夜间行动中：`橘里九号 → 目的地` 一条虚线（走向）。
  夜间地点内的房间级移动不上图——图管乾坤，不管抽屉。
- 归途、袭击一律不预告（图不剧透夜晚的结果）。
- **无交互**：不可点、不可缩放。它是墙上挂的一张舆图，不是雷达。

### 3.3 为什么值得做

地名不再悬空：幕二说"渡口封了"，图上看得见渡口在哪；
白翎线触发时，玩家知道水门渡与自家隔着一道城濠。
空间感是沉浸最便宜的杠杆，也是最不干扰核心循环的一块旁窗。

### 3.4 留痕层（拍板升格：图是活的）

**战争在图上留疤。** 事件、季候、玩家的作为，都要在舆图上留下看得见的痕——
这是拍板第 5 条的执行面，可视化优先，不怕麻烦。

**痕迹协议**（`map.json` 增 `traces`，触发全部来自既有旗标／文档／封印／结局，不新造状态）：

```json
{ "traces": [
  { "id": "tr_fire", "icon": "scar",  "at": "city:north",
    "when": { "flag": "granary_burned" }, "once": true },
  { "id": "tr_seven_ships", "icon": "ships", "at": "river:jing",
    "when": { "phase": "warEnd" }, "once": true }
] }
```

- server 现算已激活痕迹（纯视图，与 §3.2 同口径，不入账）。
- **双显形原则**：同一触发，轴上一句（§7.2 投影闲笔），图上一痕（本节）——
  「世界记得」写两遍，一句给读史的人，一痕给看图的人。
- **痕不消退、不跨局**：一局之内疤只在增多；跨局各局重演同一个秋天，
  城市痕不继承（宅内痕属 EC-04 故地重游，另册管理）。
- **密度闸**：同屏至多七痕；旧痕淡为底纹，悬停可查——痕多不等于城碎。

**图标库（首批十二枚，手绘线稿 SVG：stroke 为主，无 emoji、无位图；
强调色只许朱砂、霜青两色）**：

| 痕 | 图标 | 触发（示例） | 时性 |
|---|---|---|---|
| 焦痕 | 焦黑斑块＋烟迹三缕 | 大仓失火步（幕三 `m_fire`） | 永久 |
| 烟 | 细烟两缕 | 医棚疫病苗头（`m_d06`） | 永久，淡 |
| 箭 | 箭簇记号；停火后加一横线 | 水门渡白翎线／送谱停火（`crossing_*`） | 可变 |
| 鼓 | 鼓形＋两道声弧 | 北津台举火（或然A／还师 `alt_maicheng`／`lighthouse_day`） | 永久 |
| 船 | 船影一枚 | 鲁舟泊船日（逢双日，最淡） | 当日 |
| 七船 | 小船影七枚排列 | 交割日黄昏（D45） | 永久 |
| 门缝 | 城门一道细缝＋一滴油 | 交割前夜（`m_d44`）；惨胜线改「干涩的叉」 | 永久 |
| 封泥 | 方印小记 | 薄姑验出编号段（`vera_stamps` 类旗标） | 永久，淡 |
| 霜 | 全图霜色滤镜（非图标） | `winterActive` | 季内 |
| 水纹 | 江面纹线加密 | 霖雨日 | 当日退 |

图标随批三做基础五枚（霜／焦痕／烟／缺口／水纹），批七补齐余枚；
每枚 icon 一枚 `<symbol>`，web 端原生 SVG 引用（零依赖不变）。

## 4. 大事轴引擎：主线日步

### 4.1 五幕骨架（D1–D45，手作，零随机）

| 幕 | 天数 | 幕名 | 主线一句话 | 收束节点 |
|---|---|---|---|---|
| 一 | D1–10 | 大胜之秋 | 胜仗为什么是灾殃 | 降卒入城、米价、第一次征发 |
| 二 | D11–20 | 盟约的静默 | 盟友为什么不送粮 | 陆逊谦书、吕蒙称病、湘关米传闻；城防空一层 |
| 三 | D21–30 | 火 | 守城的人烧了自己的仓 | 纪南大仓失火；**惨胜时限 D30 在此幕** |
| 四 | D31–40 | 救兵的谣曲 | 露布变调与枯竭 | 徐晃援军循环；**还师窗口 D40 在此幕** |
| 五 | D41–45+ | 交割 | 门从里面开 | 讲古日、船期反常、交割前夜、D45 开城 |

结局幕（延展步）：史实《开城》／或然 A《麦城得脱》／或然 B《惨胜》（endDay+6，
步序随内核交割日顺延）／《还师》／《出江陵记》——各一组收束步，不掷骰。

### 4.2 步结构（schema，`content/base/mainline.json`）

```json
{
  "acts": [ { "id": "A1", "title": "大胜之秋", "days": [1, 10], "spine": "胜仗为什么是灾殃" } ],
  "steps": [
    {
      "id": "m_d01",
      "day": 1,                        // 或 "dayWindow": [11, 13]（窗口内取首日未占用者）
      "act": "A1",
      "anchor": "降卒入城第三日",          // 正史/局势锚（固定，防火墙词表之源）
      "surface": "米价再倍；露布第七篇",     // 水面（玩家可见表象，局势表已有）
      "undertow": "胜仗的账单开始计息",      // 水下暗流提示（层钩子，只暗示不揭底）
      "sense": {
        "marker": "loc:market", "suggest": { "mood": -1 }   // 步对状态的影响（走既有 effects 白名单）
      },
      "hooks": [ { "key": "doc:#007", "hint": "征发檄的编号段不对" } ],  // 伏笔登记（§7）
      "when": { },                      // 分支条件（协议同事件卡 when：requiresFlag/maxDay/…）
      "brief": "史官渲染指令（§4.5）",
      "fallback": "直读文本（LLM 离线时的当日大事条目，手作定稿）"
    }
  ],
  "endings": { "lighthouse": [ … ], "join_table": [ … ] }
}
```

- 步是**骨架不是文案**：`anchor/surface/undertow` 三行事实 ＋ `brief` 指令 ＋ `fallback` 底稿。
  LLM 在骨架上长肉；直读时 fallback 即肉。
- `sense` 走既有 effects 白名单（mood 微幅、旗标），每日大事的机制痕迹至多一条，
  **大事轴不抢事件系统的戏**——它是窗外的江，不是门里的客。

### 4.3 选步规则（内核，确定性）

1. 每日破晓：按 `day`（或 `dayWindow` 首个未占用日）取步；`when` 不满足则顺延取下一步。
2. 一日一步；无步之日（骨架留白日）大事轴只出闲笔（§5.2）。
3. 分支：或然 B 触发 → `endDay+6`，D31 起的步自动后移（内核 endDay 已可移，vitals 既有逻辑）；
   还师启动（`lighthouse_day`）→ 切入 `endings.lighthouse` 步组；
   出江陵接受 → 切入 `endings.join_table`。玩家选择决定走哪组步——
   **这就是"大剧本随玩家走向支线"的全部机制含义：步组切换，锚不换。**
4. 选步入 `MAINLINE_STEP` 事实（事件溯源，fold 可回放）；当日 LLM 文本存
   `run_narration` 表（既有 004 迁移），重放取缓存，离线取 fallback。

### 4.4 玩家轴：当日纪事（确定性，不走 LLM）

- 每日凌晨，server 从当日 facts（事件选择、交易、袭击、伤亡、文档、旗标）汇编
  「我方一行」：至多三拍，每拍一句话（句式从 storyline 的 beat 短语表取）＋队伍状态一句。
- 事实性条目内核出，文采不外包——玩家轴是**账**，大事轴才是**史**。账不粉饰。

### 4.5 史官（annalist，新提示词角色）

- 提示词文件：`content/base/prompts/annalist.md`。
- 输入：当日步（anchor/surface/undertow/brief）＋当日至多两条闲笔（§5.2）＋
  玩家轴三拍（供"纹理动"）＋前两日大事文（连续性）＋文风圣经约束块＋正史防火墙词表。
- 输出：当日大事条目 1 条，**史书体 ≤120 字**，高亮标记（§6）合法；
  允许"露布体引文一句＋史笔正文一句"的双层写法（官话与实情同框）。
- 校验（提示词变更规范，AGENTS §2.6）：金样本评测断言——
  ①锚点零改动（防火墙词表命中即拒）；②标记全部过 registry（§6.3）；
  ③文风禁词零命中；④≤120 字。违规回退 fallback。
- 降级：LLM 离线 → `fallback` 直读（GE-13 模式，可玩性完整）。
- sim 不受影响（bots 不请求史官；大事轴对 bots 是旁路）。

## 5. 历史轴的血肉：锚层 · 闲笔层 · 传闻层

历史轴 = 大事轴条目里的三种墨。**演义熟面孔主要活在闲笔层与传闻层**——
名将不上台（正典圣经 §6）的纪律不变：他们在远方、在露布上、在别人的嘴里，
而这正是《演义》读者最熟悉的登场方式。

### 5.1 锚层（固定，正史）

水淹七军 → 威震华夏 → 曹操议迁都 → 陆逊谦书／吕蒙称病 → 擅取湘关米 →
徐晃救樊 → 白衣渡江 → 糜芳降 → 麦城 → 临沮。
锚层的日期与结果即正典圣经 §10.A，一字不挪；对应 `mainline.json` 的 `anchor` 字段。

### 5.2 闲笔层（抽样，边缘史实人物）

- 人物池（`content/base/historia.json`，手作，每条一两句史笔＋出场条件）：
  董昭（射书之计）、蒋济（谏迁都）、满宠（沉白马）、赵累／王甫（樊城城中）、
  潘璋／马忠（西道上）、虞翻（说士仁的书）、胡修／傅方（降于羽者）、
  麋竺（成都的面缚）、邓玄（一封假信）、习珍／樊伷（不降者）、吴范（观气者）……
  首批二十人，逐批补。
- 抽样：调用方注入种子 RNG，每日 0–1 人，一局至多五六人。
  **不触锚律：闲笔写"这个人此刻在做什么"，不写任何锚事件的日期、结果与在场。**
  董昭可以献策，潘璋可以在路上——历史不因闲笔改一字。
- 闲笔与玩家的交织：闲笔触发条件可引用玩家状态（持有 #058 → 满宠条目出现；
  素徽线揭示 → 渡口方向多一句闲笔）——**史书的角落照见你的作为**（§7.2）。

### 5.3 传闻层（市语体）

既有 `broadcasts` 池（露布／童谣／寻人）并入历史轴渲染：
大事条目＝锚一句＋闲笔至多一条＋传闻至多一条，史官拼盘成文。
童谣同源（誊抄所）的暗线原样保留——历史轴本身就是层 2 的猎场。

## 6. 高亮标注协议

### 6.1 标记语法（数据层，六类）

```
[[人|关羽]]   人物——朱砂
[[地|水门渡]] 地名——黛青
[[物|#039]]   物品/文档——鎏金（hover 出物名）
[[事|白衣渡江]] 事件——玄墨加粗
[[决|还师]]   决断/分支——绛红衬底
[[伏|断弦的琴]] 伏笔——暗金下划线（回收后变色，§7.1）
```

### 6.2 用法纪律

- 手作文本与 LLM 输出同律；正文体里每段标记至多两处（多则噪），
  大事轴条目每条至多三处。
- 标记是**指路**：`地`指向可去之处，`物`指向可寻之纸，`伏`指向已埋之钩。
  无指向价值的名词不上标——高亮的稀缺性就是它的视力。

### 6.3 校验（registry）

`人`须在闲笔人物池或正典名单；`地`须在 locations／map；`物`须在 docs／items；
`事`须在锚层白名单；`决`须在结局/或然名单；`伏`须在伏笔登记表。
解析器（内核 util＋前端渲染共用 schema）不认的标记即拒——
**标不出＝不存在**，防幻觉从防高亮开始。

## 7. 交织：伏笔登记与"锚不动，纹理动"

### 7.1 伏笔登记表（mainline steps 的 `hooks` ＋ 既有体系的互认）

- 步可埋伏笔：`{ key, hint }`。key 三种落点：`doc:#id`（纸）、`flag:xxx`（事）、
  `seal:xxx`（真相）——与既有文档/旗标/封印体系一一互认，不新造状态。
- 回收：玩家轴或事件系统兑现该 key（拾到纸／触发旗标／揭封印）→
  历史轴上该伏笔标记由暗金转为已回收色。
- 兰台跨局：伏笔回收状态入兰台（"这一局埋下的、那一局收到的"），
  呼应 EC-04 故地重游——**伏笔是跨周目的的针脚**。

### 7.2 玩家作为投影为闲笔（纹理动的机制）

- 玩家的重大作为（封印揭示、或然触发、声望档、白翎处置、卖纸给鲁舟）
  生成"投影闲笔"：不指名，只留痕——
  "有人在渡口听了一夜的箭"（素徽线）、"北津的门轴干得发涩"（惨胜）、
  "城南有人家夜里点灯到四更"（玩家长期守夜）。
- 投影闲笔经史官拼入大事条目，与正史闲笔同墨；同一触发在舆图上再落一痕（§3.4，双显形）——
  **玩家的故事长进历史里，历史却一个字没改。** 这是两线交织的本体。

## 附录A 批次〇文本定稿（卷首 · 围城）

> 定稿即 `prelude.json` 之 `heaven`／`siege`；文风遵圣经，一字入档前不再改动措辞（数值与锚点除外）。

### 幕一「天下」（三段＋转轴）

建安二十四年，秋。

要讲这一年的江陵，先得讲天下。天下讲起来不长。黄巾死了，董卓死了，袁绍也死了。官渡一把火，北方姓了曹；赤壁一把火，南方拆成两半。皇帝还在许都坐着。坐了二十几年，坐成一枚牌位。汉室还在——各人叫各人的忠。

然后是这一年。七月，[[人|关羽]]围樊城。八月，汉水暴涨，平地水数丈。[[人|于禁]]七军皆没，三万人降，[[人|庞德]]死。捷报入城那天，满城香案。[[人|曹操]]议迁都，以避其锐。史书写到这里，都是真的。史书没写的，从这个秋天开始。

### 幕二「围城」（两段）

大胜的第三天，城门开了最后一次。降卒进了城：泡发的，挤伤的，三万张嘴。[[地|南市]]的米价翻了一倍。露布栏的捷报写到第七篇，一篇比一篇近，一篇比一篇响。

江陵没有敌人。江陵是胜利者的后方——是仓，是账房，是[[事|大胜]]要吃饭的地方。渡口封了，旱路征了。这座城自己围住了自己。

### 合流段（通用版，接 p2「写名上墙」之前）

三条路，一扇门。[[地|橘里九号]]，里坊深处，堂屋一张[[伏|断弦的琴]]。谁先推开的门，后来成了家里唯一的争论。名字写在门后的墙上。约定只有一条：夜里听到动静，先叫名字，再出声。

## 附录B 前传样张 ×3（金样本，定文风基准）

### 素徽 · 断弦

素徽，乐户，琴师。教坊的册子上有她的名字，名字后头压着一个「籍」字——乐籍，良民册外的另一种册子。征乐户的文书下来那年，名册上不知怎么成了哥哥的名字。抄错了，都这么说。哥哥素伯去江边做了屯候鼓手。临走他说：鼓打得好，也是一种活法。她信了。

三个月前，哥哥「[[事|阵殁]]」。同一个月，教坊来人，说她的乐籍除了，缴费栏空着，办好的人没留名。两件事隔七天。她没敢往一处想。

橘里九号是兄妹的旧宅。哥哥住这边，她住教坊。她回来推开门，堂屋一张琴，断了一根弦。她没有续弦，也没有动屋里任何一件东西。她住了下来。

### 逄灶 · 半面台

逄灶，烽燧卒。建安十三年，[[人|曹仁]]弃城那一夜，[[地|北津台]]举火，他守台，挨了一棍。腿留下了病，台塌了半面。后来太守府换了三茬，没人修台，也没人裁他。他就留着——塌着的台也是台，他每天绕着走一圈。

省话。城里人当他是哑巴。更鼓的拍子他一听就懂：城里几更，城外几里出了事，鼓不会说谎。这个秋天的鼓声越来越齐。齐，不一定是好事——太齐了，像一个人敲的。

### 文简 · 半本账

文简，塾师，退了。教了三十年书。最后一课停在八月：学生散了，有的跟家走了，有的被征发了。他收起戒尺，把没写完的里坊账装进书箱——谁家借了谁家的盐，哪个孩子的束脩还欠着半匹布。账要有人记。

女儿嫁在公安，江那边。最后一班渡船那天，他在[[地|北津门]]的队伍里排到一半，回头去捡一册学生落下的字帖。队伍走完，城门关了。他怀里从此有两样东西：那册字帖，半本账。他等城门再开——等成了习惯，习惯等成了这个秋天。

**单句版（`line` 字段定稿，二周目幕三用）：**

- 素徽：素徽，琴师。哥哥「阵殁」那月，她的乐籍被人除了名；她住回旧宅，没续那根断弦。
- 逄灶：逄灶，烽燧卒。北津台塌了半面，他守着——塌着的台也是台。
- 文简：文简，塾师。城门关上前，他回头捡了一册学生的字帖；此后他等城门再开。

## 附录C 前传四拍模板与十二人困局要点

**模板：** 来处（一技一业＋两件实物）→ 裂缝（knot 之现象，不写真相）→
困局（一个被截断的具体动作）→ 落点（收进橘里九号，一句收束）。
每段 150–250 字；裂缝拍禁止出现任何封印层事实（§2.3 前传不泄封印律）。
