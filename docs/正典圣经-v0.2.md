## 1. 三次易主年表（208 / 215 / 219）：门从里面开

江陵三面环水，控江汉之会。谁占江陵，谁就捏着半个荆州。
所以每过几年就有人来要这座城——**而这座城从来没有被攻破过。**

| 年 | 名义上的交战 | 实际 | 门的开法 | 城里的说法 |
|---|---|---|---|---|
| 208–209 | 周瑜 vs 曹仁 | 相持岁余，曹军粮尽援绝，**弃城北还**。周瑜打了一年，没打进去 | 从里面关上的（弃守） | "周郎啃不动江陵" |
| 215 | 吕蒙取三郡 | 零陵太守郝普被挚友邓玄之一封谎信说开城门——信上说刘备在汉中被围（假的） | 从里面开的（一封家书体的假信） | "郝普是让人骗开的" |
| 219 | 吕蒙 vs 糜芳（本局） | 商船白衣，屯候尽缚；糜芳潜相和已久，开城 | 从里面开的（一把火 + 一封信 + 一条备好的退路） | 老人只活到讲古的年纪 |

- **"门从里面开"是本作暗线的总纹。** 水面叙事里江陵是坚城（关羽增筑城垣，城甚固）；
  水下真相：坚城的价值从不在于挡人，在于**卖个好价**。
- **41 日新义**：本局正典时间轴 D45 = 交割日（闰十月，江陵开城）；
  交割后第 41 日，关羽没于临沮（十二月）。城里人是事后才倒着数出来的：
  **城破不是结束。城破是将军死亡的倒计时。**
  这就是《第 41 天》在本卷的含义——你拼命活到的"停战"，
  是另一个人的死期第一天。
- **D41 讲古日**（内核事件）：老邻敲门，只说一句：
  "江陵城啊，从来不是被打下来的。十一年了，门开了两回，回回都是从里面。"
  （档案馆线索正式浮面。）

## 2. 水下总纲：盟约是租约，券局全相

### 2.0 一句话

**战争不是被打输的，是盟约到期没有续的。**

215 年的湘水之盟（以湘水为界，东属吴、西属蜀）是和平的租约。
租约里没有"自动展期"四个字。219 年，无人续期。
不是谁破坏了和平——是和平到期了，而全江陵只有一个守藏吏知道到期日是哪天。

### 2.1 券局：四张脸与一纸券约

**券局不是密谋小集团，是一条合规的商路。**
江汉之间，米、盐、药材、军械、木料、情报，过三方的津戍，凭的是符传。
符传每四十日一续，无人叫停即自动展期——**商路的船不停，战争就断不了奶**。
它由三张看得见的脸和一纸无脸的券约组成。

#### 「东主」牙行的主人 —— 三栏账的账房（从不上台）

宛（魏）、柴桑（吴）、成都（蜀）三栏账，同一批货，三个买主。
他不恨关羽，也不爱孙权；他只怕一件事：**有一家赢**。
一家赢了，三栏账就只剩一栏。券局的祖训不是"帮谁"，是"**桌上不能少买家**"。
玩家在物证里只能见到他的花押——一个"券"字的半边。

#### 「签字人」糜芳 —— 南郡太守（从不上台）★改黑（v0.2 定稿拍板）

正史给了他两句话："南郡城中失火，颇焚烧军器。羽以责芳，芳内畏惧，权闻而诱之，
芳潜相和。"以及《麋竺传》的四个字："**私好携贰**"。
我们的水下把这两句焊在一起：**他早就和吴暗通，火是他自己授意点的。**

- 火不是券局烧给他的台阶，是他向券局下的订单（经长史之手、券局之钱、
  仓吏之火折子，三层手）。烧掉军械 = 烧掉守城的资本 = 烧掉自己的退路。
- 他要的不是"惧"，是**理由**："芳内畏惧"是他写给后世的封面。
  后世读到的糜芳是个被吓破胆的懦夫——懦夫在史书里是可以活的，
  卖家不行。**他连自己的罪名都提前改好了。**
- 所以他不只是清算人——清算书是他自己写的。
- 对照组（正史）：哥哥麋竺在成都是真忠，面缚请罪，惭恚而卒。
  糜家不是两边下注——是被兄弟两个各自的选择劈成两半。
  哥哥的命抵不了弟弟的账，但"商人家族全族皆奸"这个读法，正史自己就否了。

#### 「守藏吏」文修 —— 府库、符传空白检、死档的保管人 ★本卷最大灰度

江陵府库的守藏吏。刘表、曹操、刘备、关羽，四易其主，他没换过桌子。

- 他的信（他对自己说的）：**有人记账，战争才有底线。**
  没有他的印，征用会在巷子里用刀进行。他相信自己是在"限制伤害"。
- 他的罪 ①：215 年湘水之盟的盟书是他誊的。草稿里本有一句
  "**期满无异议，盟约自展一年**"——被朱笔划掉了。他看着它被划掉的。
  从此只有他知道：和平是租来的，租期四年。
- 他的罪 ②：三个月前，屯候更籍的副本从他手里"借"出去过一夜。
  还回来的时候简册是湿的。他没问。§7.7
- 他的罪 ③：交割前夜，他盖了最后一批符传——给商路的人、士族的家眷出城用。
  每一张都合规。
- 他现在做的事：里社施粥、收死档、指驿亭（死信库是真话——
  他真的希望这座城没说完的话被读到）。
- 玩家能在主线里见到他（府库里社）。他是全游戏**唯一一个每次敲门都在的共谋者**。
- 破绽只有两处：他从不核符传的编号段（券局供应，不需要核）；
  听到"麦城"两个字时，他会把手里的简册放反一次。

#### 「券约」—— 不是人，是台机器

符传、粢引、券书、续期条款的总和。它没有脸——这正是层 3 结构的一部分：
**最重的罪找不到一个可以恨的人。**

### 2.2 机器怎么转（玩家可拼出的流程链）

```
三方幕府下单（要荆州 / 要江南 / 要钱） → 券局三栏记账
鲁舟的船走三方津戍（符传自动续期） → 武器/药材/米两边三边卖
文修保管符传空白检（府库） → 更籍"借"出一夜 → 白衣船按更籍收屯候
老纪誊露布与童谣（誊抄所） → 城里听到的战争是套语版
军仓的火（§7.2） → 糜芳的惧 → 权诱之 → 交割
```

## 3. 交割日全相（闰十月那一夜）

本卷的可玩高潮。**史实结局的终点、两条或然的检验场。**
当夜内核时间轴 D45，内核不掷任何骰——一切按正典走位，玩家的位置只决定
**看见多少、带走多少、有没有让北津台响起来**。

- **黄昏**：江津码头比平时多了七条"商船"。吃水很深——商船不装货装人的时候，
  才是这个吃水。（鲁舟今夜不来摆摊。他的船在那七条里。）
- **一更**：沿江屯候依次沉默。没有鼓声告警——更籍在手，收台的人知道
  每座台几个人、几更换、谁睡得沉。**素徽若在队：她能听出沉默的顺序**
  （从下游往上游，一座一座，像有人顺着琴弦捋过来）。这是她的终局听辨。
- **二更**：公安方向无火光（傅士仁已开——虞翻的信前天到的）。
- **三更**：北津门开。没有撞门，没有喊杀。城门的轴上过油——
  太守府的长史提前三天让人上的（物证：门轴的油，§7.2 火线的延伸——
  油和火，出自同一只手）。
- **四更**：吕蒙入城，约法三章：不得干历人家，有所求取。
  一名吴卒取民家一笠覆官铠，斩。垂涕而斩。城里反而安静得奇怪——
  **最有礼貌的占领，是最有效的占领。**
- **五更**：家访开始。羽军将士的家眷挨家被"问候"：问寒暖，送米，问有没有信要捎。
  礼貌，周到，不收钱。**从这一更起，樊城下那支大军开始自行蒸发。**
- **同时**：府库交割。文修交出钥匙、符传空白检、死档。
  于禁从降卒营被"接收"——交割清单上的一项，和粮、药、符传印在同一列。
- **玩家可见的尾声**（D61 晨报）："没有攻城。天亮了，城是别人的了。"

交割日之后（D61+，短余波）：羽军家属区排队捎信的长队；
商路连夜收摊；文修把出借登记册烧了——或者没有（§7.7 分支）。
**D86 尾声快剪**：交割后第四十一日，临沮。雪。麦城出来的十几骑，章乡。
（玩家什么都做不了。这一天永远属于正史。）

## 4. 烽火与白翎：三任射手，一个鼓手 ★本卷情感主梁

水门渡的"白翎"是关羽军的心理战品牌：守渡神射，夜里听声放箭，箭箭咬人。
真相比品牌简陋，也比品牌狠。

- **第一任：素伯**，乐户出身，江边屯候的鼓手，素徽的哥哥。
  征发名单上是妹妹的名字（乐户征为营伎）。他拿着征书去替妹妹报到，
  登记官抄没抄错名字，永远没人知道。
  他先做了屯候鼓手——烽燧卒，管鼓，也管**更籍**（沿江屯候的名册与更次）。
  三个月前，他把更籍的抄件和鼓语（烽鼓的信号节奏）卖给了券局。
  价码不是钱：**妹妹出乐籍**。他知道自己卖的是什么——
  卖的不是纸，是将来某一天这座城的门。
  军正查出更籍外流，他一个人顶了全部，没供出券局——
  券局的话：你顶罪，你妹妹除籍照办。
  他被军法处置，对外称**阵殁**。同月，素徽的乐籍被一位"好心官吏"除掉了。
  她至今不知道是谁办的。
- **第二任**：军中发现"白翎"有用——人活着，节奏留下。
  一个老屯卒照鼓谱放箭。干了两个月，酗酒离职。
- **第三任（现任）**：农家子，识字不多，箭术平平。
  他拿到一页抄来的节奏表和三句话的指令："按这个间隔放箭，别问。"
  他不知道那节奏是一支挽歌的小节线（《蒿里》——送葬的曲子，
  哥哥改的：放箭的间隔要像呼吸，第四小节前偷半口气）。
- **素徽线的终极一击**：她听出来的不是哥哥回来了，
  是**换气的地方不对**——哥哥在第四小节前偷半口气，这个射手没有。
  她找到的不是哥哥，是哥哥的遗物：
  一页鼓谱残页（#028）、一纸除籍文书（#046，正典反转）、和半城的沉默。
- **三选择的伦理结构**（水门渡）：杀他（救偷渡的人，毁掉素徽）/
  绕行（渡口的箭继续）/ 把 #028 送到他手上（照死人鼓谱放箭的人看到原作者的笔迹，
  停火 24 小时——他第一次想知道自己在念什么。之后一切照旧）。
- **与主线的焊接**：素伯卖出的更籍 = 白衣渡江的通行证。
  正史写着"至羽所置江边屯候，尽收缚之，是故羽不闻知"——
  收得那么干净，是因为名册是买来的。
  **妹妹找哥哥的线，就是这座城为什么开门的线。** 两股拧成一股。

## 5. 誊抄所与老纪（回声站）★三合一确认

- **誊抄所**：府库街对面的抄手铺子。战前誊公文、讼状、家信；
  战时产品：①**露布战报**（城门露布栏的捷报——"大破""斩获"的套语，
  同一篇改日子）②**童谣**（城里新出的童谣，都是同一手好字——
  交割前的心理垫层："白衣来，城门开"不是预言，是预习）③劝降书的底本誊抄。
- **老纪**：誊抄所老书手。**白简的师父**（教他"字是有斤两的"），
  **逄灶的同期**（当年一个在屯候写更籍，一个在烽台举火——
  一个造信号的纸，一个造信号的火）。三合一，一个灰色人物压住两条暗线。
- 开战第一个月，券局给了他全城最好的纸笔和"你在保存这个城的声音"的说法。
  他是自愿的。他不是坏人——他是最贵的坏人。
  润笔收据（#044）夹在字纸篓最底下。
- 真结局夜（§8）：白简把铁证拍在他面前。他的终局分支（接触深度 + 内核检定）：
  **把铁证誊成百份，连夜贴满四座城门**（全城第一次看到没有套语的露布——
  这是真结局的"广播"）/ 他把字纸篓烧了。没有第三种——
  他的手在笔上，不在嘴上。

## 6. 正典 NPC 志

### 鲁舟（船牙）
- 券局物流网最末端。他的"逢双日泊船"= 商船在津戍的交接期（太准时——
  围城里的准时是特权，多周目后这是他的破绽）。
- 他高价收文档（E-09，8 点收纸）= 替券局回收证据。但他的暗账：
  上交的里掺着他熬夜仿的赝品——赌城里人读不出更籍和假更籍的区别。
  他救下的证据比他主人知道的多。**他是最末端的赎罪者，赎罪方式是拖延。**
- 他知道全部。入桌结局（§8《出江陵记》）里他把提议带给玩家时，手在抖：
  他见过接受的人后来去了哪。
- 交割日黄昏，他的船在那七条"商船"里。这是他的正典位置。

### 杜仲（降卒营医棚主事）
- 不知情，但离真相最近的人。#021 伤兵簿是她偷记的，写在药方背，
  缝在医棚的席子里。
- 双方都收、只看伤情——208 年疫营那夜之后立的规矩（辛夷线，§7.4）。
- 她的危险：三万降卒（于禁的七军，正史：步骑三万送江陵）吃空了江陵的仓，
  疫病在降卒营里传。她知道这份簿子指着什么：捷报越频，粮越紧——
  **最大的胜利制造了最大的饥荒。** 她不走。

### 潘濬（治中从事）★正史真人，"三不"
- 正史写着：羽败，荆州将校悉降，**潘濬独称疾不见**；孙权遣人以床就家舆致之。
- 本作的潘濬：荆州政务中枢，什么都知道。
  三不：不配合，不告发，不出门。他不是任何人的卧底——
  他只是拒绝给任何一份券书当见证。
- 或然 B 的关键收件人：全城只有他接得住玩家的证据（§8）。
- 多周目追问，他是层 3 的人证之一（"你们要的账，我屋里有一屋子。
  但打开门的是你们，不是我。"）

### 于禁（降卒营）★正史真人，灰色活证
- 正史写着：七军皆没，禁降，庞德死。城里人也都知道：他跪了。
- 本作的于禁：降卒营最里面的一个老人，不辩解。
  玩家接触深了（杜仲引见 + 连续送药），他会说一次，只说一次：
  "三万人泡在水里。我站着，他们沉底。"——善意读法还是开脱，留给玩家。
- 他是层 2→3 的活证：樊城怎么没的（平地水数丈）、射进营里的帛书（§7.5）、
  以及"投降也是一种交割"这层真相。
- 交割日，他被"接收"。后日谈正典方向：他被送去吴地，又转魏——
  曹丕让人画了一幅画给他看。（玩家若有伊的因果账，后日谈多一句冷的。）

### 濠鼠（城濠水窦社群）
- 中立情报渠道，要吃的。他们知道水窦网，不知道券局——
  但他们捡过"长桌边开会的人"留下的东西：**封泥残片**（#060 方向，
  汉代的烟头）。军仓失火那夜，也有濠鼠捡到过一只火折子和一把赏钱（§7.2）。
- 火线的活证人住在濠里，要用三夜的吃的换一句话。

### 磨面妪一家（求助链）
- 纯人性锚点，无暗线。噪音是必要的。
  婆婆的腿肿了、黑了——是疫病后的坏疽，草药救不了。
  求助链的伦理内核：善举不保证结果（给药后她仍在 D+6 前后去世，
  儿子把最后一袋麸扛来道谢。退不退，是你的事）。

### 逃兵（无名）★回旋镖本体
- D3 前后敲门的逃兵（v_deserter）：麻鞋磨穿，蜷在门厅角落。
  他是樊城围中的羽军士卒，不识字。
  曹操按董昭之计把孙权密书抄件射进两军营地（正史，《董昭传》）——
  他捡了一张帛书，因为**帛值钱**。
  他不知道自己怀里那卷"卖钱的帛"是什么。
- 玩家 D3 关上的那扇门，是唯一能亲手拿出魏吴券书物证的活人。
  回旋镖链：v_deserter → #026 驿亭死信登记背面一行小字
  "拾帛一卷，不识字，问值几何" → 多周目识破：
  他的绑腿里缝着帛书残角（#061）。
- 收他一夜 = 风险 + 心情；赶他走 = 铁证 #039 从此只能走鲁舟的赝品堆碰运气。

### 不上台的人（正典纪律）

## 7. 水下支线八条

每条的格式：层｜三拍（裂缝→揭示→反转）｜物证｜人证｜分支出口。
全部支线在层 3 汇入同一句：**江陵不是被攻破的，是被交割的。**

### 7.1 鼓与箭（素徽 × 素伯）——情感主梁
- 层 2→3。三拍：#028 鼓谱残页（橘里九号地窖暗格）→ 水门渡听出节奏 →
  三任射手的轮换名单（#031）+ 除籍文书（#046）。
- 物证：#028、#031、#046。人证：素徽（正典钥匙）、老鼓手（第二任，酒醒后）。
- 分支出口：水门渡三选择（杀/绕/送谱）；
  **或然 A 的种子**：素徽线 ≥ 揭示拍是交割夜"北津台的鼓"行动的前置。

### 7.2 火（纪南大仓）——交割的第一级台阶
- 层 2→3。三拍：大仓失火（D21-30 局势事件）→ 火场勘验（#058：
  火起于库内三重，非外焚；门轴上过油）→ 放火人=被券局买通的仓吏，
  事后灭口沉濠（濠鼠的活证人 + #060 封泥）。
- **反转拍（改黑后）**：仓吏的上线不是券局的牙行，是太守府的长史——
  火是糜芳自己下的订单（券局只是收钱的承包商）。
  同时浮出第二层物证：北津门轴的膏油与火场的膏油是同一罐。
  **火与油，出自同一只手：守城的人，就是开门的人。**
- 物证：#058、#060、门轴的油、（反转拍）长史手令的残牍 #063。
  人证：濠鼠、石大（救火闻出膏油）、大柯（看出仓门榫卯是拆的不是烧的）。
- 分支出口：D30 前勘破 + 证据交潘濬 → **或然 B 的种子**：
  潘濬不动人，只动纸——他把勘验文书"照例"抄送军正与城门候，
  第二把火被截、长史被盯死、门轴的油没了。
  **或然 B 拆的不是糜芳的心，是他的机关**（他照样想卖，只是门没了）。
- 主题：火不是为了烧军械，是为了把"芳内畏惧"四个字烧得可信。
  正史有"权闻而诱之"——我们把"惧"的来处点亮，发现它是自焚的烟。

### 7.3 符传（薄姑 × 文修）——"战争是被办理的"
- 层 2→3。三拍：薄姑清点时发现 17 道符传的编号段不属于军需曹 →
  编号段的纸是府库的纸（文修的出借登记 #059）→ 那批符传的流向：
  白衣船的七条船，每张都合规。
- 物证：#033 鲁舟流水（三栏）、#052 券书残页（自动续期条款）、#059。
  人证：薄姑（正典钥匙）、文修（多周目对峙）。
- 分支出口：层 3 主入口之一；薄姑赎罪线终点 =
  "券局不是几个人在签字，是几百只像她一样的手。"
- 与大柯的门版对峙（人物设计-v0.2 §4.10）：429 枚检署里有一枚征走的是他家的门。

### 7.4 降卒营（杜仲 × 于禁 × 辛夷）——胜利的账单
- 层 1→3。三拍：降卒进城，米价翻倍（层 1 体感）→ #021 伤兵簿：
  溺伤、疮疫、箭簇有吴制 → 湘关粢引（#047）：羽以乏粮擅取湘关米（正史）——
  取米是困兽之斗，米道是券局递过去的绳。
- 物证：#021、#047。人证：杜仲、于禁、辛夷（208 疫营的回声）。
- 分支出口：捐药/带话的心情线；于禁的一段话（层 3 活证）；
  杜仲线的危险升级（她的簿子被人问过价——券局收纸的手伸到医棚）。

### 7.5 死信与帛书（逃兵 × 驿亭 × 上庸）——救兵永不到
- 层 1→3。三拍：驿亭死信库（#014 纯人性家书）→ #026 登记背面小字 →
  逃兵的绑腿（#061/#039：魏吴券书抄件）。
- 物证：#014、#026、#061、#039。人证：逃兵、驿卒阿走（正典钥匙候选）。
- 上庸的信：关羽连呼刘封、孟达发兵（正史，"辞以山郡初附"）。
  玩家可把一封没送到的信送往上庸方向（驿亭线，三日往返）——
  **信送到了，兵仍然不来。** 残酷是正典：或然也救不了所有人；
  但刘封的"不来"从此有了一个见证人（后日谈变化）。
- 分支出口：铁证 #039 的人证链；"救兵将至"传闻循环的层 3 解答。

### 7.6 露布与童谣（白简 × 老纪）——剪辑版战争
- 层 1→3。三拍：白简看出两篇捷报是同一篇改的（削痕）→
  童谣同源（同一手好字）→ #045 誊抄所底稿 + #044 润笔收据。
- 物证：#045、#044。人证：白简（Q≥8 判读）、老纪（终局对峙）。
- 分支出口：真结局的"广播"执行人（老纪的百份露布）。

### 7.7 府库与出借登记（文修）——租约的到期日
- 层 3 核心。三拍：里社施粥（善的面）→ 他从不核符传编号（破绽一）→
  #026 湘水之盟誊抄底本：草稿里被朱笔划掉的"自展一年"条款 +
  #059 出借登记：更籍副本借出一夜，归还时湿过。
- 物证：#026、#059。人证：文修（唯一每次敲门都在的共谋者）、潘濬。
- 分支出口：交割后他烧不烧那本出借登记（玩家可干预：替他把登记留进死档——
  档案馆入"这城没烧掉的一页"）；层 3 显形后的对峙场景（封印场景）。

### 7.8 城郊旧垒（208 年的骨头）——噪音与骨殖
- 层 1 + 纯人性。三拍：拾荒者的圣地与坟场 → 十一年前的箭镞和今年的是一个制式
  （层 1：兵器制式的冷知识）→ 一具抱着琴的骸骨（无暗线——
  就是十一年前的一个乐师。噪音是必要的）。
- 地理说明：208 年周瑜攻江陵岁余，城郊旧垒带是那一年的战场遗址，
  夜间可步行往返。**长坂（当阳）不在夜行半径内**，长坂的骨头留给别传
  《长坂拾遗》（长线体验-v0.2 §3.4 CH-05）。
- 物证：旧箭镞、断戟（高价值战利品）。人证：无（死人不开口）。
- 分支出口：无暗线出口。这条线存在的意义是让玩家想起：
  不是每一具骨头都欠着一个真相。**有些骨头只是骨头。**

## 8. 或然点与野史馆

### 8.0 三类结局架构

| 类 | 名称 | 频率 | 内容 |
|---|---|---|---|
| 史实结局 | 《开城》 | 大多数局 | D45 交割，D86 麦城。你活了或死了，历史没有眨眼 |
| 或然结局 | 《麦城得脱》《惨胜》 | 稀有（几十局一遇） | 交割仍发生（A）或被推迟（B），但某根线被你剪断或接上 |
| 真结局 | 《还师》 | 最深条件 | 交割没有发生。你知道得够多，还跑得比船快 |
| 黑暗结局 | 《出江陵记》 | 隐藏 | 券局买你的铁证，换一条船 |

### 8.1 或然 A《麦城得脱》
- 前置：素徽线 ≥ 揭示拍 + 逄灶在队（或北津台已修复）+ 知晓度 Q≥8。
- 行动：交割日当夜的夜访链：潜至北津台 → 修台（逄灶）→ 举火 →
  按#028的鼓语击鼓（素徽）——消耗当夜全部时间槽 + 三段检定链。
- **v0.2 实现状态（已落地）**：交割前夜内核确定性注入「交割前夜：北津台的鼓」
  （无骰，满足即触发）；选"上台"后黄昏指派素徽夜访北津台——台基 → 举火 → 击鼓
  三段链（s_beacon_1/2/3，鼓认人：非素徽上台则断在第三拍）。逄灶开局即识北津台，
  揭示拍之后全图可去。
- 结果（正典）：樊城大营早六个时辰知道。**只早六个时辰。**
  关羽从麦城出走时多了一夜的先机——走房陵，得脱。
- 野史（史书体，冷）："建安二十四年十二月，羽自麦城走房陵，得脱。
  吴尽得荆州。"——后附一句正典批注：
  **你救下的不是荆州，是一个人的命。这座城的交割一天都没有推迟。**
- 设计意图：或然不是爽文。城照样开，人照样死，
  只有雪里的十几骑变成了十几骑活口。

### 8.2 或然 B《惨胜》
- 前置：火线勘破（#058 + 濠鼠活证 + #063 长史手令）+ D30 前证据交潘濬 +
  潘濬信任弧 ≥ 共事。
- **v0.2 实现状态（已落地，渠道代偿）**：潘濬不进地点卡（他闭门不见），
  交付走里社渠道（church 声望 ≥1 作为代理门）；濠鼠活证已随城濠水窦地点卡并入前置
  （中间人脚本卡 s_sewer 的"问大仓失火那夜"选项，需先读过 #058）。
  内核效果：交割日 +6（endDay 与 forceEndDay 同移），结局「惨胜」。
- 结果（正典）：潘濬不动人，只动纸——勘验文书照例抄送军正与城门候，
  第二把火被截、长史被盯死、门轴的油没了。**糜芳的卖心一分未减，
  但他的机关被拆了**：开城推迟六日。吕蒙只能围。关羽还师，与吴军战于城下——惨胜。
  城守住了。守城的人换了一茬。
- 野史："建安二十四年十一月，吕蒙围江陵。关羽还师击之，吴人退。
  是岁，江陵大饥。"——批注：**守住的城，和开过的城，账本不一样，死人一样多。**
- 与或然 A 可叠加（独立种子）；叠加时野史变体《另一种三国》——
  全游戏最稀有的一页。此页不写纪事，老年阿禾只批一句：
  "那年秋天，门没有开，将军没有死。后来他们还是死了——不过，是后来的事。"

### 8.3 真结局《还师》（灯塔行动的本卷形态）
- 触发：层 2 已显形 + 当局集齐三铁证（#039 券书抄件 / #045 誊抄底稿 /
  #055 更籍抄件）+ 逄灶在场（或北津台已修复）+ 一名"知晓者"存活。
- 路线：D40 前，把证据送过三道津戍到樊城大营
  （夜访链终局：北津台 → 汉水 → 羽军前哨；强攻 / 买通 / 白简伪造符传 /
  鲁舟最后背叛券局——四种过法，价不同）。
- 老纪的百份露布（§5）在全城贴开的同时，羽军收兵。
  连锁三日：吴船退、券局连夜收摊、文修的登记册、于禁的降卒被接管。
  **交割没有发生。但荆州没有因此得救——它只是继续被战争使用。**
- 后日谈升级为全城后日谈：不止你的小队，还有文修、杜仲、鲁舟、
  濠鼠、潘濬、于禁，甚至白翎第三任——他的结局由你在水门渡的处置决定。
- 野史：《还师》一页。批注：
  **"这一版历史没有发生。但未必没有被发生过。"**

### 8.4 黑暗结局《出江陵记》（入桌的本卷形态）
- 持有 #033 或 #052 时，鲁舟在某个黄昏带来提议：
  **券局买你的证据**——一条船 + 三张符传（全家出城），代价是沉默。
- 接受 → 黑暗结局：「你活着离开了江陵。江陵没有。」
  档案馆解锁特殊词条（野史馆一页无字的白帛），
  且此后**每周目**商路都认得你（新开局的隐藏事件：鲁舟见你第一面就说
  "船还给你留着"。）
- 拒绝 → 鲁舟此后不再泊船，交易渠道变窄（真实代价）。
- 江鳅在场时提议变双份（"他们有位置给你"）——他的入桌抉择是第二种走法
  （人物设计-v0.2 §4.11）。

### 8.5 野史文体规范（EPI 约束，防爽文化）
- 一律史书体：纪年 + 月 + 一行事实。冷，短，不安慰。
- 每页野史必有正典批注一句（老年阿禾的笔迹，人物设计-v0.2 §4.9）。
- 野史不写"后来天下如何"超过三行——蝴蝶的翅膀不许扇成风暴。
  **或然的分量是那一个被改写的瞬间，不是新编的三国演义。**
