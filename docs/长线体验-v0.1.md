## 1. 不腻的解构

### 1.1 玩家为什么离开（疲劳分类）

| 疲劳类型 | 表现 | 对策归属 |
|---|---|---|
| 系统疲劳 | "又要点吃饭烧水" | 委托自动化（Z）、概述日（§4.4）、快局 |
| 叙事疲劳 | "这个事件我见过" | C 层生成、主题轮盘、别传解锁节奏 |
| 张力疲劳 | "闭着眼都能活" | 挑战语法、长夜局、历史学家难度 |
| 意义疲劳 | "活下来又如何" | 关系弧线（§2）、遗愿/时间胶囊（§3.3） |
| 完成感疲劳 | "档案馆 100% 了" | 表达引擎、合上档案仪式（§3.6） |

### 1.2 玩家为什么回来（五类回报）

1. **不知道的**：新角色、新地点、新真相（有限，须排节奏）。
2. **没做到的**：结局、挑战、别传（有限但可再生——挑战语法）。
3. **没玩过的**：不同组合/道德/策略的身份玩法（组合爆炸）。
4. **新产生的**：C 层事件与涌现戏剧（无限但须有界）。
5. **自己的**：回忆录、时间胶囊、打法风格被城市"认出"（表达复利）。

前两类是**内容**，会被耗尽；后三类是**系统与自我**，才是长尾。
本设计的所有机制，最终都在把玩家从 1/2 推向 3/4/5。

## 2. 玩家与城市的关系弧线（SA）

跨周目的真实元进度不是数值，是**这段关系**。档案馆进度是其可见刻度。

### SA-1 陌生者（第 1~4 局）
- 核心问题："我能不能活过这个冬天。"
- 内容：系统学习、第一次死亡、首批文档。
- 推进器：首新保底（NE-02）保证每局 ≥2 个新入档。
- 退出条件：标准难度活到停火一次。

### SA-2 居民（第 4~10 局）
- 核心问题："这条街、这些人，我认识了吗。"
- 内容：角色秘密、求助链全貌、邻居与商人的真面目、层 1 显形（D41 台词）。
- 推进器：城市开始认出你（EC-01 声望反应）。
- 退出条件：累计 8 份文档，层 1 显形。

### SA-3 知晓者（第 10~20 局）
- 核心问题："这场战争哪里不对。"
- 内容：层 2 真相、正典钥匙角色的专属线、别传①解锁。
- 推进器：封印揭示的跨局复利（同一个地点，带着不同知识再来，看到不同东西）。
- 退出条件：层 2 显形 + 三件铁证曾集齐过任意一件。

### SA-4 干预者（第 20~30 局）
- 核心问题："知道之后，我配得上它吗。"
- 内容：灯塔行动 / 入桌 / 沉默，战争级三选。
- 推进器：入桌与灯塔互斥的道德重量；知晓者难度加压。
- 退出条件：完成灯塔或入桌各一次。

### SA-5 守望者（第 30 局起）
- 核心问题："这座城市的故事，轮到我讲了吗。"
- 内容：回忆录、挑战、时间胶囊、白桦纪元变奏、遗愿清偿。
- 收束：**合上档案仪式**（§3.6）——游戏主动承认"故事讲完了"，
  并保持档案馆永远可重开。守望期没有新内容压力，只有表达。

## 3. 五台重玩引擎

### 3.1 新鲜感引擎（NE）

- **NE-01 未见池**：档案馆维护"尚未见过"的文档/遭遇/台词池。
- **NE-02 首新保底**：连续 2 局零新入档 → 下局新内容生成权重 ×2；
  仍零 → 下局必有一份未见文档被放置在可抵达地点（导演指令，保底不违反
  RND-08：只影响"放置概率"，不影响正典事实）。sim 断言：连续无新局 ≤3。
- **NE-03 揭示预算**：标准局新入档目标 2~5 项（对齐 KPI"每局文档中位数 3~6"）。
  多了泄底，少了白玩。
- **NE-04 节奏见 §8**：解锁内容按阶段排片，绝不提前。

### 3.2 表达引擎（EX）

- **EX-01 回忆录**：局终由 LLM 依事迹账本写 300~500 字第二人称文学体章节，
  经 N-02 事实校验，存入"回忆录"合集，可导出纯文本分享。LLM 离线走模板。
  玩家重玩的一部分动机是"写好这一章"。
- **EX-02 这一局的三件事**：内核按"戏剧分"（死亡/牺牲/铁证/千钧一发的事件权重）
  自动选出三拍 engrave 进档案馆该局页面；三件事同时是回忆录的骨架。
- **EX-03 身份玩法**：游戏不贴标签，但档案馆以"这座城记得"的口吻记录你的
  行为画像（守财/侠盗/商人/修士/猎人……按事迹账本聚合），
  不同画像触发不同 C 层提案倾向（编剧拿到你的画像作上下文锚）。
- **EX-04 自动化即精通**：委托策略（Z）支持导出/命名/复用；挑战维度之一
  是"最少手动干预活过标准局"——把琐事变成可炫耀的策略编程。

### 3.3 回响引擎（EC）——玩家成为城市记忆的一部分

- **EC-01 城市反应（反攻略机制）**：各锚点（教堂/医院/超市劫掠者/沟鼠/哨卡）
  维护跨局声望。反复对同一目标作案 → 该锚点在后续周目自适应（多了守卫、
  藏匿点挪了、态度敌对）；反复行善 → 互惠（预警、赊账、口信）。
  **边界**：只影响生成与态度，永不触及正典事实（RND-08 兼容：
  声望是"城市与你的关系"，不是历史）。
- **EC-02 时间胶囊**：任意结局后可埋下**一件物品 + 一句 ≤100 字的话**。
  后续周目该容器真实存在（标注"无名者的埋藏"，不点破是你）。
  上限同时 5 枚。零平衡影响（物品本来就是你的），纯情感装置。
- **EC-03 遗愿**：角色死亡（非全灭）时生成遗愿卡（如"安东未寄出的信"：
  下周目邮局出现这封信，可以替他送）。同时至多 1 张，3 局未清偿自动入档
  作"未完成"。报酬只有档案馆词条与一句回应，**绝不给数值**。
- **EC-04 故地重游**：每周目若开局住所随机到槐树街 21 号，
  墙上有上一任住客（你）的痕迹池——钢琴的修好程度、暗格是否被翻动。

### 3.4 挑战引擎（CH）

- **CH-01 挑战语法**：`阵容约束 × 资源约束 × 道德约束 × 目标约束 × 时限`
  的参数化挑战卡生成器（如"斋戒者：不偷不抢不吃肉""双烛：只有两张床"
  "黎明 55：D55 前完成灯塔"）。核心验证可行性标签（经济可行/需精确运营），
  保证不生成死局。
- **CH-02 本周的别列佐夫**：确定性周挑战——种子与约束由
  `hash(年-周, 内容包版本)` 派生，**无需服务器**，所有装同版本内容的实例
  得到同一道题。单机干净，联机无害。
- **CH-03 挑战记录**：本地通关册（完成日期/结局/三件事），无排行榜、无数字攀比
  （反设计 §5）。
- **CH-04 别传**（A 层手作内容，按 §8 节奏解锁，每段 20~30 分钟）：
  - **法比安的一周**（知晓其身份后解锁）：扮演行脚商五天——路线、进货、
    卖给谁、瞒什么；直达"入桌"道德的内部视角。
  - **灰雀的长夜**（狙击手线了结后解锁）：三夜狙击手叙事谜题，
    无生存经济，只有瞄准镜里的人心。
  - **塔玛拉的病房**（层 2 后解锁）：分诊小品，双方伤员、不足的药。
  每部别传都让主游戏的旧场景**事后变色**——这是最高性价比的重玩性：
  不换系统，换眼睛。

### 3.5 干预引擎（已由 GDD §12 覆盖，此处补两点）

- 灯塔/入桌/沉默三向的互斥存档（档案馆记录你"每次都选了什么"，
  SA-5 的画像素材）。
- **白桦纪元·黎明三天**（首次灯塔后解锁）：固定小队、只有三天、没有经济——
  广播之后、停火生效之前最凶险的 72 小时：藏好证据、劝住哗变、护住证人。
  真结局的"余味"不是过场动画，是一段可以重打余韵的短局。

### 3.6 优雅退场：合上档案

- **触发**：档案馆 100% + 灯塔与入桌各完成一次 + 回忆录 ≥10 章。
- **仪式**：档案馆首页出现"合上档案"——城市用你十局的三件事为你送行，
  回忆录装订成册导出，游戏明说："这个故事讲完了。别列佐夫会记得。"
  之后任何新局照常可开，但游戏**不再用新内容吊你**（C 层密度降半，见 §10）。
- **设计意义**：对抗完成感疲劳的最后手段是尊重，不是无限卷。
  诚实的谢幕本身是最强的回来理由。

## 4. 形态层：一局长什么样

### 4.1 局型（开局即选）

| 局型 | 时长 | 结构 |
|---|---|---|
| 围城切片（快局） | 20~40 分钟 | 15 天压缩战局或 D10~D20 切片，预设中盘状态 |
| 标准局 | 1.5~3 小时 | D1 起，30~45 天，完整弧线（默认） |
| 长夜局 | 2~4 小时 | 无干预强制 D60 终局，枯竭期全程 |

### 4.2 别传局：§3.4 CH-04。
### 4.3 白桦纪元：§3.5。
### 4.4 概述日（系统疲劳的解药）

- 快速模式升级：平淡日由叙事者一次性**概述**（一段文字交代三天），
  只在事件/状态突变处停下问玩家；概述文本同样入回忆录素材。
- "概述日"与"沉默日"（GE-07）共同保证：文本游戏的节奏阀门永远开着。

## 5. 反设计清单（永远不做）

1. **数值元进度**：不解锁更强角色/更多起始物资——知识是唯一允许的元资产。
2. **排行榜与公开攀比**：战争的死人不排名。挑战只有本地通关册。
3. **战斗通行证 / FOMO**：周挑战不设限时奖励，只是"这周的世界是这一份"。
4. **跳过键**：加速重玩 ≠ 尊重重玩。压缩靠局型（§4.1），不靠 fast-forward。
5. **正典随机化**（RND-08）：再缺内容也不拿暗线事实凑重玩性。
6. **让重复变快的机制**：我们不优化"刷"的效率，我们让每一刷有名字（EX-01/02）。

## 7. 与现有系统的整合约束

- **RND 宪章兼容**：NE-02 保底只改放置权重；EC-01 声望只改生成倾向与态度——
  两者都在"玩家-城市关系层"，不进入正典层（RND-08）。
- **GE 层协同**：EX-03 行为画像作为编剧上下文锚（GE-04 的合法锚源扩充）；
  合上档案后 C 层密度 ×0.5（GE-02 密度配置新增"守望档"）。
- **平衡 KPI 新增**：连续无新局 ≤3（NE-02）；挑战卡死局率 = 0（CH-01 验证器）；
  回忆录事实违规率 <1%（复用 N-02 校验）。
- **档案馆扩展表**：capsule / last_wish / memoir / persona / challenge_record
  五类新 archive_entry kind（技术架构 §6 表结构不变形，kind 枚举扩展）。

## 8. 节奏预算表（首新内容排片）

| 局数 | 必须出现的新东西 | 来源 |
|---|---|---|
| 1~3 | 每局 ≥2 新入档（NE-02 强保底） | 文档池浅层 |
| 4~8 | 三条求助链收束各一次；≥1 角色秘密 | 手作卡 |
| 9~12 | 层 1 显形（D41 台词+征用令） | 局势脚本 |
| 13~18 | 层 2 真相 ≥2 项；别传① | 封印档案 |
| 19~25 | 三铁证集齐路径打通；灯塔或入桌 | 正典 |
| 26~30 | 另一个战争级选择；白桦纪元；别传②③ | 正典/手作 |
| 31+ | 表达与挑战长尾；合上档案可触发 | 本文档 |

（排片是"保底不提前"：玩家比预期跑得快，系统不拦，但不透支后面的惊喜。）

## 9. 测试钩子

- NE-02：sim 断言随机策略下"连续零新局"最大长度 ≤3（万局采样）。
- EC-01：声望边界测试——同锚点作案 N 次后的生成差异列表恰为白名单允许项。
- EC-02/03：胶囊与遗愿状态机（埋设/发现/过期）单元 + 跨局 e2e。
- CH-01：挑战验证器单测（不可行组合必拒）；抽样 1000 卡走 sim 存活可行性标注。
- EX-01：回忆录事实校验复用 N-02 管线，评测集断言违规率。
- CH-02：周种子确定性测试（同内容包版本跨实例同题）。
- §3.6：合上档案触发条件的覆盖测试与"降密度"开关断言。

## 10. 待定问题（★）
