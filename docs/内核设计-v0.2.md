## 2. 幸存者系统（六轴 + 状态机）

六轴定义、饥饿 H-01~H-13、伤病 I-01~I-12、心情 M-01~M-14、疲劳 F-01~F-05、
受冻 T-01~T-06、成长 G-01~G-03 全部继承，仅以下条目有皮肤修订：

- **H-03** 进食：生食 +1（糙米/杂粮）；熟食 +2（炊煮）；**肉脯 +2**（原罐头位）；
  高级餐 +2 且心情 +1（老甑）。
- **H-06** 烹饪：炉灶，生食×1 + 柴×1 → 熟食×1，耗 1 AP（**老甑免柴**）。
- **H-07** 高级餐：**老甑专属**，生食×1 + 葵菜×1 + 水×1。
- **I-07** 医护加成：**辛夷**（或习得医护的阿禾）执行"治疗他人"时，恢复计数 +1 档。
- **I-10** 医棚路线：白天改为"护送就医"（耗 1 人全天 + 交易代价：
  裹创布×1 或 价值 10），当日伤/病直接 -1 级。
- **M-06** 嗜好：**江鳅（浊酒）、白简（蜜水）**：断供 >24h 每晨 -1；供给时 +2。
- **M-13** 特殊正向：续弦后首次鼓琴 = 全队 +3（仅一次）；《还师》露布当夜全队 +5。
- **G-02** 教学源：**老甑 / 辛夷 / 大柯 / 逄灶**（阿禾可学）。
- **T-04** 老弱名单：**文简**（及伤病 ≥1 者）受冻检定 40%。

## 4. 避难所（B）

橘里九号是一张**室内地点卡**，与夜间地点共用数据结构：

- **B-01** 初始开放：门厅、堂屋（断弦的琴）、灶间。
- **B-02** 封锁区与门槛：

| 区域 | 门槛 | 内含 |
|---|---|---|

| 阁楼 | 瓦砾 + 锁 | 望楼（观察哨：袭击预警 +1 判定）、旧衣（燃料） |

| 柴房 | 锁 + 破车（拆） | 杂件×6、铁件×2、膏油罐（燃料×2） |

- **B-03~B-08** 继承（白天搜自家、观察哨、防御值、门降级）。

  完好后 M-13。它是多次游玩后的情感地标（EC-04 痕迹池成员）。
