## v0.2「一页书」（2026-10-11 实施，替代 §4 的白天双栏与 §6 的部分形态）

玩家交互事实：选择题 + 自由自然语言。v0.2 据此把界面收成一页书：

- **主屏即书页**：双栏（叙事+档案侧栏）退场。正文栏收窄到 `min(880px)` 的纸页、40em 的读宽，
  叙事由句级浮现引擎（Typist）逐句落墨；**全部"世界停问"嵌进正文流**——
  晨报问题、急件事件、黄昏方案、夜访岔路、价目摊，与序章闪回同一副版式（`.ask` 卡）：
   hairline 上下线 + kicker + 选项序号章。时过境迁就合上（`.settled`：字留、选项收），
  书页因此始终读得回去。
- **状态浓缩成两行**：人物行=一人一签（姿态剪影+名字+至多两个状态词，左缘色阶=严重度），
  细看收进 hover/点按浮卡（原索引卡的仪表全部搬入浮卡，不占书页）；
  家底行=门板加固 + 七类家什计数 + 设施 + 夜里火柴，尾挂「细目」开抽屉
  （围城日历、这个家、物资图标格、夜访现状——**只看，不操作**）。
- **地图操作退场**：庇护所剖面图与夜访节点图从界面移除。
  开门/清废墟/走房间全部回到自然语言与岔路选择；剖面与路线图不再是游戏重点。
- **菜单=扉页**：右上角「菜单」（Esc 亦可）展开覆盖层——这一局（自动存档说明：
  每一笔都落在纸上，服务端每轮自动持久化）、没写完的局（一键续）、另起一局、
  封存这一局（两步确认，档案馆保留收获）、阅读设置（字号三档、落墨动效开关，存本机）、
  档案馆/管理入口、退出登录。报头由此瘦成一行：刊名 + 时日 + 菜单。
- **前文落库**：每轮的玩家落笔与叙事文本写入 `run_narration`（迁移 004）。
  刷新/换机/隔日续局时，前文按日分组瞬时铺回纸面（不重播笔迹），
  书签线「前文如上 · 翻到此处」接住下文；旧局没有落库前文时，用现状生成「前情提要」。
- **批注即原文**：点选项时，书页上的玩家批注写的是选项原文（而非「选1」），
  落库前文与玩家所见一致。

被本版取代的旧条目：§4 的"白天"高密度双栏（改为单栏书页+页眉境况带）、
§6 输入区对档案抽屉的依赖（侧栏不存在了，急件直接嵌正文）、
§2 中"庇护所剖面图"与"炭笔地图+火柴"作为**操作界面**的地位（火柴计时保留为行内小尺）。
§1 七原则、§5 排印层次、§7 档案馆、§9 反模式、§11 可访问性继续有效。

## 0. 两个必须先说破的陷阱

1. **字墙陷阱**：等宽等距的同质文本无限下滚，读者的眼睛三屏就"失焦"。
2. **聊天壳陷阱**：输入框+气泡+头像——那不是游戏，是套壳聊天软件。
   玩家会把界面读成"和 AI 对话"，世界的真实感当场瓦解。

所有设计原则都从避开这两个陷阱出发。

## 1. 七条界面原则（UIP）

- **UIP-1 界面是第四叙事者**。叙事者、裁判、演员、编剧之外，
  界面本身承担叙事：纸的质感、字的重量的、光影的时辰——每个像素都有战争的口音。
- **UIP-2 数在图里，事在文里**。状态用一眼可读的隐喻呈现（不出现 HP 条），
  事件用散文呈现；两者 hover 都能落到"人话"（"他两天没吃东西了"）。
- **UIP-3 屏幕随日子呼吸**。破晓/白天/黄昏/深夜四种版式，天气与季节改变边框状态。
  界面的节奏就是游戏日的节奏——布局本身防腻。
- **UIP-4 文本即地图**。叙事流里的名词（人/物/地点）是可交互的，
  悬停浮出"已知情报卡"。散文不只是读的，是可以进去翻的。
- **UIP-5 界面与庇护所一起生长**。D1 的界面是素净的；
  建了收音机才出现电台控件，清了阁楼才有观察哨窗口，修好钢琴界面角落才有琴键。
  **界面有自己的建筑史**——进度不需要进度条，需要的是界面长出来。
- **UIP-6 永远不像聊天软件**。无气泡、无头像、无表情。
  玩家输入排成**铅笔批注体**；系统回应按内容类型排成世界的产物（报/信/账/讣）。
- **UIP-7 动效必须挣到自己的位置**。默认克制；
  唯二的全局动效保留给炮击（轻微震屏+落灰）与严冬（屏幕边缘结霜）——
  因为它们是事实，不是装饰。

## 2. 界面词汇表（机制的拟物映射）

每个内核系统都有一个"世界的实物"作为界面形态：

| 机制 | 界面实物 | 说明 |
|---|---|---|
| 晨间结算 | **晨报**（报纸版式） | 头条=昨夜大事；状态变化是小字栏目 |
| 收音机 | **电台刻度盘** | 旋钮/频段；杂音状态字流过，锁定后"电波字体"播报 |
| 交易 | **地摊布 + 价值天平** | 货物摆在布上；天平可视化价值差（E-06 带内浮动看得见） |
| 计划模式 | **计划纸** | 步骤/耗时/检定点逐条列出，逐条勾选或划掉 |
| 夜间探索 | **炭笔手绘地图 + 火柴** | 房间节点图+战争迷雾；**时间槽=10 根火柴，行动烧掉一根**；声响=波纹指示 |
| 敲门事件 | **门** | 全屏门板叩响，开/不开/隔门问——门就是按钮 |
| 文档发现 | **档案卡** | 实体卡片入袋动画，卡片可"拿起"细读（档案馆同构） |
| 角色死亡 | **讣告** | 黑框排版，名字上"砖墙"（见档案馆） |
| 局终 | **长卷结算** | 后日谈从上而下展开，回忆录章节收尾装订 |
| 庇护所 | **横版剖面图** | **致敬原作的侧视小屋剖面**：房间/床位/炉火/加固一目了然，点击房间即行动 |

## 3. 状态呈现：人物与队伍

- **UIP-2 的落点**：六轴不用数字条——
  - 饥饿=餐盘隐喻（面包缺角程度）；伤=绷带角标；病=咳色斑；
  - 心情=**人物剪影的姿态**（直坐/低头/蜷缩）；
  - 疲劳=烛光变短；受冻=角标结霜。
  - 悬停任何人 → 一句人话状态（由 facts 驱动的模板，不是 LLM 现编，保证零成本零延迟）。
- **全家福站位**：队伍栏像一张合影——关系深的人站得近，
  抑郁者背对或退到边缘，有人死亡后照片留一个空位。
  **关系网不画线，画距离**。
- 状态变化即动画：心情跌落 → 剪影低头 + 一行斜体独白闪过（facts 驱动）。

## 4. 一天的五种屏幕（UIP-3 的落点）

| 阶段 | 版式 | 密度 |
|---|---|---|
| 破晓 | 报纸整页：头条+栏目+天气角标 | 中 |
| 白天 | 主操作屏：剖面图（左）+ 人物全家福（右）+ 叙事流（下/右折页）+ 库存带 | 高 |
| 黄昏 | **指派卡**：全屏聚焦——谁出门/带什么/谁留守，三步走完 | 低（仪式感） |
| 深夜 | 双栏：地图+火柴（左），叙事流（右，烛光光圈照明） | 中 |
| 概述日 | 极简居中：一段概述+几个突变点 | 极低（留白即节奏） |

- 阶段切换有 0.5s 的"翻页/天光变化"过渡，不是硬切。
- **密度跟随戏剧**：平淡日文字稀疏留白大，大事日排版收紧字距压深——
  排版的松紧是呼吸，读者的身体会先于脑子感到紧张（微节奏排版）。

## 5. 文本的层次与排印

- 内容类型分版式：叙事（衬线正文）/ 对话（引号+说话人名，不气泡化）/
  广播（等宽+杂音底纹）/ 系统（小型大写标签）/ 玩家输入（铅笔批注体）。
- 检定的"世界屏息"：不显示骰子（默认）——成功句利落收束；
  代价成功在句中插入一枚斜体代价（"——你的脚碰到了玻璃。"）；
  失败段戛然而止，留一行空白。透明模式才展示 2d6 明细小字。
- 中文排印工艺：避头尾、标点悬挂、段距代缩进、1.6~1.8 行距——
  对文字的尊重是这类游戏的第一观感。
- 已读快进/回滚：叙事流可回翻（事件溯源保证任意时点可重建）。

## 6. 输入区（反聊天壳的核心）

- 单行输入嵌在"桌面"里，配一支铅笔的隐喻；Enter 后排成批注体浮入叙事流。
- **动态 placeholder 即教学**：随阶段与情境换台词
  （白天"现在，你想做什么？"→ 深夜"黑暗里，你的下一步——"→ 谈判中"你想说什么？"）。
- 快捷建议=3~5 张小纸片（不是按钮），可点可无视；纸片内容来自导演 facts
  （"查看状态""把窗户钉死""问他要什么"）。
- 计划单流程：玩家说多步计划 → 弹出"计划纸"核对（可划掉步骤）→ 确认执行。
- 等待 LLM 时：不转圈。烛光轻晃 / 一句过渡小字（"风从窗缝里进来。"）——
  流式输出让等待本身几乎不可见。

## 7. 档案馆（跨局界面）

- 实体隐喻：**抽屉柜**（文档分类）+ **绳夹照片墙**（历代角色：照片+名字+一句铭文，
  结局不同边框不同：阵亡=黑角，灯塔=微光）+ **刻名砖墙**（"这座城记得"，
  你的事迹账本刻在砖上，越刻越满——长线体验 EX 的可视化）。
- 回忆录=可翻的书（跨页装订线排版），导出成册即纯文本。
- 档案馆首页的"合上档案"（长线体验 §3.6）：一书脊合上的动画，克制而郑重。

## 8. 界面的生长与痊愈（UIP-5 的落点）

- 组件解锁=庇护所建造：收音机/观察哨窗/钢琴键/蒸馏器刻度……
- 季节生长：入冬时整个边框材质变冷；停火前兆（炮声稀疏）数日后界面"松一口气"
  ——噪点减少，暖色回来一点。
- 灯塔结局后：框架的弹痕裂纹**仍在但不新增**——痊愈是叙事，不是重置。
- 跨局：照片墙与砖墙随周目变满——界面的历史厚度=玩家的投入可视化。

## 9. 反模式清单

1. 聊天气泡/头像/表情/打字指示三点。2. HP 式数字进度条与百分比。
3. 旋转 loading。4. 无意义微动效（呼吸/浮动按钮）。
5. 弹窗打断叙事（一切以嵌排版式进入叙事流）。
6. 声音默认开（音频见 §10，默认静音）。

## 10. 声音（可后置，宁缺毋滥）

- 白噪基底：雨/风/远炮（低频、低音量、可开关，默认关）；
- 语义音仅三处：叩门、电台锁定、火柴划燃。
- 钢琴单音预留给 M-13 首演与灯塔夜。

## 11. 可访问性

字号/衬线切换、高对比模式（纸底可换纯深色）、纯键盘可玩
（输入即万物，天然友好）、动效可全局关闭（尊重前庭敏感）、
读屏友好的语义标签（叙事流为 live region，流式文本分句推送）。

## 12. 验收与测试钩子

- **组件状态矩阵**：每个隐喻组件 × 全部状态值 → Playwright 截图基线
  （饥饿 5 态 × 心情 5 级 × …… 全枚举，防止"状态变了界面没变"）。
- 阶段版式切换 e2e：四阶段 DOM 结构断言（不是视觉近似，是结构切换）。
- 界面生长 e2e：建收音机前/后电台控件存在性断言（UIP-5 可测）。
- 名词词典：叙事流标记名词的 hover 卡内容 = 内核已知情报（不得超纲，
  与封印协议一致性同源测试）。
- 概述日/沉默日排版断言；动效全局关闭开关的功能测试。
- 视觉验收走评审流程（截图对比进 PR），不做无人值守的像素级回归。
