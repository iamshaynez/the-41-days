## 1. 总纲：四条操作性原则

1. **动词与名词承重。** 句子的重量放在动词和名词上，不放在修饰上。
2. **短句成拍。** 一句一拍，拍毕即止。长句是官府的特权（见 §5 露布体）。
3. **具象代抽象。** 不写"很冷"，写"水缸结了一指冰"；不写"非常紧张"，写"他把碗放下了，又拿起来"。
4. **留白即节奏。** 该断的地方断。读者补出来的，比写出来的重。

## 2. 免状语律（本圣经的刀法）

### 2.1 什么是要避免的状语

修饰动词或形容词的成分：时间（在夜里／三个月来）、地点（在江边）、
方式（慢慢地／悄悄地）、程度（非常／十分）、范围（都／全）、频率（常常／总是）。
白话文靠状语 glue 句子；古典文靠**拍**与**动词**承句子。

### 2.2 三条替代法

| 状语类型 | 替代法 | 例 |
|---|---|---|
| 时间、地点 | **独立成拍**：前置顿挫短语，单独短句 | ❌ 他在夜里悄悄地放下了船桨 → ✅ 夜半。他放下船桨。 |
| 方式 | **还给动词**：换一个自带方式的重动词 | ❌ 她慢慢地把药碾碎 → ✅ 她把药碾成霜。 |
| 程度 | **交给名词**：用一件实物承载程度 | ❌ 城里非常安静 → ✅ 城里静得能数出更滴。 |

### 2.3 额度

- 每句至多一个短状语，可删则删。删掉不改句意的，一律删。
- 否定词（不、没、未）与"也、又、还"不在此列，照常使用。
- **露布体例外**：官样文章的"案语腔"（"均已""一体""照得"）是讽刺用法，受 §5 露布体管，不受本律管。

### 2.4 正反例（本作场景）

| ❌ 白话状语句 | ✅ 本律句 |
|---|---|
| 他突然停下了手里的活，慢慢地转过头来。 | 他停了手。头转过来。 |
| 在雨中，他们沿着城墙悄悄地向北走去。 | 雨未歇。城垣下，北行，无声。 |
| 米价已经渐渐地涨得让人无法承受了。 | 米价又翻了一倍。缸见了底。 |
| 素徽突然认出了这个节奏，心里非常震惊。 | 三短，一长。素徽按住了你的手腕。 |
| 他终于在第三天的时候收到了那封信。 | 第三天，信到了。 |
| 老人非常感激地捧着那碗粥。 | 老人捧着粥，掌心贴着碗沿，不肯放。 |

## 3. 句律

- 常态句长 ≤ 20 字。超过 26 字的句子，正文体里不许出现。
- 一句一拍；两句可合，中间用逗号，合完仍须读得出两拍。
- 段落至多 5 行。段落之间允许一句成段——那是重拍。
- 排比与顶针是本作的骨法："等成了习惯，习惯等成了这个秋天。"

## 4. 词律

### 4.1 雅言词表（进，替换白话）

| 白话 | 雅言 |
|---|---|
| 吃东西 / 食物 | 吃食／饭食；具体到物：糙米、麦饼、肉脯 |
| 很长时间 | 许久／一炷香（市语体可用"半晌"） |
| 死了 | 没了／殁了／没挺过去（视语域） |
| 走了（离开） | 动身了／走了（皆可，配上下文） |
| 告诉 | 说与／捎话（市语）／告（公文体） |
| 开始 | 起了／起了头（"开始"限公文体） |

### 4.2 禁词表（退）

- **状态副词**：突然、忽然、渐渐、慢慢、悄悄、立刻、马上、终于、已经、正在、十分、非常、特别、居然、竟然、其实、简直、几乎、越来越（历史轴与正文体禁；露布体的"日渐"除外）。
- **现代腔**：进行了一次、做出了……的决定、情况、状态（名词义）、心理、压力（名词义，"军压力大"可作"军情紧"）、信息（作"消息""音信"）、时间（作"时辰""日子"）。
- **欧化长定语**："那个穿着破旧军服拿着一把生锈刀的士兵" → "溃兵。军服不合身，刀锈了。"
- 数字翻体感（GDD 支柱 5 全文有效）：数值进叙事文本时必须落在实物上。

### 4.3 专名

人名、地名、物名第一次出现可不解释——信任读者，也信任高亮标注（叙事双轴 §5）。
同段内不重复全名：素徽／她；鲁舟／船牙。

## 5. 四体（语域）

| 体 | 用场 | 定位 | 范例 |
|---|---|---|---|
| **正文体** | 第二人称主叙事 | 克制、感官、具体；叙事者只旁观 | 夜半。他放下船桨。水声替他掩了门。 |
| **史书体** | 大事轴、野史、正史栏 | 纪年＋月＋一行事实；冷，不安慰 | 建安二十四年八月，汉水溢，七军没。 |
| **露布体** | 官方榜文、征用令 | 套语、大词、与真象隔一层纸 | 照得樊城再捷，斩获无算，吏民同庆，各安其业。 |
| **市语体** | 民间对话、童谣、闲笔 | 断句、俚语、热的东西 | 「米又涨了。涨罢，反正也没米。」 |

- 同一文本可以换体，但不许混体成句。
- 露布体的"假"与市语体的"真"对照，是本作的反讽引擎；两体的差距越大，层 1 越疼。

## 6. 标点律

- 对话与引语用「」；露布与文书的引文用『』。
- 逗号短拍，句号收束；问号省着用（问句多以句号收，语气交给下文）。
- 破折号每段至多一次；省略号每篇至多一次。
- 高亮标记（叙事双轴 §5）属于数据层，不作标点使用。

## 7. 执行机制

1. **content lint**：`test/unit/style.test.js` 对 `content/base/` 文本字段跑禁词正则。
   启用顺序：prelude.json / mainline.json / historia.json（随批次上线即启用）→
   narrations / events / sidestories（批次八校订后启用）。白名单：露布体卡片可豁免"日渐／已经"。
2. **提示词注入**：narrator.md、annalist.md（叙事双轴 §3.5）头部引用本圣经 §2–§4；
   金样本回归断言输出无禁词。
3. **金样本**：每个 LLM 角色维护 3–5 条定稿样本（好句为准），回归时断言：句长分布、禁词零命中、标记合法。
4. **校订批次**：批次八对存量文本做一次圣经化改写，改动词表与措辞，不动事实与数值（N-02 同源精神：只动衣裳，不动骨头）。

## 7.5 序章白话例外（信息优先律）

序章（prelude 的 heaven／siege／entry／confluence）是新玩家的说明书，不是正文叙事——
**留白断在情绪上，不断在因果上**。自 0.14.0 起：

- **白话优先**：偏白话文讲述，允许说明文式的铺陈与重复；该交代的背景（为什么围城、
  规矩是什么、困难在哪、三人为何同住）必须交代清楚，不嫌啰嗦。
- **短句成拍、免状语律仍然有效**：句子可以多，句子不因此变长；禁词表照跑。
- **要点朱批 `[[要|……]]`**：规则、任务、危险、关键结论用朱批标出，玩家扫一眼可辨。
  「要」是排版指令，非名词引用，不走 registry 校验。
- **引文块**：文本行以 `> ` 起头即按史书引文排版（楷体、左缘一线），用于《三国志》
  原文与《三国演义》回目；引文之后必须跟白话解说——引文给出处，白话给人听。
- 前传（prequels）、正传叙事、大事轴仍按正文文风执行，不适用本例外。
