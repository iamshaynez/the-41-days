## 1. 一天的完整生命周期

**PH-01** 一局 = 连续的游戏日（D1..D∞），每日依序经过四个阶段：
`破晓(结算) → 白天(行动) → 黄昏(指派) → 深夜(探索/袭击) → 次日破晓`。

**PH-02** 破晓结算按固定顺序执行（顺序即测试顺序）：

```
① 夜间归位：外出者回府、卸货、袭击结果生效
② 饥饿 tick：全员 -1 级（H-02）
③ 伤病 tick：治疗/恶化结算（I-08~I-12）
④ 疲劳 tick：睡眠结算（F-03）
⑤ 温度 tick：严寒检定（T-04）
⑥ 心情 tick：状态拖累与嗜好（M-05/M-06）
⑦ 日计数 +1，天气抽取，事件抽取（V-02）
⑧ 晨报生成（内核产出 facts，LLM 渲染）‣
```

**PH-03** 阶段推进只由内核驱动；LLM 无权跳过或回退阶段。
玩家说"我们连过三天"时，若日常委托已配置 → 走快速模式（Z-05），否则拒绝并引导。

## 2. 幸存者系统

### 2.0 六轴总览

| 轴 | 取值 | 每日节奏 |
|---|---|---|
| 饥饿 | 0濒死 ~ 4饱足 | 晨 -1，进食 +1/+2 |
| 伤 | 0无/1轻/2重/3危重 | 晨结算 |
| 病 | 0无/1微恙/2重病/3危重 | 晨结算 |
| 心情 | 值 [-15,+15] → 5 级 | 事件驱动 + 晨拖累 |
| 疲劳 | 0正常/1疲惫/2力竭 | 睡眠结算 |
| 受冻 | 布尔（冬季） | 夜间检定 |

### 2.1 饥饿（H）

- **H-01** 状态：`4饱足 / 3正常 / 2饥饿 / 1严重饥饿 / 0濒死`。
- **H-02** 每晨全员 -1 级；4→3 为上限衰减（饱足只跌到正常）。
- **H-03** 进食：生食 +1；熟食 +2；罐头 +2；高级餐 +2 且心情 +1。
  已达 4 时再吃无增益（内核警告浪费，LLM 演出角色吃撑的烦躁）‣。
- **H-04（v1 修订：渐进式挨饿）** 濒死每晨 50% 转为微恙；带病仍挨饿才升重病
  （原 v0 为直接转重病——sim 显示烈度过高，见平衡报告）。
- **H-04b** 各状态的机制效应：
  - 2 饥饿：无惩罚，仅叙事提示 ‣。
  - 1 严重饥饿：无法执行「重劳动」（建造/清塌/战斗 -1），每晨心情 -1。
  - 0 濒死：无法外出/建造/战斗，每晨 50% 转为重病（I-04）。
- **H-05** **隔天餐策略（核心经济锚点）**：熟食 +2 配合晨 -1，
  形成"吃一天、扛一天、始终在 4↔2 振荡"的生存节奏——
  每人每 2 天消耗 1 份熟食（=1 生食 + 燃料）即可维生。此节奏必须有测试保证（H-13）。
- **H-06** 烹饪：炉灶，生食×1 + 柴×1 → 熟食×1，耗 1 AP（埃米尔免柴）。
  节能灶：柴耗减半（向上取整）。
- **H-07** 高级餐：埃米尔专属，生食×1 + 蔬菜×1 + 水×1 → 高级餐（吃时全队心情 +1）。
- **H-08** 水不由"口渴"消耗（同原作，无脱水机制）；水是制造资源（蒸馏/园艺/高级餐）。
- **H-09** 捕鼠笼：任意食物×1 作饵 → 3 天后 50% 得生食×1（可循环上饵）。
- **H-10** 草药园：水×2 启动 → 4 天后收草×3；菜园（升级）：水×3 → 5 天收蔬菜×3。
- **H-11** 冬季雪水：雪天且铁炉燃烧 → 每晨额外产水×1。
- **H-12** 食物变质：不开败坏机制（对齐原作），罐头即"无炉时代的储备"。

### 2.2 伤病（I）

- **I-01** 伤：`0/1轻伤/2重伤/3危重`；病：`0/1微恙/2重病/3危重`。两轴独立。
- **I-02** 受伤来源：战斗（C-07）、袭击（R-06）、坠落/塌方事件（V 类）、自伤（M-14）。
- **I-03** 患病来源：严寒（T-04）、濒死转化（H-04）、伤口感染（I-06）、疫情事件（V-31）。
- **I-04** 濒死每晨 50% → 重病。
- **I-05** 治疗物品作用：
  - 绷带：伤 2→1 立即生效，并使后续恢复加速（I-08 中按"已用药"计）。
  - 药品：病 2→1；危重稳态必需。
  - 草药药：病 1→0；或病 2 时替代第二份药品（草药药×2 = 药品×1 效果）。
- **I-06** 感染交叉：伤 ≥2 且未用绷带连续 3 天 → 每晨 30% 伤 2 且并发微恙。
- **I-07** 医护加成：玛尔塔（或习得医护的尤拉）执行"治疗他人"时，恢复计数 +1 档。
- **I-08** 恢复结算（每晨，取最先满足的条件）：

| 状态 | 条件 | 结果 |
|---|---|---|
| 伤1 | 任意（不卧床也可） | 3 天后 → 0 |
| 伤1 | 卧床 | 次日 → 0 |
| 伤2 | 绷带 + 卧床 | 每晨 -1 级 |
| 伤2 | 仅卧床 | 每 2 晨 -1 级；每晨 20% 感染检定（I-06 提前） |
| 伤2 | 无处理 | 每晨 30% → 伤3 |
| 伤3 | 绷带 + 药品 + 卧床 + 医护照料 | 稳定，每晨 -1 级 |
| 伤3 | 缺任一 | 每晨 50% 死亡 |
| 病1 | 卧床 或 草药药 | 2 天 → 0 |
| 病2 | 药品 + 卧床 | 每晨 -1 级 |
| 病2 | 仅卧床 | 每 3 晨 -1 级；每晨 20% → 病3 |
| 病3 | 药品 + 卧床 + 医护 | 稳定，每 2 晨 -1 级 |
| 病3 | 缺任一 | 每晨 50% 死亡 |

- **I-09** 卧床定义：该日该角色 AP 上限降为 1（仅轻活动），且占床。
- **I-10** 医院路线：白天改为"护送就医"（耗 1 人全天 + 交易代价：绷带×1 或 价值 10），
  当日伤/病直接 -1 级并清除感染计时。夜间不可就医。
- **I-11** 死亡结算：角色移除，其随身物品与床位释放；全队心情事件（M-08）；
  遗物入档案馆（跨局"这座城记得"）。
- **I-12** 死因记录进事迹账本，供后日谈与平衡统计（死因分布 KPI）。

### 2.3 心情（M）

- **M-01** 心情值 MV ∈ [-15, +15]，映射：`≥+4 坚定 / -3~+3 平静 / -4~-8 低落 /
  -9~-13 抑郁 / ≤-14 崩溃`。
- **M-02** 事件增减基值见 M-09 表，先乘**角色伦理向量**（M-10），再做钝化（M-03）。
- **M-03** 钝化：同类事件第 n 次，实际值 = 基值 × max(0.3, 0.8^(n-1))（麻木机制）。
- **M-04** 级别效应：
  - 坚定：检定 +1（全队至少一人坚定时，晨报多一句暖话）‣。
  - 抑郁：AP -1；出现拒绝清单（建造/外出/战斗，按人设 LLM 演出拒绝）‣；
    每夜独走检定 20%（无人同屋交谈时）。
  - 崩溃：进入**崩溃链**（M-14），不再直接出局。
- **M-05** 晨拖累：饥饿 ≤1 每晨 -1；伤 ≥2 每晨 -1；嗜好断供每晨 -1（M-06）。
- **M-06** 嗜好：达尼洛（烟）、卡佳（咖啡）：断供 >24h 每晨 -1；供给时 +2（钝化适用）。
- **M-07** 心情传染：任意角色连续 2 天 ≤ 低落 → 全队每晨 -0（不传染值，
  但 LLM 在叙事中表现氛围）‣；有人进入崩溃链 → 全队 -2。
- **M-08** 队友死亡：按关系档 -6（同屋深谈过/救过命 = 深交 -8）。
  关系档由内核按历史事件记账（同队天数、互相治疗、共同战斗）。
- **M-09** 心情事件基值表（节选全表，v0 完整表入 content）：

| 事件 | 基值 |
|---|---|
| 熟食饱餐 / 收音机音乐 / 读书 | +1 |
| 嗜好供给 / 帮助邻居成功 | +2 |
| 佐菲亚演奏 / 全队高级餐 | 全队 +2 |
| 捐药给医院 / 救下被欺凌者 | +4 |
| 目睹惨剧 / 平民死于你面前 | -5 |
| 拒绝求助（有心结者） | -2 ~ -4 |
| 队友死亡（关系档） | -6 ~ -8 |
| 偷窃良民 / 抢劫良民 | -5 |
| 杀死武装敌人 | -1 |
| 杀死无辜者 | -10 |
| 被袭击失窃 | -2 |

- **M-11** 安抚行动：对低落以下者执行"交谈"（1 AP）→ +1；
  深谈（2 AP，需同屋过夜后）→ +2 且清除独走计数。
- **M-12** 抑郁独走：20%/夜（同屋有清醒者则免疫），出走者次日晨回归，
  带回随机后果（平安/失窃/轻伤/撞见暗线情报，5:3:1:1）。
- **M-13** 特殊正向：修好钢琴后的首次演奏 = 全队 +3（仅一次）；灯塔广播当夜全队 +5。
- **M-14** 崩溃链（3 步，可被安抚逆转）：
  - 第 1 晨：失眠独语，全队 -1（演出）‣。
  - 第 2 晨：藏匿危险物/写告别信（晨报可见预警）。
  - 第 3 晨：若累计未被 +4 以上安抚 → 离队（带走个人份额）或自伤（→伤2，全队 -4）。
  - 安抚条件：M-11 交谈累计 +4，且饥饿 ≥2、伤病 ≤1。

### 2.4 疲劳（F）

- **F-01** 状态：`0/1疲惫/2力竭`。
- **F-02** 累积：整夜未眠（守夜/外出/独走）+1。
- **F-03** 恢复：睡床过夜 -2（并按 I 表加速伤病恢复）；地板/椅子 -1。
- **F-04** 效应：疲惫 = 检定 -1、战斗 -1；力竭 = -2 且次日 AP 强制为 1（昏睡半日）。
- **F-05** 排班约束：床位数 ≥ 睡床人数；守卫可睡椅（恢复 -1 档）但被袭击惊醒后参战 -1。

### 2.5 受冻与温度（T）

- **T-01** 冬季窗口：D10~D35 随机开始，持续 8~14 天（难度可调）。
- **T-02** 天气序列每日抽取：`晴/阴/雨/雪/严寒`；冬季雪与严寒权重上升。
- **T-03** 室温判定（每夜）：`室温 = 取暖炉燃烧值 - 天气严酷度`
  （火盆 2、铁炉 3；严酷度：雪 2、严寒 3；节能炉燃烧值 +1）。
- **T-04** 室温 < 0 时每夜受冻检定：普通 25%、老弱（安东/伤病≥1）40% → 微恙。
- **T-05** 燃烧值：柴 1 / 燃料 2 / 书 1；铁炉可烧燃料，火盆只烧柴与书。
- **T-06** 受冻者次日叙事标记 ‣，连续两夜受冻 → 检定 +15%。

### 2.6 成长（G，尤拉专属）

- **G-01** 尤拉初始无特长；AP 3；脆弱：负面心情事件 ×1.5（已并入 M-10 向量）。
- **G-02** 教学机制：与有特长者同日执行同类行动累计 5 次 → 习得弱化版特长
  （如"学徒厨师"：烹饪免柴 → 半柴）。可用教学源：埃米尔/玛尔塔/格里高利/阿列克谢。
- **G-03** D18 后（"他过了生日"事件）脆弱移除，背包 +1。‣

- **C-03** 被击倒的敌对者处置三选一：补刀（=杀死，走 M-09 杀敌/杀无辜判定）、

- **C-04** 对中立/友好动手 = 抢劫/杀死无辜，直接入事迹账本。
- **C-05** 背刺：持刀 + 未被察觉 + 一次成功潜行检定 → 直接击倒且无战斗轮；

- **C-06** 枪械：+2/+3 且每轮耗弹 1；声响 +2（几乎必然引来注意）。
- **C-07** 受伤结算按 C-02 差值带映射伤 1/2/3。
- **C-08** 撤退：任意战斗轮后可宣布撤退 → 撤离检定（帕维尔 +3）；

- **C-09** 出动者死亡：随身背包全失，I-11 结算。

## 7. 袭击与防御（R）

- **R-01** 每夜来袭概率 `P = min(0.8, 0.35 + D日/100 + 恶名×0.05 − 守卫威慑0.15)`。
- **R-02** 恶名 0~5：抢良民 +1、杀无辜 +2、杀敌 +0.5、帮助 −0.5（下限 0）。
- **R-03** 威胁值 `T = 2 + D日/3 + 家产值/50 + 恶名`（家产值 = 库存总值/10）。
- **R-04** 袭击类型阶梯（按 D 日与随机）：D1-10 流民（饥民，可门外施舍化解 → 心情 +2）/
  D8+ 劫匪 / D15+ 醉兵（特殊：可上交价值 10 物资免战）/
  恶名 ≥3 触发寻仇队 / 任意夜"无声夜窃"（无战斗，晨报发现失窃）。
- **R-05** 结算带：`D≥T` 击退（25% 守卫轻伤）/ `0.6T≤D<T` 击退+失窃 10% 家产 /
  `0.35T≤D<0.6T` 失窃 25% + 50% 有人受伤 / `D<0.35T` 重创：失窃 40% + 必有人重伤，20% 死亡。
- **R-06** 失窃顺序按袭击类型口味（流民拿食物、劫匪拿贵重、醉兵乱拿）。
- **R-07** 袭击后：门 -1 级（B-08）、全队心情 -2（击退则 -0 且 +1）。
- **R-08** 求助链回报：深交邻居在来袭夜 30% 预警（当晚 D+2 或免袭）。

- **B 层·参数化卡**：结构固定、槽位随机的模板卡（敲门人的身份/需求/天气情境
  从数据池抽取组合）。组合空间大，数值由池子保证。
- **C 层·生成卡**：编剧 LLM 在预算内**原创提案**，核心验证后入场——
  世界的呼吸，本节规则只约束 C 层。

**GE-01 提案协议**：编剧产出结构化提案 JSON
`{前提, 情境, 涉及方, 玩家可应对面(2~4), 请求效果[], 主题标签, 锚点[]}`，
经核心验证（GE-03~08）后才成为可触发事件；拒绝的提案不重试原样提交。

**GE-02 触发预算**：每晨 Tier C 配额 0~1 个（密度可配：关/低 0.5/标准 1/高 1.5）；
单局 Tier C 占全部事件 ≤25%。**大事件（价值流动 >4 点、伤害 ≥2、袭击、
任何正典接触）禁止由 C 层首发**——只能由 A/B 层卡承载，或由已注册生成元素的
弧线递进到达（GE-05，每步仍受预算约束）。

**GE-03 效果白名单**（机制菜单，带频次上限；皮肤自由，效果只准从这里点菜）：

| 效果 | 幅度 | 频次上限 |
|---|---|---|
| 心情 | 单角色 ±1~2 / 全队 ±1 | 每类每周 2 次 |
| 物品 | 获得 ≤4 值 / 失去 ≤4 值 | 每周 3 次，需叙事锚 |
| 信息 | 已知范围内的情报（物价/天气/人性细节） | 不限 |
| 关系 | 邻居好感 ±1 / 生成NPC 关系 ±1 | 不限 |
| 时间 | 耗 0~1 AP | — |
| 风险 | 一次 JD 检定，伤害上限伤 1 | 仅玩家自选冒险分支 |

禁止项：直接伤病 ≥2、死亡、袭击触发、越价格带交易、封印关键词（GE-10）。

**GE-04 上下文锚定**：提案必须引用 ≥2 个**真实存在**的上下文锚
（当前天气/日期/角色状态/近期事迹/已注册元素/未访问地点），核心逐一校验；
锚不存在即拒绝。防止万能模板漂移——事件必须"长在"这一局的世界里。

**GE-05 生成元素注册表**（连续性账本）：编剧可引入新命名元素
（NPC / 动物 / 小物件），首次入场时登记 `{名字, 身份, 关系, 状态, 弧线步数}`。
上限：活跃生成 NPC ≤3、动物 ≤1、有戏物件 ≤3。已注册元素可被后续事件引用并
演化（初遇→发展→收束，≤3 步），玩家可主动寻找它们（"去找那个卖火柴的女孩"）。
元素随角色死亡/战争结束写进档案馆"这座城记得"。

**GE-06 回响规则**：每晨导演从 事迹账本 + 生成元素表 里抽 1~2 个"回响种子"
供编剧参考；≥30% 的 C 层提案应回响过往（帮过/亏欠过的生成 NPC 必在其后
5~15 天内可再出现）——恩怨有回声，世界才有记忆。

**GE-07 主题轮盘**：每日抽当日主题
`稀缺/病痛/孩子/士兵/天气/失物/交易/艺术/沉默日`，提案须贴合；
连续两天同主题强制换；"沉默日"= 无 C 层事件（留白也是节奏）。

**GE-08 去重指纹**：每个提案按 `前提+对象+效果类型` 生成指纹，7 天冷却；
高相似提案（同锚同效果）计入冷却。

**GE-09 色调护栏**：战争写实、克制、以小为美（一根火柴、一句谣言、一只猫）；
禁超自然、禁荒诞喜剧、禁英雄主义爽感；残酷呈现走分级（GDD §11.5）。

**GE-10 正典防火墙**：提案含封印关键词或暗示暗线结构 → 直接拒绝（复用泄漏词表）；
生成 NPC 不得与正典 NPC 同名同姓或结亲缘；生成事件不得触碰战局时间轴。

**GE-11 玩家交互**：生成事件以情境呈现，玩家自然语言自由应对 → 裁判解析 →
常规意图管线结算；**无视/回避也是选择**，多数微事件可安全走开，有些会留后果。

**GE-12 测试与门禁**：核心验证器走单元测试（预算/锚/防火墙/指纹四类断言）；
生成器本体走 LLM 评测集扩展（技术架构 §10 L4）：抽样 500 条断言
主题贴合率 ≥90%、色调违规率 <2%、正典泄漏 = 0、效果档分布符合设计带宽；
平衡 sim 中 Tier C 以"等效效果卡"替身运行（固定分布采样白名单效果），
保证生成层的存在不破坏 KPI 带。

**GE-13 直读降级**：LLM 离线 → C 层整体关闭，只剩 A/B 层，游戏完整可玩。

**C 层触发位**：晨报里的一句世界纹理（0 预算纯氛围）· 白天敲门/窗外/家中微事件 ·
黄昏小插曲 · 夜间遭遇变奏（对既有遭遇卡换皮：对象/动机/小转折可变，
机制结算不变）· 已注册元素的回访。

**示例**（锚定+预算内的自由度长这样）：
- 天气锚+艺术主题，0 预算："巡逻兵在对面楼顶升了面颜色不对的旗，
  邻居们隔着废墟争论它意味着停火还是换防。"（全队氛围，无机制）
- 回响种子：你曾把食物分给门口的流民 → 他今晨在门把手上挂了
  三根钉子拧成的鱼钩（物品 +1 值，关系 +1）。
- 生成 NPC 弧线第一步："卖火柴的女孩"要热水，给一小把盐换；
  第二步（5~15 天后）她带来下城的传言（信息）；第三步她不再出现，
  门口只剩一根燃过的火柴（心情 -2，收束）。
- 夜间变奏：超市劫掠者带着一个咳嗽的孩子——"守地盘"变"守口粮"，
  检定与结算与原卡完全一致，但你扣扳机前会多想一秒。

## 12. 收支试算（平衡锚点，供 sim 校验）

**基准局**：3 人 · 纪实 · 无冬 · 30 天 · 隔天餐策略。

- 食物需求：3 人 × 15 餐 = 45 熟食 ≈ 45 生食 + 45 柴当量。
- 开局供给（标准）：生食 4 + 罐头 2（=4 餐）+ 地窖窖藏 ≈ 12 餐当量。
- 外出期望：平安夜均带回 10~14 价值点 ≈ 2.5~3.5 生食当量 ×25 夜 ≈ 65~85 餐当量。
- 缺口 −30 餐当量 → 由捕鼠（~6）/园子（~9）/交易（卖奢侈品买食物）/求助链/道德获取填补。
- **结论**：纯守家不可活（饿死线），纯搜刮 80% 局需在 D20 前建立两项以上补充渠道
  ——压力恰好落在道德抉择与建设取舍上。此锚点即 sim 的"均衡策略"验收带。

## 14. 随机性宪章（RND）

从玩家视角，随机分五族，各族管理方式不同；本节是所有概率设计的评审准绳。

### RND-01 两族概率协议（总纲）

- **主动族**：玩家发起的动作不确定性一律 `2d6 + 明示修正` vs JD-01 三带。
  玩家在行动前永远能知道"我在赌什么"（观察、计划单预览、修正可见），
  且永远保留撤退权（C-08）。
- **被动族**：世界结算一律固定概率晨 tick（百分比，不掷骰），
  且**每个概率都必须有对应的预防动作**。
- 禁止混用：不对晨 tick 掷 2d6；不在玩家动作上掷隐藏骰。
  例外只有物品级风险（开锁器 50% 折断——买"无声"的价格，事前明示）。

### RND-02 五族清单

| 族 | 内容 | 玩家感知 | 管理手段 |
|---|---|---|---|
| ① 主动检定 | 潜行/开锁/破拆/战斗轮/撤退 | 当场、可见修正 | 创意加值≤3、观察+1、随时撤 |
| ② 晨间结算 | 濒死转病/感染/受冻/独走/捕鼠 | 隐蔽发生，晨报追认 | 每个概率配预防杠杆（吃/绷带/取暖/陪伴/上饵） |
| ③ 局势抽签 | 天气/事件抽取/商人库存与到访/停火日/冬季窗口/容器重填 | 部分预告 | 天气预报、炮声前兆、邻居与观察哨预警 |
| ④ 开局配置 | 队伍/地点子集/季节/种子 | 开局全透明 | 首局保底正典钥匙角色 |
| ⑤ 剧本假随机 | 假停火/屠杀/D41 魔咒/D60 强制 | 演出为无常，实为时间轴 | 多周目显形为"模式"→暗线入口 |
| ⑥ 生成随机 | C 层微事件/遭遇变奏/生成NPC（GE） | 皮肤随机、机制有界 | 效果白名单+预算（GE-03）、锚定（GE-04）、指纹去重（GE-08） |

### RND-03 预告原则

灾难级结果（角色死亡、全灭、失去住所能力）**至少提前一天有可读信号**
（观察哨 B-04、深交邻居 R-08、广播 §8.5、崩溃链 M-14、天气预告）。
无预兆死亡只允许出现在玩家**主动选择**的极端威胁地点（前线废屋带、狙击路口）。

### RND-04 下限保护

危重状态留 2~3 晨干预窗口（I-08）；崩溃留 3 晨安抚链（M-14）；
袭击最差结算带需要长期忽视防御才会落入（R-03/R-05）；
sim 门禁兜底：袭击致全灭率 <5%（技术架构 §11.2）。

### RND-05 可控不消除

观察换 +1（N-04）、计划模式预览、随时撤退、守卫威慑、创意加值上限 +3
且重复递减（GDD §11.3）——随机可以被准备压低，不可以被消除。

### RND-06 种子与反读档

所有随机由 run 级种子派生序列产生；同种子 + 同输入 = 同事件流
（技术架构 §4.1）。回档重试得到相同结果——save-scumming 在机制上无意义。

### RND-07 呈现纪律

默认只给结果叙事；透明模式显示 RollLog；LLM 采样温度只作用于文字，
永不作用于状态。晨 tick 的具体百分比数值不直接展示给玩家（透明模式除外），
以体感语言呈现（"他的腿在发黑"）‣。

### RND-08 正典零随机

暗线事实（谁/为何/何时）永不掷骰；随机的只是玩家何时、以何顺序遭遇它们。
文档分布每局部分刷新（E-10 同族）——多周目元知识 = 概率优势，不是攻略答案。

### RND-09 跨局收敛

多周目玩家将部分局势随机转化为已知（真假停火判读、文档高产点），
这是奖励而非破坏；"历史学家"难度相应加压（§11），让知识本身成为新的风险面。

### RND-10 生成随机的有界性

C 层生成事件（GE）的叙事皮肤无限，机制效果**永远**只能从白名单菜单取值
（GE-03），且须经核心四重验证（预算/锚/防火墙/指纹）后才入场。
因此：LLM 的想象力不改变概率分布的形状——平衡 sim 用"等效效果卡"替身
即可完整覆盖生成层的机制影响（GE-12）。皮肤是礼物，骰子还是内核的。
