# 《第 41 天》游戏设计文档 v0.2（建安二十四年 · 江陵）

> 一个基于 LLM 的网页文字生存冒险游戏。核心致敬《这是我的战争》（This War of Mine），
> 但舞台是**建安二十四年（219 年）的江陵**——关羽围樊、白衣渡江、麦城，
> 这一段你以为你熟知的三个月。你熟悉的每一个名字都不会登场，
> 登场的是他们从没被写进书里的那些人。
>
> 状态：v0.2 设定转向定稿（替代 v0.1 的别列佐夫设定；机制骨架全部继承）
> 本文档是迭代的基线，所有数值均为 v0 调校值，标注 ★ 的为待定问题。

## 0. 一句话概述

你操纵一队被困在江陵城里的平民——塾师、药婆、琴师、仓吏——白天经营避难所，
夜间冒险外出，用自然语言告诉游戏"你想怎么做"——LLM 负责当裁判和叙事者，
一个不掺假的数值内核负责让你饿、让你冷、让你付出代价。
而在一次次的死亡与重来之间，你会发现：
**这场你以为你熟知的历史，你只读过它的露布。**

**副标题口号**：*江陵不陷落，江陵只交割。*
**玩家入口钩子**：*你没有背叛关羽。你只是把船划到了对岸。*

## 1. 设计支柱

所有后续设计决策都对照这六条（v0.2 新增第 6 条）：

1. **自由但有边界**：玩家可以说任何话、做任何事，但世界按硬规则回应。
   LLM 是翻译官和叙事者，**不是**上帝。数值内核是唯一的上帝。
2. **挫折是内容，不是惩罚**：饥饿、疾病、抢劫、崩溃都服务于体验。
   玩家死亡是常态，死亡也推进认知（见兰台）。
3. **道德有重量**：偷窃、杀戮、见死不救都有真实代价；
   但游戏不审判玩家，只呈现后果。原作式的克制与沉重。
4. **谜底藏在你自以为知道的历史里**：玩家带着《演义》进场——
   那是一份被剪辑过的档案馆。游戏的水下层嵌在正史的缝隙里，
   嵌到玩家去查史料时会愣一下："居然查得到。"
5. **文本即玩法**：一切数值都翻译成可感的文字（干呕、发抖的句尾、沉默），
   一切文字都锚定在数值上。没有纯装饰的叙事，也没有裸露的数值。
6. **正史锚点零随机（新）**：水面上的正史（水淹七军、白衣渡江、麦城）
   永不掷骰、永不被生成层触碰；水下的虚构只准填缝，不准改缝。
   或然结局是唯一的例外出口，且被严格圈养（§12.5）。

## 2. 世界观

### 2.1 表层：建安二十四年的秋天

- **时间**：建安二十四年，八月廿三（D1）至 闰十月（D45，交割日）及以后。
- **地点**：江陵城，南郡治所，江汉之会。关羽的荆州后方。
- **背景**（水面，人人皆知）：关将军围樊城，上月水淹七军、降于禁，
  威震华夏，曹操议徙许都以避其锐。**江陵是胜利者的后方。**
- **你**：谁也不是。平民。城里的米价、降卒、疫病、军法，正在逐日收紧。
  三万降卒的口粮压在仓里，捷报越频，粮越紧。
- **名将在哪里**：在露布上、传闻里、征用令的花押上、远方的鼓声里。
  **关羽永不登场**（§2.4）。

### 2.2 暗层：三层真相（跨周目揭示）

游戏有一份固定的**正典（Canon）**——正史锚点 + 水下虚构，全部写死
（[正典圣经-v0.2.md](./正典圣经-v0.2.md) §10）。任何一局游戏都不会改变它，
只会改变你看到多少。

**层 1 ——「这仗打得有点怪」（单局内即可察觉）**
- 捷报越打越频，米越吃越紧。胜仗为什么会饿？
- 降卒营抬出来的伤兵，伤是泡发的，疮是挨挤出来的——不像战场下来的，像水里捞的。
- 城里商船过三方津戍都放行：挂的都是"合法"符传。
- "议和""迁都"的传闻出现了两次，每次 48 小时内就发生摩擦升级（湘关的米、津戍的冲突）。
- 已经很久没人提"盟约"两个字了。孙刘是盟友——盟友为什么不送粮？

**层 2 ——「有人在三方同时供货」（跨周目浮现）**
- 船牙鲁舟是"券局"商路的末端——一个横跨三方的物资组织（三栏账：宛/柴桑/成都）。
- 城门露布栏的捷报产自府库街对面的誊抄所——同一篇"大破"改了三个月的日子。
- 水门渡的神射"白翎"是乐户出身的鼓手，他放箭的节奏是一支挽歌的小节线。
  **他是幸存者池里琴师素徽的哥哥。**
- 医棚主事杜仲的伤兵簿指向一个结论：箭簇有吴制——这场"孙刘联手"的战争，
  有人早就在对面下单了。

**层 3 ——「江陵不是被攻破的，是被交割的」（兰台 + 关键证据解锁）**
- **魏吴券书**：孙权上书乞以讨羽自效，曹操许割江南——真正的城下之盟
  在闰十月之前就已签署。抄件被射进两军营地当心理战（董昭之计，正史），
  捡到过它的只有一个不识字的逃兵。
- **屯候更籍**：吕蒙白衣渡江"尽收缚之，羽不闻知"（正史）——收得那么干净，
  是因为名册是买来的。卖它的人是白翎第一任，价码是妹妹出乐籍。
- **军仓的火**：烧掉军械的火起于库内三重。而订单是糜芳自己下的——
  正史写着"芳内畏惧，权闻而诱之"，《麋竺传》写着"私好携贰"：
  他早就和吴暗通，火是他烧给后世看的理由。
  **守城的人，就是开门的人。**
- **湘水之盟没有展期条款**：215 年的和平是租约，219 年无人续期。
  全江陵只有一个守藏吏知道到期日——他当年誊抄盟书时，
  亲眼看着"期满自展一年"被朱笔划掉。
- **门的传统**：208 曹仁弃守、215 郝普中信、219 糜芳开城——
  江陵三次易主，没有一次是被攻破的。
- 本局若无人干预，D45 交割日准时至。交割后第 41 日，关羽没于临沮。
  **你拼命活到的"停战"，是另一个人的死期第一天。**

### 2.4 名将不上台（正典纪律）

关羽、吕蒙、曹操、孙权、徐晃、陆逊、司马懿、虞翻、刘封、孟达——
一律不以 NPC 形态登场，只以露布、传闻、童谣、征用令、远方的鼓声存在。

设计理由：这个版本的情感脊柱是**先让玩家恨关羽三个月，再让他死**。
玩家进场时爱他；游戏用三个月的征用、军法、米价和降卒
让"关将军"变成压在头顶的天；然后麦城的消息传来，
玩家才发觉自己不知道什么时候哭了。
名将一登场，这套距离感就破了——他是庙里的神，
神像不能走下来说话，一下来就成了戏台上的角儿。

## 3. 游戏循环总览

### 3.1 局内循环（单局，约 30-60 个游戏日）

```
┌─ 破晓 ──── 夜间结算（袭击/外出结果）、状态衰减、晨报
│  白天 ──── 行动点分配：建造/制造/吃饭/治疗/交谈/交易/看榜（自然语言驱动）
│  黄昏 ──── 决定：谁出门、去哪、带什么、留谁守家
│  深夜 ──── 外出者：LLM 主持的探索场景（对话/潜行/战斗/逃跑）
│           守家者：袭击检定（后台）
└─ 凌晨 ──── 归队、卸货、自动睡眠、日计数 +1
```

### 3.2 局外循环（跨周目）

```
一局结束（全灭 / 开城 / 还师 / 出江陵）
        ↓
结局结算 → 后日谈（或野史一页）→ 兰台存档（文档、人物真相、史册永久保留）
        ↓
开启新局（新的幸存者组合 / 天气切片，但正典不变）
        ↓
玩家带着元知识重新进场 → 能问到新的问题 → 挖到更深的层
        ↓
（你的《演义》认知是第一份元知识——它有时是资产，有时是陷阱）
```

## 4. 内核 A：幸存者

### 4.1 六条状态轴

机制完全继承（饥饿 / 伤 / 病 / 心情 / 疲劳 / 受冻），数值见
[内核设计-v0.2.md](./内核设计-v0.2.md) §2。文本翻译层更新为建安语汇

### 4.2 幸存者池（12 人，每局随机 3-4 人）

每人 = 属性倾向 + 特长 + 心结 +（部分人为**正典钥匙**）。
完整人格卡、隐藏三拍、声音样本见 [人物设计-v0.2.md](./人物设计-v0.2.md)。

| 角色 | 背景 | 特长（机制） | 心结 / 私欲 | 正典关联 |
|---|---|---|---|---|
| 文简 | 退休塾师 | 高级制造；谈判小加成 | 女儿在公安，音信断了 | 无（但文书类文档他读得快） |
| 辛夷 | 药婆 | 治疗效果 ×2，卧床者稳定 | 心软：拒绝求助 = 大量心情损失 | 与杜仲是旧识（医棚线引子） |

| 阿走 | 驿卒 | 逃跑检定大加成；背包 10 | 怕黑（夜间独处检定） | 驿亭死信线的引子 |
| 老甑 | 邸舍庖厨 | 烹饪省 1 份柴 | 闻得出"仓米里掺了沙" | 层 1 线索的活体探测器 |
| 素徽 | 乐户琴师 | 鼓琴：全队心情 +2（消耗 1 行动） | 哥哥被征发，生死不明 | **正典钥匙**：白翎之妹 |
| 大柯 | 梓匠（棺匠） | 建造/制造省 20% 材料 | 想给家人打一口像样的棺 | 无（但火线仓门他看得懂） |
| 阿禾 | 15 岁屯候火夫 | 成长型：可被教会任何特长 | 脆弱：心情崩溃加速 | 数周目后：他的老年版是野史馆的"批注者" |
| 薄姑 | 仓曹女史 | 簿记：库存自动盘点、交易 +10% | 赎罪：围城前她封过 429 枚检署 | **正典钥匙**：认得券局符传编号段 |
| 江鳅 | 私枭（私盐私米） | 开局多 1 箱物资；黑市联络人 | 被军法队通缉（津戍风险） | 知道鲁舟的"上家"存在（层 2 引子） |
| 逄灶 | 老烽燧卒 | 可修烽台/置鼓置火 | 沉默寡言，旧伤腿 | **终局钥匙**：北津台与《还师》的技术前提 |

**组合规则**：每局从池中抽 3-4 人；存在互斥（江鳅 + 薄姑开局互不信任事件）与
联动（素徽 + 任何"水门渡"情报 = 主线大节点）。
首次游戏固定抽到含 1 名正典钥匙角色的组合，保证暗线可被第一次触碰。

## 5. 内核 B：物品与经济

机制继承，物品皮肤汉化。完整总目录见 [内核设计-v0.2.md](./内核设计-v0.2.md) §3。
旗舰映射：罐头→**肉脯**（硬通货）；私酿酒→**自酤浊酒**；香烟→**浊酒/蜜水**（嗜好品）；
书→**简册**（可读可烧——烧字纸会触发文简的抗议，敬惜字纸）；
电子件→**铜件**（铜是战略金属）；子弹→**弩箭**；手枪/步枪→**手弩/强弩**；
贵重品新增**蜀锦**（硬通货）。

交易规则继承：鲁舟逢双日泊船；价格带由内核裁决，LLM 只在带内演出；
**文档异常价**（E-09）保留——鲁舟收纸的价高得反常，他买的不是纸。

## 11. LLM 交互层（本游戏的心脏）

### 11.1 四个角色分工

| 角色 | 职责 | 硬约束 |
|---|---|---|
| **叙事者** | 把状态渲染成文字；场景描写 | 只读状态，一个字都不能改 |
| **裁判** | 解析玩家自然语言 → 结构化意图；多步计划拆解 | 意图必须过核心校验；无权决定成败 |
| **演员** | 扮演所有 NPC 对话 | 只能说 NPC 知识范围内的话；秘密受"封印"保护；**名将不上台** |
| **编剧** | 从事件表提案包装随机事件 | 只能在核心抽中的事件槽内发挥；**正史锚点防火墙**（§11.6） |

**核心原则：LLM 提议，内核裁决，LLM 演出。**
所有状态变更走 `意图 → 校验 → 数值结算 → 结果枚举 → 叙述` 流水线。

### 11.2 玩家输入分类 / 11.3 创意加值 / 11.4 知识封印 / 11.5 公平性

完全继承 v0.1（§11.2-§11.5 逐条不变）。
越界拒绝示例更新："你怀里其实有一把强弩"→
"建安二十四年的江陵，私藏弩机是连坐的罪。这座城里像你这样两手空空的人，
唯一的武器就是还在喘气这件事。"

### 11.6 正史防火墙（GE-10 扩展，新）

生成层（C 层）除原有的暗线封印词表外，新增**正史锚点词表**
（正典圣经 §10.A）：任何涉及名人生死、正史日期、正史事件结果的提案
一律拒绝。生成 NPC 不得与正史人物同名同姓或结亲缘。
**LLM 可以虚构江陵的每一粒米，不能改动史书的每一个字。**

## 12. 主线：兰台与多周目

### 12.1 兰台（账号级永久存档）

一局结束，无论结局，本局收获自动入台。兰台分三格：

- **物证格**（#001-#060）：简牍、符传、券书、鼓谱、账页、勘验记录、帛书残角。
  旗舰示例：
  - `#007 城门候征发檄`（层 1：编号段不属军需曹）
  - `#014 死信：寄樊城的家书`（纯人性，无暗线——噪音是必要的）
  - `#021 杜仲的伤兵簿`（层 2：溺伤比例与吴制箭簇）
  - `#028 鼓谱残页`（层 2，白翎线）
  - `#033 鲁舟流水三栏`（层 2，船牙身份）
  - `#039 魏吴券书抄件`（层 3：城下之盟早已签署）★铁证
  - `#045 誊抄所底稿`（层 3：露布造假）★铁证
  - `#052 券书残页`（层 3：自动续期条款与交割清单抬首）★铁证
  - `#055 屯候更籍抄件`（层 3：羽不闻知的原因）
  - `#058 大仓火场勘验`（层 3：火起于内）
  - `#061 绑腿里的帛书残角`（回旋镖终点）
- **人物真相格**：每位正典 NPC 一份档案，逐条解锁
  （"鲁舟为什么总在逢双日泊船？""文修为什么从不核编号段？"）。
- **史册格（新）**：本作档案馆的心脏，分两栏——
  - **正史栏**：你解锁的"通行叙事"批注（露布/童谣/《演义》版本），
    每条附水下对照——你以为你知道的三个月，逐条被覆写。
  - **野史栏**：你打出的水下解读与或然结局（§12.5），
    批注者是老年阿禾（人物设计 §4.9）。
- **江陵记得**：你历代角色的结局与事迹账本。浏览旧文档时，
  会看到"当年也见过这份纸的人"留下的批注——包括已经死去的那些角色。
- **进度门槛**（解锁矩阵）：
  - 层 1 显形：累计任意 8 份文档
  - 层 2 显形：累计 20 份 + 任 3 位 NPC 真相
  - **《还师》**（层 3 终局剧本）：层 2 已解锁 + 当局内集齐 3 件铁证
    + 逄灶在场（或北津台已修复）+ 一名"知晓者"存活

### 12.2 交割日（史实结局的可玩高潮）

D45 当夜，内核按正典走位（正典圣经 §3），不掷骰。
玩家的位置只决定三件事：**看见多少、带走多少、有没有让北津台响起来**。
这一夜是全游戏的情感顶点：没有攻城战的"城破"——
塔的沉默、门轴的油、五更礼貌的家访。

### 12.3 真结局《还师》（灯塔行动的本卷形态）

- 触发后，当局新增目标线：**D40 之前，让铁证跑在吕蒙的船前面。**
- 路线：取得北津台（修复 / 买通 / 白简伪造符传 / 鲁舟最后背叛券局）
  → 夜访链过三道津戍 → 证据抵樊城大营 → 老纪的百份露布贴满四座城门。
- 羽军收兵，连锁三日：吴船退、券局连夜收摊、于禁的降卒被接管。
  **交割没有发生。但荆州没有因此得救——它只是继续被战争使用。**
- 结算升级为**全城后日谈** + 野史《还师》一页，正典批注：
  "这一版历史没有发生。但未必没有被发生过。"

### 12.4 黑暗结局《出江陵记》（入桌的本卷形态）

持有 #033 或 #052 时，鲁舟会在某个黄昏带来一个提议：
**券局买你的证据**——一条船 + 三张符传（全家出城），代价是沉默。
- 接受 → 黑暗结局：「你活着离开了江陵。江陵没有。」
  兰台解锁特殊词条（野史栏一页无字的白帛），
  且此后**每周目**商路都认得你（新开局的隐藏事件：鲁舟见你第一面就说"船还给你留着"）。
- 拒绝 → 鲁舟此后不再泊船，交易渠道变窄（真实代价）。
- 这给暗线装上了牙齿：发现真相之后，你还要**选择**配不配得上它。

### 12.5 或然结局（圈养的历史分岔）

或然是本作的新结局类：稀有、昂贵、苦甜。铁律：
**或然不许改正史锚点**（麦城得脱 ≠ 荆州不失）；
野史一律史书体、三行以内、必有冷批注（正典圣经 §8.5）。

| 或然 | 种子 | 结果 | 野史批注 |
|---|---|---|---|
| 《麦城得脱》 | 素徽线 + 逄灶/北津台 + 交割夜行动 | 樊城早六个时辰知道；羽走房陵，得脱。城照样交割 | "你救下的不是荆州，是一个人的命。" |
| 《惨胜》 | 火线勘破 + D30 前交潘濬 | 开城推迟六日，吕蒙只能围，羽还师惨胜。江陵大饥 | "守住的城和开过的城，账本不一样，死人一样多。" |
| 《另一种三国》（叠加变体） | A+B 同局达成 | 全游戏最稀有的一页 | （老年阿禾只写一句，见正典圣经 §8.2） |

### 12.6 正典不变量 vs 周目随机量

| 每局随机 | 永不改变（正典） |
|---|---|
| 幸存者组合、天气序列 | 正史锚点全部（谁、何时、如何——史书怎么写就怎么是） |
| 地点可用子集、事件抽样顺序 | 水下虚构全部（券局、更籍、火线、文修的罪） |
| 袭击/物价波动骰运 | 正典 NPC 的身份与秘密 |
| 你的选择与结局（含或然） | 三次易主"门从里面开"的模式 |

玩家的元知识 = 唯一跨周目增值的资产。二周目起，部分对话会出现
「你已经知道结局」专属选项（灰色小字），点了会有真实的叙事回报。
**本作特有一例**：你用《演义》知识行动可能被坑（《演义》是露布的孙子）——
错误的熟知同样有代价，这是本背景独占的机制（§1 支柱 4）。

## 14. 示例流程（第 1 天，节选）

> **破晓 · 橘里九号 · 建安二十四年八月廿三 · 霖雨**
> 更鼓在四更乱过一次，又装回整齐。辛夷在灶下生火，
> 石大把门厅的柜子又推了半寸。降卒进城第三天，米价翻了一倍，
> 露布栏的捷报却写到了第七篇。
> 你们有：板材×6、杂件×4、肉脯×2、糙米×1、水×3、裹创布×1。
> 状态：全员「正常/平静」，文简微恙。

**玩家**：先把里间那张破榻拆了当板材，让石大干。
然后辛夷给文简看看咳。我下午想去磨面妪家问问能不能换点麸——听说她儿子上周被抓了夫。

**裁判解析**（内部）：
`石大: 拆榻 → +板材×3, 耗时2` ✓
`辛夷: 治疗文简 → 微恙→明日痊愈, 耗时1` ✓
`玩家(以谁的身份?)去磨面妪家 → 需指派角色 + 1行动` → 反问确认

**叙事者**：石大的铁撬在榻腿榫口处发出三声闷响……（略）
你要亲自去？这会用掉你整个下午，而且雨还没停。

**玩家**：让白简去吧，他会说话。带两件杂件当见面礼，但如果人还在家，别提交换，先听听他们要什么。

**叙事者**（执行 + 编剧掷中「邻居求助」事件槽）：磨面妪没走。她媳妇在。
她隔着门缝听完了白简的来意，很久没说话。然后：
"杂件我有用。但如果你们有药……我婆婆的腿在发黑。你们有吗？"
（她盯着白简的眼睛。白简知道家里有且仅有一卷裹创布。）

**黄昏指派** → **深夜 · 被焚的南市**（石大外出，携铁撬）：
> 烧塌的铺面像被巨兽舔过。粮行后柜有声响——人，活的，带着刀。

**玩家**：我不出声，先退回断墙后，听他的动静规律。要是他只是翻东西，我就等他离开这个区域再动手搜。

**裁判**：潜行检定 2d6（+1 利用环境已描述的残檐雨声掩护）……核心掷出：代价成功。
**叙事者**：你贴着断墙挪了两步，脚下的碎陶替你出了声。那人按刀转过身来——
是个和你差不多年纪的溃兵，军衣不合身，饿得手都在抖。
他喊了一句南阳土话："出去！这是我的！"

**玩家**：我慢慢举起手，用另一只手从包里拿出那块肉脯，放在地上，退后两步。

**叙事者**：男人的刀在你和肉脯之间摆了三次。……"一半。"他用刀把肉脯劈开，
真的掰了一半推回来。"南市是我的。但……驿亭的死信库，没人翻。我发誓。"
（你获得了：半块肉脯。你记住了：**驿亭的死信库**。）
（石大心情：这个人没有动手。他也不好过。心情 +1。）

**玩家**：趁现在，我怀里其实还有一把手弩，我拿出来指着他说把米袋交出来。

**裁判**（越界驳回 → 叙事性拒绝）：你没有弩。建安二十四年的江陵，
私藏弩机是连坐的罪——这座城里像你这样两手空空的人，
唯一的武器就是还在喘气这件事。
（如果你想获得武器：南市后库有堵死的夹墙，铁撬能打开，但会花掉你剩下的时间。）
