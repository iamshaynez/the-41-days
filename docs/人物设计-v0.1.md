## 1. 人物三层模型

每个幸存者由三层构成，三层分别对应玩家体验的三个时段：

| 层 | 内容 | 玩家何时看到 |
|---|---|---|
| **公开面** | 人格、坚持、口癖、功能特长 | 开局第一天 |
| **隐藏面** | 秘密、心结、与他人/正典的交织 | 局内三拍揭示（§3） |
| **未来面** | 后日谈方向种子（存活/死亡/主线完成度分支） | 局终，由 LLM 展开（§6） |

三条铁律：

1. **性格即机制**。每个人的"坚持"必须挂钩一个真实可触发的机制事件
   （烧书、补刀、签字、关收音机）——不是 flavor text，是玩家每周目都会撞上的冲突。
2. **秘密即内容**。隐藏故事不是背景板，是有触发条件、有揭示节奏、有反转的可玩内容。
3. **未来即种子**。后日谈不写死文案，写"方向种子"，当局事实填充，LLM 文学展开——
   同一角色在不同周目有不同的结局文本，但永远不崩人设（§6）。

## 2. 人格卡协议（P）

- **P-01** 每名角色一份人格卡，分三页：**公开页 / 隐藏页 / 未来页**。
  隐藏页走与暗线相同的知识封印（GDD §11.4）——触发条件不满足时，
  LLM 上下文里**根本没有那一页**，玩家怎么套话都套不出来。
- **P-02** 每人 6~10 句**声音样本**（分心情档），作为演员/叙事者 LLM 的风格锚。
  人设一致性的保证不是"扮演好这个角色"这种空话，是样本句的句式、词汇与禁忌。
- **P-03 坚持即机制**：每个"绝不"对应一个内核事件钩子。触发时人格卡注入抗议/冲突事件：
  - 安东：玩家下令**烧书取暖** → 抗议事件（心情 -2，可强制执行，关系受损）。
  - 玛尔塔：玩家选择**补刀被击倒者** → 她若在队，强烈反对事件。
  - 薇拉：交易/文书事件中若出现"**来路不明的物资**" → 她必追问来源。
  - 阿列克谢：玩家**三天不听收音机** → 他自己去打开（"关机的人听不到真的那一句"）。
  - 埃米尔：连续两天生食 → 主动占用 1 AP 做饭事件。
  - 格里高利：用**抢来的门**加固 → 拒绝施工事件。
  - 帕维尔：被安排**独睡** → 请求守夜事件。
  - 达尼洛：玩家抢劫**平民随身物** → 他退出该次夜间行动事件。
  - 卡佳：玩家转述未经核实的传闻 → 纠正微事件。
  - 佐菲亚：炮声日的演奏请求 → 拒绝（但崩溃夜她会自己弹）。
  - 尤拉：大人说谎被他听见 → 他不拆穿，当晚在手背上记一笔（情绪暗账）。
  - 布罗：夜间地点出现**被困者** → 无视其他指令优先救人（检定事件）。
- **P-04** 台词禁表：每人有"绝不说的话"（玛尔塔不说"没办法"、薇拉不说"大概"、
  布罗不说"那次火警"、尤拉不说谎）。禁表进演员提示词。

## 3. 隐藏故事三拍结构（HIDE）

- **HIDE-01** 每个隐藏故事按三拍揭示，每拍有独立触发条件，跨系统分布：

| 拍 | 名称 | 内容 | 典型触发 |
|---|---|---|---|
| 一 | **裂缝** | 一个说不通的小行为（发呆、回避、暗语） | 天数 + 同屋/同队，晨报微文本 |
| 二 | **揭示** | 本人坦白或被物证撞破（秘密的"表面版"） | 关系值 / 特定地点 / 事件卡 |
| 三 | **反转** | 真相的最后一层，必须**拼合 2~3 个独立线索** | 跨系统：文档+对话+广播/另一角色的线 |

- **HIDE-02** 反转拍永远需要"拼图"：单一渠道只能拿到第二拍。
  这是多周目引擎的一部分——你以为你知道了，下一局的某个文档告诉你你只知其二。
- **HIDE-03** 隐藏故事必须与"他人或世界"交织，禁止孤立的身世惨剧。
  交织对象：另一名幸存者 / 正典 NPC / 正典层 1-3 / 地点。
- **HIDE-04** 揭示不可逆：已揭示的事实当局永久生效（关系、选项、地点反应随之改变），
  并入档案馆"人物真相"跨周目保留。

## 4. 人物圣经

> 格式：公开面（人格/坚持/魅力）→ 隐藏三拍 → 个人主线 → 未来种子 → 声音。
> 标注 ★正典 的部分待《正典圣经》第一卷确认。

---

### 4.1 安东 · 退休数学教师 ——「用秩序对抗崩塌」

**人格**：战争把一切变成混沌，他的反抗是把一切变成表格：物资账、天气账、
全队每个人咳嗽的频率。他不是冷血——他的账本背面全是人。
**坚持**：绝不烧书（T-05 的燃料冲突是每周目的常驻张力）；每天记完账才睡。
**魅力**：他记得全队生日，用废报表折东西当礼物。算了一辈子账，只算人不算命。

**隐藏三拍**：
- 裂缝（D5+）：他对账时对着一页写满名字的纸出神。问 → "我的学生。"
- 揭示：战争第 2 天，女儿回来接他出城。他坚持带走一箱子学生试卷——
  "这些是孩子们写过字的纸。" 末班车没等他。女儿独自走了，或者没有。
- 反转（拼 #014 类死信 + 邮局线 + 下城情报）：死信库里有一封女儿写给他的信，
  没寄出——她回来找他了。"爸，我恨了你三个月。现在我在地下室给邻居的孩子们上课。
  我懂了——你留下的原因和我想的一样蠢。" 信封地址被炮火抹掉一半。
  两种正典分支由当局局势判定：**重逢**（下城地下室，她和 11 个孩子）/
  **噩耗**（#021 弹道统计里那行"学校地下室"就是她）。
- **终极抉择（玩家）**：找到信时，给不给他看——给他真相（他可能死在寻女的路上）
  还是给他一个能活下去的谎。**游戏第一次让玩家替别人选择知道或不知道。**

**个人主线**：名单 → 死信 → 信的抉择 → 下城三步（地址→口信→重逢/噩耗）。
**未来种子**：重逢 → 父女重开学校，校名「第 41 天小学」；噩耗 → 他撕掉账本最后一页，
第二天开始教邻居孩子，"名单上多了 11 个名字"；死亡 → 若尤拉同局，账本换人接手，
词条「账本还在记，换了一只手」。
**声音**："账不是这么算的。账是：他们还在，我们就还欠着。"

### 4.2 玛尔塔 · 退役护士 ——「用忙碌压住记忆」

**人格**：她从不坐下。坐下就会想起那一夜。
**坚持**：绝不放弃任何伤员，包括开枪打伤她的人（处置被击倒敌人时触发她的反对事件）；
不许别人替她道谢。
**魅力**：全队都在抖的时候，只有她的手是稳的。

**隐藏三拍**：
- 裂缝：她给绷带打结时默念一个名字——"伊利亚"。
- 揭示：十年前矿难，分诊，唯一的血浆。她给了"更有希望的"，伊利亚死了。
  带她的人是塔玛拉——那天塔玛拉去抬第二个伤员，不在场。
- 反转（需医院线 + 塔玛拉对话两阶段）：塔玛拉"双方都收、只看伤情"的分诊原则，
  正是那夜之后立的。而伊利亚的哥哥此刻就躺在塔玛拉的病房里，按"敌军伤员"收治——
  塔玛拉一直知道他叫什么，没告诉玛尔塔："他活着，活得不好。值得一看，进门之前想好。"
- **收束抉择**：进那间病房，或不进。两种都是答案。

**个人主线**：绷带上的名字 → 与塔玛拉重逢（医院线开启事件升级）→ 病房门前。
**未来种子**：存活 → 战后在医院废墟挂牌"诊所"，规矩一条："先来后到，不看军装"；
死亡 → 急救包传给队友，词条「她这辈子最后悔的不是那次选择，
是学会不选择，用了十年」。
**声音**："绷带不分制服。"

### 4.3 布罗 · 消防员 ——「用肩膀抵债」

**人格**：他欠的那笔债，别人用命都还不清。他的还法是"再背一个"。
**坚持**：破门清塌永远第一个上；绝不谈"那次火警"（P-03：夜间地点出现被困者时
他会压过其他指令优先救人）。
**魅力**：全队的安全感来源；每天夜里检查三次门锁的人。

**隐藏三拍**：
- 裂缝：不许人碰他左肩的旧烧伤；路过烧毁的建筑会停半秒。
- 揭示：五年前公寓大火，他在七人和一人之间选了七人。
  那个"一"是他的徒弟，第一天出勤。
- 反转（邻居感谢名单事件）：徒弟其实被另一名消防员背出来了——活着，残了。
  布罗不知道。他用别人的命，还了一个活人五年。
  "当年把我背出来的人说，他师傅才是全别列佐夫最好的消防员。"
  布罗听完，去门后站了很久。
- 交织：安东深夜对话事件——"你做的是对的。""我知道。这就是问题。"

**个人主线**：烧伤回避 → 火场 PTSD 事件 → 被困的孩子（再进一次火场：
陪他去 / 按住他 / 让他自己去）→ 徒弟的名字。
**未来种子**：存活 → 重建消防队，收徒弟，第一课教"你会选错的，带着它接着背人"；
死亡 → 全队用门板把他抬出来——"这次没有人被留下。"
**声音**："门让我来。你们的肩膀，留着扛别的。"

### 4.4 卡佳 · 前电台记者 ——「用追问赎罪」★正典钥匙

**人格**：她的每一条"为什么"，都在还一条假的。
**坚持**：从不说"据说"；没核实的字一个都不转述。
**魅力**：全队唯一敢把真话说出口的人；用冷咖啡和旧笔记撑着体面。

**隐藏三拍**：
- 裂缝：她拒绝听战前自己电台的存档录音。
- 揭示：战争第 3 天，她被要求播"医院无恙"的安抚稿。她播了。
  第二天医院被炸，37 人。她辞了职，电台换了人——换的人继续播。
- 反转（回声站线）：回声站的录音师**维克托**是她的师父——教她
  "声音是有重量的"的那个人。他不是被抓去造假的，是自愿的：
  长桌会给了他全城最好的录音棚。灯塔行动里，卡佳的声音上广播时，
  维克托在录音棚里听见了她。★正典
- 维克托结局分支（玩家前期接触深度 + 内核检定）：他**关掉垫乐**——
  全城的"背景战争"第一次露出静音 / 他把垫乐声调大。

**个人主线**：广播判读 → 听出垫乐（Q≥8）→ 找到回声站 → 师徒。
**未来种子**：灯塔 → 《白桦城之死》，档案馆批注者之一；沉默 → 小咖啡馆老板娘，
墙上贴满没人看的剪报，"她把真相从职业变成了墙纸"；死亡 → 采访本入馆，
最后一页写着"这条还没核实"。
**声音**："名字、日期、谁说的。没有这三样的句子，我不转述。"

### 4.5 帕维尔 · 短跑运动员 ——「用玩笑包裹恐惧」

**人格**：白天是全队的太阳，夜里是全队的哨兵。两个他隔着一层黑。
**坚持**：外出侦察永远第一个报名；绝不独自睡觉。
**魅力**：他教尤拉跑步，管全队叫"接力队"，给每段废墟都起了赛道名。

**隐藏三拍**：
- 裂缝：他从不在黑的地方站着不动——守夜永远踱步。
- 揭示：停电夜，妹妹在楼道里心脏病发。他跑去找人，
  跑出了这辈子最快的一次。回来晚了。他恨"快"——
  全世界只有"快"辜负过他。
- 反转（与佐菲亚/狙击路口交织）：必须有人穿越狙击路口取药救队友的那一夜，
  全程唯一一次，他需要"慢"：灰雀的节奏三短一长，活路在拍子里。
  佐菲亚在队，她数，他走。他用最慢的一次奔跑，救回一个人。
- 收束文本："有些路，走得慢的人才到得了。"

**个人主线**：踱步 → 停电夜 → 狙击路口的慢。
**未来种子**：存活 → 战后当邮差，全城唯一还在跑的人，送信从不敲门——
"等他们数三秒再开"；死亡 → 跑鞋放在门口，词条「他终于不用跑了」。
**声音**："我去。我快——这次我慢。"

### 4.6 埃米尔 · 饭店厨师 ——「用一口热饭对抗非人化」

**人格**：他的逻辑只有一句：人只要还坐在一起吃饭，就没输。
**坚持**：绝不做喂不饱人的"假饭"；队友剩饭他默默吃掉；不许人说"凑合吃"。
**魅力**：三样破烂做出全队沉默吃完的饭（高级餐机制的人格化）。

**隐藏三拍**：
- 裂缝：闻到配给粮，鼻子抽一下，一整天不说话。
- 揭示：战前他是谷物加工厂质检主厨。战争第一周，厂长让他"按比例掺"，
  他摔了围裙走人。他的徒弟留下了。
- 反转（加工厂线）：徒弟现在是"师傅"。围裙口袋里一张"底线表"——
  他把每批掺假压在"吃不坏人"的线上。"我不掺，他们就换人。
  至少我掺的是锯末，不是玻璃。" 而那条线，正被上头一寸一寸往下挪。
  师徒对峙里没有坏人，只有一个在撤退的底线。
- **玩家抉择**：把底线表公之于众（层 1 证据 + 徒弟陷入危险）/
  埃米尔回厂接班（配给粮回升 + 内线食物渠道，代价：埃米尔每夜出门）/ 算了。

**个人主线**：配给粮 → 加工厂 → 底线表。
**未来种子**：存活 → 小食堂，店名用战死的队友命名，菜单只有一行字：
"今天有什么做什么"；死亡 → 全队第一次自己做饭，难吃得没人说话，
词条「那顿饭他们都吃完了」。
**声音**："饭要趁热。话要趁软。"

### 4.7 佐菲亚 · 爱乐小提琴手 ——「用倾听代替存在」★正典钥匙

**人格**：全队说话时她最安静——她在听每个人句尾没说出口的东西。
**坚持**：不在炮声里练琴；但队友崩溃的夜里她会弹——"哭声不该和那个声音
共用一个房间。"
**魅力**：绝对音感是全队的雷达（机制：袭击预警——她听得出夜里脚步的数目）。

**隐藏（双层）**：
- 层一 · 哥哥（灰雀线，三拍）：乐谱碎片 #028 → 路口听出乐句 →
  ★正典提案：灰雀三个月前就死了。"灰雀"有用，人死了，节奏留着。
  现在的枪手是第三任，照谱开枪。她听出来的那一刻——换气的地方不对。
  **她找到的不是哥哥，是哥哥的遗物。**
- 层二 · 这栋房子（槐树街 21 号）：父母的房子，哥哥住。她为什么在乐团宿舍？
  战争前半年兄妹吵翻：哥哥要退团"做正经事"，她说他背叛音乐。
  征兵名单上是她的名字——哥哥拿着通知书去替妹妹报到，登记官抄错或没抄错
  （永久留白）。灰雀替她扛了枪。她欠的从来不只是思念。
  （拼合条件：#028 + 广播寻人 + 本人坦白，三者齐才显形。）
- 钢琴细节：修好后她弹的第一首完整曲子是哥哥改过的《死神与少女》。
  若灰雀线已触发，玩家会当场认出那个节奏——同一个旋律，两种枪声。

**个人主线**：= 灰雀线（狙击路口三选项：杀 / 绕 / 把 #028 乐谱射进射界——
照死人乐谱开枪的人看到原作者笔迹，停火 24h，之后一切照旧）。
**未来种子**：存活 → 战后第一场音乐会演奏哥哥改过的版本，
"最后一个音没落，没人鼓掌——全场都在听那个不存在的换气声"；
确认死讯 → 小提琴收入暗格，改弹钢琴，"琴弦太像他了"。
**声音**："嘘。你们听——不对。这个声音里没有车。"

### 4.8 格里高利 · 木匠 ——「用手说话」

**人格**：嘴是多余的，手不会撒谎。
**坚持**：给死人做的东西不收钱；他打的木头绝不装在抢来的门上。
**魅力**：全队东西坏了放他门口，第二天都是好的。他从不说"修好了"，
东西自己会回来。

**隐藏三拍**：
- 裂缝：他攒木料，量尺寸用手比——不用尺。
- 揭示：围城初期，城防军"征用"了他家的门和地板做工事。
  病重的妻子在没有门的屋子里过了第一个寒夜。
  他不恨哪支军队——他恨"征用"这两个字。
- 反转（★与薇拉同局触发，交织主线）：他用两罐头的代价从认领处赎回过一块
  自家门板，背面有征用编号。某天他看见薇拉记账的字；薇拉看见那块门板。
  编号段她认得。她盖的。——全游戏最安静的爆炸：没有喊，
  两个人隔着一张桌子，中间一块木头。
- **玩家抉择**：劝和（"她盖的时候不知道是你家。"——"她也没问。"）/
  让薇拉搬走 / 冷处理（第三天他把薇拉漏风的窗修好了——"手不懂记仇"——和解）。

**个人主线**：木料 → 门板 → 对峙。
**未来种子**：存活 → 给无名死者打棺材打了四年，最后在教堂墓地立一块
没有名字的木板——"所有没被记住的人，躺平的地方我都量过"；
死亡 → 他用攒的木料打的棺材最后装的是他。词条「木料终于够了」。
**声音**：（他大多时候不说话。）"门挡的是风。挡人的是墙。别把两样搞反。"

### 4.9 尤拉 · 15 岁少年 ——「全队的镜子」

**人格**：你们是什么样，他就长成什么样。他是这局游戏的道德成绩单。
**坚持**：从不说谎——除了"我不怕"。
**魅力**：把全队生日记在手背上；给守夜的人留半块糖。

**隐藏三拍**：
- 裂缝：他夜里喊的不是"爸妈"，是"姐"。
- 揭示：逃难队伍在哨卡被拦，姐姐把他塞进排水管，自己留在队里。
  他说父母"出城了"，是因为答应姐姐"告诉别人我们都很好"。
- 反转（寻人启事/死信拼合）：姐姐的名字在"灰隼旅医疗队"征募名单里——
  被征为医护，活着，在河对岸。成长线由此装上终局方向。
- **他的未来是全游戏分支最多的**：档案馆批注者 = 老年尤拉（正典：他活下来了），
  但**他成为谁完全由玩家塑造**——教学账（G-02 扩展）记录他每项技能的来源，
  后日谈由 LLM 按教学账生成：被教会医术 → 战地医生；被教会走私 → 下一个达尼洛；
  没人教他 → 他教会自己开枪。

**个人主线**：手背上的名字 → 哨卡 → 河对岸（结局后解锁的"第二天"微别传★）。
**未来种子**：批注者老年尤拉给下一代玩家写注：
"那年冬天有个混蛋教会我解剖兔子。我谢谢他一辈子。"
**声音**："我不怕。（停半秒）你们呢？"

### 4.10 薇拉 · 前军需官文员 ——「用精确赎罪」★正典钥匙

**人格**：她把世界分成两类：有据可查的，和她盖的章。
**坚持**：绝不在没读完的纸上落笔；来路不明的物资她必追问。
**魅力**：冷面毒舌，毒舌永远对准权力不对准人——对达尼洛：
"你这种人，和平年代是罪犯，战争年代是物流。"

**隐藏三拍**：
- 裂缝：看到征用令她数编号段；她不碰印泥。
- 揭示：开战第一周她盖了 412 个章。第 413 个她停了——
  那份文件征用一所学校的全部孩子"构筑工事"。她回头去查：
  前 412 份里，17 份的编号段根本不属于军需处。
  有人用他们的纸、他们的章，发自己的令。
- 反转（层 3 社会学真相）：长桌会不是几个人在长桌上签字——
  它是几百只像她一样的手。每张纸都合规，每一章都是例行公事。
  **"战争不是被操纵的。战争是被办理的。"** 而那 17 份假令里，
  有一份征走的是格里高利家的门。
- 与格里高利的门板对峙见 §4.8。和解线的尾声中，格里高利只说了一句：
  "你数你的编号。我量我的木板。数清楚，量平。"

**个人主线**：印泥 → 17 份 → 门板 / 账本线（层 3 主入口之一）。
**未来种子**：存活 → 战后战争罪行调查记录员，"她终于把章用在了对的地方——
证词里没有'据说'，只有编号"；死亡 → 账本入馆，
扉页「412+17。我记得全部 429 个」。
**声音**："给我看纸。纸比人诚实——纸至少不假装。"

### 4.11 达尼洛 · 走私犯 ——「用玩世不恭执行纪律」

**人格**：江湖人的规矩比法律严。他嘲笑一切，除了自己的规矩。
**坚持**：不碰平民随身物（只动"有主的货物"：军队、仓库、长桌会的）；
欠的情必须还。
**魅力**：全城地下血管活地图；给哨卡的孩子带糖——用抢来的军需糖。

**隐藏三拍**：
- 裂缝：法比安见他总是多一分客气——末端物流对劫道者的同行敬意。
- 揭示：通缉令不是为走私——他劫了一趟长桌会的军需车，
  把车上的药分给了下城。那批药本该进 #033 的"北南"两栏。
- 反转（★入桌线变奏）：法比安的上家找他不是报复，是招揽——
  能从有清单的组织手里劫到货的人，正是清单需要的人。
  达尼洛在场时，"入桌"提议变成双份："他们有位置给你。"
- **他的入桌抉择是入桌结局的第二种走法**：替全队入桌（他消失，
  全队拿通行证+物资）/ 最后时刻掀桌（他知道仓库在哪）/ 拒绝并离开队伍。

**个人主线**：通缉令 → 法比安的客气 → 双份提议。
**未来种子**：存活 → 黑市变灰市、变自由市场，"别列佐夫第一根自由的胡萝卜
是他卖的"；替队入桌 → 档案馆黑暗词条；死亡 → 通缉令与讣告同日张贴，
"两张纸，都错了，都对"。
**声音**："规矩一条：穷人的口袋是圣地，军队的仓库是菜地。"

### 4.12 阿列克谢 · 电台工程师 ——「用手代替嘴」★终局钥匙

**人格**：语言会失真，焊点不会。
**坚持**：修好的东西必须能用，拒绝"凑合"；从不关收音机——
"关机的人听不到真的那一句。"
**魅力**：温柔全在物件里：给尤拉攒的铁皮蚱蜢，给佐菲亚做的琴弦替代扣。

**隐藏三拍**：
- 裂缝：阴天他的腿先迈哪条要停半秒；他从不提战争第一天。
- 揭示：第一天他去电台抢修民用发射机，被城防军以"破坏通讯设施"开枪打伤——
  他要修的东西会绕过审查。
- 反转（★正典提案）：回声站录音师**维克托**是他的同期，两人当年共用一间维修间。
  战争把他们分到信号的两端：一个修真相的管道，一个造假的内容。
  灯塔终局不是战斗，是两个工程师隔着一台发射机聊信号和噪音——
  "你修的这机器会害死人。""你录的那些声音，已经害死了。"
  若卡佳在场：师父对面站着他的过去，也站着他的徒弟。三个人，一台机器，全城的耳朵。
- **正典 NPC 合并提案**：维克托 = 回声站录音师 = 卡佳的师父（内容端）=
  阿列克谢的同期（技术端）。一个灰色人物压住两条暗线，比三个薄反派有力。

**个人主线**：旧伤 → 发报机图纸（电气维修站旧同事留言）→ 灯塔。
**未来种子**：灯塔 → 重建电台，第一档节目是寻人启事，念到没人再来问；
沉默 → 停火那天他把收音机拆了，"里面的东西配不上外面的安静"。
**声音**："别说话，听——滤波器好了。假的真不了，真的有底噪。"

## 5. 关系网（REL）——有戏的对子

不做 12×12 全矩阵，只做**会触发专属内容的对子**。
每个对子 = 至少一个双人事件/对话/机制交互；同局才触发，是组合探索的奖励。

| 对子 | 戏 | 形式 |
|---|---|---|
| 薇拉 × 格里高利 | 门板对峙：同屋檐下的加害者与受害者 | 主线交织事件链（§4.8/4.10） |
| 安东 × 布罗 | "你做的是对的。""我知道。这就是问题。" | 深夜对话事件（数学×火场） |
| 安东 × 尤拉 | 生日账 × 手背名字："纸会烧。""那记哪？""记在心里，心不死。" | 教学事件温情分支 |
| 卡佳 × 阿列克谢 | 内容 × 管道：灯塔线双子，维克托对峙的同框前提 | 终局剧本 |
| 佐菲亚 × 帕维尔 | 狙击路口：她数拍子，他走 | 主线机制交互（§4.5） |
| 玛尔塔 × 布罗 | 救人的两种负罪："我们这种人，账都记在自己头上。" | 深夜对话事件 |
| 埃米尔 × 格里高利 | 做饭的 × 打棺材的："都是伺候人的手艺。" | 微事件一句台词 |
| 达尼洛 × 薇拉 | 开局互不信任（GDD 已有）→ 后期和解："你盖的章里有我劫的车。""我知道。17 份里有一份。" | 关系翻转事件链 |
| 尤拉 × 任何人 | 教学镜像：他学谁就像谁 | G-02 扩展 |
| 佐菲亚 × 布罗 | 她听得出他夜查门锁的脚步："第三次了。""……你睡你的。" | 微事件 |

- **REL-01** 对子事件不进随机牌堆，由"同局 + 阶段 + 前置"确定性触发，保证组合奖励可预期。
- **REL-02** 对子戏全部有机制投影（心情/关系档/解锁选项），不是纯文本。

## 6. 后日谈引擎 v2（EPI）——每次不同的结局，永远不崩人设

现有 N-01 是"五维 × 3 档模板"。升级为**未来种子制**：

- **EPI-01 未来种子**：每名角色局终生成
  `{方向锚点(1~3, 按主线完成度解锁) + 未竟之事 + 最深交/最亏欠 + 事迹账本摘要 + 结局类型}`。
- **EPI-02 生成**：叙事者 LLM 以种子 + 当局事实为约束，写 300~500 字文学体；
  N-02 事实校验（提到的事件必须发生过、不违正典、不死人复活、不提前正典未揭示的事实）。
- **EPI-03 变化性来源**：种子由当局事实填充——谁死了、主线走到哪步、门板对峙怎么解的、
  尤拉被教成了谁——组合本身每局不同；采样温度只作用于文字层。
  同一角色在不同周目有质的不同结局文本，但人格锚点（坚持、声音、未竟之事）不变。
- **EPI-04 回写档案馆（关键钩子）**：后日谈里的"未来事实"（校名、店名、节目名、
  一块没名字的木板）经提炼入馆，成为**后续周目的世界纹理**——
  下周目的邻居闲谈、广播寻人、地点描述里，会出现你上一局写下的人。
  玩家的结局不是句号，是下一局的地砖。
- **EPI-05 死亡墓志铭**：死亡角色的"未来"= 遗物与词条，同样由事迹账本生成，
  措辞走 §4 各人"死亡"种子的方向，不做全随机。

## 7. 组合数学：为什么玩家会持续探索

1. **队伍组合**：12 选 3~4 = 495~4950 种队伍；REL 对子戏只在特定同局组合出现——
   薇拉×格里高利同局才有门板对峙，佐菲亚×帕维尔同局才有"数拍子过街"。
2. **揭示互斥**：单局不可能看全一个人。佐菲亚的双层隐藏需要不同周目的不同走法
   （杀灰雀/绕行/乐谱停火）才能拼全。
3. **档案馆人物真相**：每人 5~8 条词条逐条解锁，全收集 = 多周目 × 多组合。
4. **未来回写**：EPI-04 让老玩家的新局世界里全是自己以前写下的人——
   探索欲从"还有什么我没见过"升级为"我的世界正在被我写满"。
