## 1. 不腻的解构

### 1.1 玩家为什么离开（疲劳分类）

| 疲劳类型 | 表现 | 对策归属 |
|---|---|---|
| 系统疲劳 | "又要点吃饭烧水" | 委托自动化（Z）、概述日、快局 |
| 叙事疲劳 | "这个事件我见过" | C 层生成、主题轮盘、别传解锁节奏 |
| 张力疲劳 | "闭着眼都能活" | 挑战语法、长夜局、历史学家难度 |
| 意义疲劳 | "活下来又如何" | 关系弧线（§2）、遗愿/时间胶囊（§3.3） |
| 完成感疲劳 | "兰台 100% 了" | 表达引擎、合上兰台仪式（§3.6） |

### 1.2 玩家为什么回来（五类回报）

1. **不知道的**：新角色、新地点、新真相（有限，须排节奏）。
2. **没做到的**：结局、挑战、别传（有限但可再生——挑战语法）。
3. **没玩过的**：不同组合/道德/策略的身份玩法（组合爆炸）。
4. **新产生的**：C 层事件与涌现戏剧（无限但须有界）。
5. **自己的**：回忆录、时间胶囊、打法风格被江陵"认出"、**野史栏里你写的那几页**（表达复利）。

前两类是**内容**，会被耗尽；后三类是**系统与自我**，才是长尾。
v0.2 的独有资产：玩家进场自带一份《演义》——**覆写它本身就是一种回来理由**，
这是别列佐夫版没有的第 6 类回报：*纠错的快感*。

## 2. 玩家与江陵的关系弧线（SA）

跨周目的真实元进度不是数值，是**这段关系**。兰台进度是其可见刻度。

### SA-1 陌生者（第 1~4 局）
- 核心问题："我能不能活过这个秋天。"
- 内容：系统学习、第一次死亡、首批文档。
- 推进器：首新保底（NE-02）保证每局 ≥2 个新入档。
- 退出条件：标准难度活到交割日一次。

### SA-2 居民（第 4~10 局）
- 核心问题："这条里坊、这些人，我认识了吗。"
- 内容：角色秘密、求助链全貌、鲁舟与文修的真面目、层 1 显形（D41 讲古台词）。
- 推进器：城市开始认出你（EC-01 声望反应）。
- 退出条件：累计 8 份文档，层 1 显形。

### SA-3 知晓者（第 10~20 局）
- 核心问题："这场战争哪里不对。"
- 内容：层 2 真相、正典钥匙角色的专属线、别传①解锁、
  **第一次意识到《演义》在这三个月里骗了你**。
- 推进器：封印揭示的跨局复利（同一个地点，带着不同知识再来，看到不同东西）。
- 退出条件：层 2 显形 + 三铁证曾集齐过任意一件。

### SA-4 干预者（第 20~30 局）
- 核心问题："知道之后，我配得上它吗。"
- 内容：《还师》/《出江陵记》/《开城》沉默，战争级三选；或然种子初尝。
- 推进器：出江陵与还师互斥的道德重量；知晓者难度加压。
- 退出条件：完成还师或出江陵各一次。

### SA-5 守望者（第 30 局起）
- 核心问题："这三个月的故事，轮到我讲了吗。"
- 内容：回忆录、挑战、时间胶囊、或然野史收集、遗愿清偿、历史别传。
- 收束：**合上兰台仪式**（§3.6）——游戏主动承认"故事讲完了"，
  并保持兰台永远可重开。

## 3. 五台重玩引擎

### 3.1 新鲜感引擎（NE）

- **NE-01 未见池**：兰台维护"尚未见过"的文档/遭遇/台词池。
- **NE-02 首新保底**：连续 2 局零新入档 → 下局新内容生成权重 ×2；
  仍零 → 下局必有一份未见文档被放置在可抵达地点（只影响放置概率，不触正典）。
- **NE-03 揭示预算**：标准局新入档目标 2~5 项。多了泄底，少了白玩。
- **NE-04 节奏见 §8**：解锁内容按阶段排片，绝不提前。

### 3.2 表达引擎（EX）

- **EX-01 回忆录**：局终由 LLM 依事迹账本写 300~500 字第二人称文学体章节，
  经 N-02 事实校验，存入"回忆录"合集；**「装订成册」已上线**：档案馆一键下载
  《我的江陵》纯文本全本（章节按时间排序，扉页落款玩家名）。LLM 离线走模板。
- **EX-02 这一局的三件事**：内核按"戏剧分"自动选出三拍刻进兰台该局页面。
- **EX-03 身份玩法**：兰台以"江陵记得"的口吻记录你的行为画像
  （守财/侠盗/商人/修士/烽卒……按事迹账本聚合），
  不同画像触发不同 C 层提案倾向。
- **EX-04 自动化即精通**：委托策略支持导出/命名/复用。
- **EX-05 史册格（新，本作表达引擎的心脏）**：
  - **正史栏**：每条"通行叙事"（露布体/演义体）配你的水下对照批注——
    逐条覆写你以为你知道的三个月。收集进度 = 你与正史的和解进度。
  - **野史栏**：你的或然结局与真结局，史书体一页 + 老年阿禾的批注。
    全游戏唯一能"写出新历史"的地方，因此也是守望期最强的表达磁石。

### 3.3 回响引擎（EC）——玩家成为城市记忆的一部分

- **EC-01 城市反应（反攻略机制）**：各锚点（里社/医棚/南市溃兵/濠鼠/津戍）
  维护跨局声望。边界不变：只影响生成与态度，永不触及正典事实（RND-08）。
- **EC-02 时间胶囊**：任意结局后可埋下**一件物品 + 一句 ≤100 字的话**。
  后续周目该容器真实存在（标注"无名者的埋藏"）。上限同时 5 枚。
- **EC-03 遗愿**：角色死亡（非全灭）时生成遗愿卡（如"文简未寄出的信"：
  下周目驿亭出现这封信，可以替他送）。同时至多 1 张。
  报酬只有兰台词条与一句回应，**绝不给数值**。
- **EC-04 故地重游**：每周目若开局住所随机到橘里九号，
  墙上有上一任住客（你）的痕迹池——琴的续弦程度、暗格是否被翻动、
  地窖里那页鼓谱在不在。

### 3.4 挑战引擎（CH）

- **CH-01 挑战语法**：`阵容约束 × 资源约束 × 道德约束 × 目标约束 × 时限`
  的参数化挑战卡（如"斋戒者：不偷不抢不吃肉""双烛：只有两张床"
  "闰月 40：D40 前完成《还师》"）。
- **CH-02 本周的江陵**：确定性周挑战——种子与约束由
  `hash(年-周, 内容包版本)` 派生，无需服务器。
- **CH-03 挑战记录**：本地通关册，无排行榜。
- **CH-04 别传**（A 层手作内容，按 §8 节奏解锁，每段 20~30 分钟）：
  - **《鲁舟的一趟船》**（知晓其身份后解锁）：扮演船牙五天——航线、进货、
    卖给谁、瞒什么；直达"出江陵"道德的内部视角。
  - **《白翎的渡口》**（水门渡线了结后解锁）：三夜射手叙事谜题，
    无生存经济，只有射界里的人心。
  - **《杜仲的医棚》**（层 2 后解锁）：分诊小品，双方伤员、不足的药。
  每部别传都让主游戏的旧场景**事后变色**——不换系统，换眼睛。
- **CH-05 历史别传（新旗舰线，正史切片，按 §8 后期解锁）**：
  - **《樊城·数板》**（首个或然结局后解锁）：曹仁侧的水淹长夜局——
    "城不没者数板"。你头顶的洪水是关将军的杰作。
    全游戏唯一一次让玩家活在"敌方"的胜利里。
  - **《廖化西还》**（交割结局后解锁）：诈死、负母、昼夜西行（正史）。
    十天徒步的微别传——交割之后，还有人用脚底板投票。
  - **《长坂拾遗》**（兰台 ≥30 份解锁）：208 年古战场的纯人性小品——
    有些骨头只是骨头。
  - **远期（下一内容季）**：《徐州·泗水》（193，最黑的一章）、
    《官渡·乌巢火》（200，一封信撬动的大战）——
    或然引擎的历史别传化，验证"小人物撬动历史"范式的可复制性。

### 3.5 干预引擎（已由 GDD §12 覆盖，此处补两点）

- 《还师》/《出江陵记》/《开城》三向的互斥存档（兰台记录你"每次都选了什么"）。
- **《闰十月·三天》**（首次《还师》后解锁）：固定小队、只有三天、没有经济——
  羽军收兵令到达之前最凶险的 72 小时：藏好证据、护住证人、盯住券局的收摊船。
  真结局的"余味"不是过场文字，是一段可以重打余韵的短局。

### 3.6 优雅退场：合上兰台 ★已上线

- **触发**：兰台 100% + 《还师》与《出江陵记》各完成一次 + 回忆录 ≥10 章 +
  野史栏 ≥2 页。
- **仪式**：兰台首页出现"合上兰台"（两步确认）——江陵用你十局的三件事为你送行，
  此后 C 层密度隔天至多一张（守望档）。
  （实现注：谢幕条件按当前内容包的文档总数自适配；野史栏页数不作硬门。）
  回忆录装订成册导出，游戏明说："这三个月讲完了。江陵会记得。"
  之后任何新局照常可开，但游戏**不再用新内容吊你**（C 层密度降半）。
- **设计意义**：对抗完成感疲劳的最后手段是尊重，不是无限卷。

## 4. 形态层：一局长什么样

### 4.1 局型（开局即选）

| 局型 | 时长 | 结构 |
|---|---|---|
| 围城切片（快局） | 20~40 分钟 | 15 天压缩战局或 D10~D20 切片，预设中盘状态 |
| 标准局 | 1.5~3 小时 | D1 起，至交割日，完整弧线（默认） |
| 长夜局 | 2~3 小时 | 枯竭期全程，无还师线的纪实体验 |

### 4.2 别传局：§3.4 CH-04/05。
### 4.3 《闰十月·三天》：§3.5。
### 4.4 概述日（系统疲劳的解药）

- 平淡日由叙事者一次性**概述**，只在事件/状态突变处停下问玩家。
- "概述日"与"沉默日"（GE-07）共同保证：文本游戏的节奏阀门永远开着。

## 5. 反设计清单（永远不做）

1. **数值元进度**：不解锁更强角色/更多起始物资——知识是唯一允许的元资产。
2. **排行榜与公开攀比**：战争的死人不排名。
3. **战斗通行证 / FOMO**：周挑战不设限时奖励。
4. **跳过键**：压缩靠局型，不靠 fast-forward。
5. **正典随机化**：再缺内容也不拿暗线事实凑重玩性；
   **正史锚点同理**（GDD §1 支柱 6）——或然只准走圈养的种子。
6. **让重复变快的机制**：我们不优化"刷"的效率，我们让每一刷有名字。
7. **把名将做进卡池（新）**：关羽不进幸存者池、不做可招募 NPC、不出立绘。
   神像不下台（GDD §2.4），这是本作气质的护城河。

## 7. 与现有系统的整合约束

- **RND 宪章兼容**：NE-02 保底只改放置权重；EC-01 声望只改生成倾向与态度；
  或然结局的种子判定是确定性的（满足即触发，无骰），不违 RND-08。
- **GE 层协同**：EX-03 行为画像作为编剧上下文锚；正史防火墙先于一切锚（GDD §11.6）；
  合上兰台后 C 层密度 ×0.5。
- **平衡 KPI 新增**：连续无新局 ≤3（NE-02）；挑战卡死局率 = 0（CH-01 验证器）；
  回忆录事实违规率 <1%；**或然触发率门禁：标准局 ≤3%（稀有性守恒）**。
- **兰台扩展表**：capsule / last_wish / memoir / persona / challenge_record /
  annal（正史栏）/ alternate（野史栏）七类 archive_entry kind。

（排片是"保底不提前"：玩家比预期跑得快，系统不拦，但不透支后面的惊喜。）

## 9. 测试钩子

- NE-02：sim 断言随机策略下"连续零新局"最大长度 ≤3（万局采样）。
- EC-01：声望边界测试——同锚点作案 N 次后的生成差异列表恰为白名单允许项。
- EC-02/03：胶囊与遗愿状态机单元 + 跨局 e2e。
- CH-01：挑战验证器单测（不可行组合必拒）；抽样 1000 卡走 sim 存活可行性标注。
- EX-01：回忆录事实校验复用 N-02 管线，评测集断言违规率。
- **EX-05 史册格**：野史文体评测集（史书体合规率 ≥95%、批注存在率 100%、
  正史锚点零改动）——或然文本是生成层的最高风险区，单独设卡。
- §3.6：合上兰台触发条件的覆盖测试与"降密度"开关断言。
- §7 或然触发率：sim 万局采样 ≤3%。

## 10. 待定问题（★）

1. ★ 快局"切片"的预设中盘状态如何生成（手作 3 套 vs 从标准局存档截取）。
2. ★ 遗愿触发比例（当前：任务线角色必出，其余 30%）是否偏高。
3. ★ 别传开发顺序（建议：鲁舟 → 杜仲 → 白翎；历史别传插在 31+）。
4. ★ EC-01 城市反应的强度档位默认值。
5. ★ 合上兰台后 C 层降半是否改为可选。
6. ★ 回忆录是否允许玩家编辑一句题记（当前：允许，仅题记，正文不可改）。
7. ★ 或然野史是否允许导出分享（"我打出了一页野史"是最强自传播物料——
   倾向：允许，且导出物永远带正典批注，防爽文截图流传）。
