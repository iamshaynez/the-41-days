## 2. 界面词汇表（机制的拟物映射，迁移全表）

每个内核系统都有一个"世界的实物"作为界面形态：

| 机制 | 界面实物 | 说明 |
|---|---|---|
| 晨间结算 | **晨报**（邸报版式） | 头条=昨夜大事；状态变化是小字栏目 |
| 信息渠道（原收音机位） | **露布栏 + 更鼓纹** | 看榜=栏上贴帛；更鼓=页缘的鼓点节奏标记，夜越深点越稀；<br>异常时（交割前兆）鼓点纹先乱后停——UI 先知道，文本后说破 |
| 交易 | **地摊布 + 价值天平** | 货物摆在布上；天平可视化价值差（E-06 带内浮动看得见） |
| 计划模式 | **计划牍** | 步骤/耗时/检定点逐条列出，逐条勾选或划掉 |
| 夜间探索 | **炭笔手绘地图 + 薪束** | 房间节点图+战争迷雾；**时间槽=10 束薪，行动烧掉一束**；声响=波纹指示 |
| 敲门事件 | **门** | 全屏门板叩响，开/不开/隔门问——门就是按钮 |
| 文档发现 | **简册卡** | 实体卡片入袋动画（竹/帛/纸三种材质），卡片可"拿起"细读（兰台同构） |
| 角色死亡 | **讣告** | 黑框排版，名字上"砖墙"（见兰台） |
| 局终 | **长卷结算** | 后日谈从上而下展开；**史册格的对照行用碑刻体**（EPI-07 的温差是排印事件） |
| 避难所 | **横版剖面图** | 致敬原作的侧视小屋剖面（操作界面地位按一页书修订收回） |

## 3. 状态呈现（迁移要点）

- 六轴隐喻皮肤：饥饿=食盒（粟米堆的深浅）；伤=裹创布角标；病=咳色斑；
  心情=人物剪影的姿态；疲劳=烛短；受冻=角标结霜。继承。
- **全家福站位**继承：关系深的人站得近，抑郁者退到边缘，死亡留空位。

## 4~7. 继承声明

一天的五种屏幕（破晓/白天/黄昏/深夜/概述日）、文本层次与排印、
输入区（铅笔批注体 → **刀笔批注体**：玩家的字是刻在牍上的细字）、
兰台（抽屉柜 → **架阁**：简册格 + 绳夹木牍墙 + 刻名砖墙"江陵记得" +
**史册格双栏**——正史栏用刊刻体，野史栏用手写体，一眼可辨），全部继承。

## 8. 界面的生长、痊愈与交割夜（UIP-5 落点 + 新增专场）

- 组件解锁=避难所建造：望楼窗/琴弦扣/蒸馏器刻度……继承。
- 季节生长：入冬时整个边框材质变冷；交割前兆（鼓点纹异常）数日后界面"松一口气"
  ——噪点减少，暖色回来一点。继承。
- **《还师》结局后**：框架的箭瘢裂纹**仍在但不新增**——痊愈是叙事，不是重置。
- **交割夜专场（新，全游戏的听觉标志）**：
  - 鼓点纹从页缘开始，**一座座熄灭**（素徽在队时，熄灭的顺序标注台名——
    她听得出来）；当夜全界面无动效、无天气角标、无事件卡；
  - 声音全部压掉，只剩页面最底一行小字按时辰浮现
    （"一更。""二更。""北津门方向，有油味。"）；
  - **静音设计**：界面能做的最响的事，是把所有声音都拿走。
    这一夜，玩家对 UI 的全部期待扑空——扑空本身就是演出。

## 10. 声音（可后置，宁缺毋滥）

- 白噪基底：霖雨/风/远水（低频、低音量、可开关，默认关）；
- 语义音仅三处：叩门、露布贴上栏、薪束划燃。
- 琴单音预留给 M-13 首演与《还师》露布夜；
- **交割夜：无声音轨**（§8 专场）。
