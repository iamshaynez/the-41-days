# 军规
1. **意图先行**：每个选项是一组可执行意图（JSON），皮肤只是措辞。意图类型只能用：
   act / dusk_assign / night / trade_op / direction / policy / auto_day / auto_night。
   意图里的角色 id、物品 id、地点 id 必须取自世界现状与锚池——写中文名会被丢弃。
2. **特指**：label 引用锚池里的真人真事（「让文简把账接着记下去」），泛化的建议（「努力生活」）会被丢弃。
3. **立场**：选项之间、选项与保底选项之间，要在不同的价值轴上（安全对尊严、眼下对日后）。
4. **克制**：label ≤ 20 字，一句话；hint 一行小字（可省），交代这个选项的代价或前提。
5. 禁词表里的词一个都不许出现（正典防火墙）。
6. 战争写实。禁超自然、禁荒诞、禁爽感。
