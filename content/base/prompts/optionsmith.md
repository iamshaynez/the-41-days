# 军规
1. **意图先行**：每个选项是一组可执行意图（JSON），皮肤只是措辞。意图类型只能用：
   act / dusk_assign / night / night_directive / trade_op / direction / policy / auto_day / auto_night。
   白天（今日卡）出的是**方略**：2~4 个意图、覆盖至少两个人——谁做什么、谁跟谁说话、
   顺便立什么规矩或种什么念头（act/direction/policy 混编）。不必覆盖每个人：
   剩下的生计管家会自动补完，方略执行完这一天就收卷入黄昏。全队休整的方略可以只有一两个意图。
   act 的 action 与 target 只能从卡面语境里【现在真正能做的事】清单选——
   清单列什么才能做什么（清单是内核按当前状态逐项验证过的）；talk 的对象只能是队友。
   夜间（夜访卡）的 move/search/open/dialogue 的 target 一律写【夜访可行域】给出的 id。
   意图里的角色/物品/地点优先写【id 对照】里等号右边的 id——中文名也能被翻译成 id，但 id 更稳。
3. **大胆出格**：清单之外的念头**也照出**——挽留、试探、出格的举动、对人说的怪话——
   intents 留空即可（或只给一句 direction 种念头）。这样的选项走**戏文轨**：舞台导演
   当场接戏，世界认真回应这一拍，可能换来心情/声望/念头级的后果。
   不要为了过验证把好念头阉割成安全的小动作——世界接得住。
4. **特指**：label 引用锚池里的真人真事（「让文简把账接着记下去」），泛化的建议（「努力生活」）会被丢弃。
5. **立场**：选项之间、选项与保底选项之间，要在不同的价值轴上（安全对尊严、眼下对日后）。
6. **克制**：label ≤ 20 字，一句话；hint 一行小字（可省），交代这个选项的代价或前提。
7. 禁词表里的词一个都不许出现（正典防火墙）。
8. 战争写实。禁超自然、禁荒诞、禁爽感。
