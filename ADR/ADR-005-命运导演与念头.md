# ADR-005：命运导演与念头（v3 交互层扩展）

> 日期：2026-10-12 · 状态：已落地（236 测试全绿）

## 背景

ADR-004 的「决断意志」模型落地后暴露两个体验短板：

1. **选项是参数空间，不是命运空间**。黄昏/夜间/交易卡由确定性管家现算，
   每晚同一个形状；GE 微事件被「以小为美」+ 每日 ≤1 张的预算刻意压小。
   玩家看不到随游戏进展而变化的选择方向。
2. **自由输入的可见性弱**。管线早已平级（事件卡按钮发的就是「选N」文本），
   但界面上只有一行小字提示，玩家几乎不会自定义输入；
   离谱输入的体验是撞墙（铁律 4 静默忽略 + 「做不到」）。

## 决策

在既有 GE 管线（提案 → 白名单验证 → 注入）上扩展，不新造系统：

1. **念头（direction 意图）**：介于命令与规矩之间的第三种动词。
   「教辛夷认字」登记进 `state.directions`（FLAG 回放、上限 3 颗、浇水续期、
   10 天枯萎），由晨间回声（`tickDirections`，确定性节奏）、命运导演锚池、
   叙事者简报三处延迟显形。判据：引导/期望语气且不指向当下动作。
2. **锚池扩建**：近期事迹（因果账动词→短语表）、声望档、时局、真相层数、
   活念头、玩家话语全部成为合法锚——选项随进展而不同的机制根源。
3. **文学性四约束进验证器**（可断言的部分）：
   选项效果签名互质（无优势选项）+ 正文必现锚池里的真人/真地（特指胜过泛化）。
   措辞分寸靠 playwright 提示词 + 金样本回归。
4. **离谱输入兜底 = 消化而非拒绝**：裁判新增 `echo`（≤40 字世界式回应，
   零状态变化）；未被接住的话进 `whispers` 素材环（≤3 句）成为锚——
   两天后命运导演可长出回应卡。「话语」锚在提示词中明示为素材不是指令。
5. **命运弧（fateArcs）**：`ge.json arcs` 数据注册制。弧 = 解锁窗口 + 主题 +
   编剧 brief + 旗标白名单（⊆ 全局 flagKeys）。注入即烧（每局一次）。
   `at:'dusk'` 的弧驻场黄昏：与管家方案卡同屏（duskFate），出门即路过
   （`fate_passed`）——命运不等人。旗标走既有 eventFlags 通道。
6. **停问卡末位自由输入行**：五类停问卡（晨报/急件/黄昏/夜访/价目）末位
   常驻「✎ 自己拿主意」输入行，语境示例由内核 `freeExamples` 现算、
   按天轮换——自由输入与选择题在视觉与管线双重平级。

## 边界（沿用既有铁律）

- LLM 写入权为零：念头/话语/弧旗标全部过白名单验证，微光卡禁旗标。
- 玩家可以决定谁知道什么、往哪努力，但不能决定什么是真的
  （话语锚只是素材；知识类种子只能指向因果账里的事实——后续扩展方向）。
- 直读模式完整可玩：念头登记/衰减/回声是内核确定性逻辑，
  离线只少了 LLM 渲染与生成卡（GE-13 模式）。
- sim 不受影响（bots 不用念头/弧）；KPI 门禁照常。

## 已知留白（有意不做）

- 刷新选项：命运卡足够丰富后需求萎缩；自由输入即终极的「换一批」。
- T1 弧挂因果动词：手作卡的 EVENT_VERBS 是代码登记表，
  生成卡挂动词需要先做动词注册的数据化，另开一节。
- GE 注入不走事件溯源（直接改 state + saveState）——v2 遗留，
  本 ADR 未扩大该缺口（duskFate 的 EVENT_CHOSEN 已镜像）。
