# ADR-006：单一交互面与水下交易（v3.1）

> 日期：2026-10-12 · 状态：已落地（245 测试全绿 + sim 门禁通过）

## 背景

ADR-005 落地后，界面同时存在两处输入（底部批注条 + 停问卡内输入行）与两张
自谋类卡（黄昏方案 + 价目）。玩家要学两套交互姿势；价目卡还把交易这件
"下九流"的生计抬到了与命运岔路同级的视觉位置。

## 决策

### 1. 单一交互面：一切回应都发生在眼前的卡上

- **底部批注条退场**（含 chips 情境建议、动态 placeholder、每回合自动聚焦）。
  每张停问卡 = 选项 + 末位输入行 + 「⟳ 再想想」。
- **今日卡**（新增，白天常驻）：晨报问题 + 种下的念头 + 情境选项（原 chips
  内容降级为选项）+ 刷新 + 输入行。有急件时让位。
- **刷新命运**：`POST /api/runs/:id/options`，新提示词角色**谋士（optionsmith）**
  按锚池补 1~3 个情境选项；纯视图数据（不碰 state、不进事件流），
  点击才走既有输入管线。每卡每天至多刷两次；LLM 离线自动隐藏。
  **边界：只刷自谋类卡（今日/黄昏/夜访）。急件与命运弧不设刷新——
  世界的提问只问一次，道德困境不许重掷。**
- **选项三层结构**：内核保底（确定性方案，永远在，直读可玩）→ 谋士情境层
  （`{label, hint, intents}`，意图逐项过 `validateIntentShape` +
  `feasibleIntent` 只读可行性检查 + 禁词扫描，点不动的静默丢弃）→ 输入行。
- 谋士意图类型白名单（OPTION_INTENT_TYPES）：act / dusk_assign / night /
  trade_op / direction / policy / auto_day / auto_night——meta、whisper、
  event_choice、advance 不是玩家的"方案"。

### 2. 水下交易：价目卡退场，管家自理

- `planDay` 在商人到访日自取一笔建议成交（`tradeDeals[0]`，delegated 记账，
  回忆录分得清）；sim 的 delegate 策略同步去重（同一口径：每访一单）。
- 玩家干预通道：自由文本指令（trade_op：「用2木板换1生食」照常走裁判/直读）、
  念头（direction，经锚池被编剧/谋士消化）。
- 交易结果照常入叙事（trade_done facts）；家底行的鲁舟行踪章保留（知道，
  不操作）。晨报的商人条目改为气氛句（"鲁舟的船靠在渡口边"）。

## 平衡

sim（300 局 × 4 策略 + delegate 100 局）：门禁全过。水下交易后 delegate
中位 47 天 / 活到停火 40% / 文档中位 2——委托路径不降反升（此前口径
35 天 / 56%，D45 收束后整体带移）。

## 代价（诚实记录）

- 底栏承载的"页边批注"言语行为消失——不请自来的话现在说给今日卡听，
  语义上从"批注"变成"对今天的回应"。沉浸优先的取舍。
- UI 设计 v0.3 §6 的动态 placeholder 条目作废；等待动效（烛光）迁移到
  刷新按钮的"谋士在想…"态。
