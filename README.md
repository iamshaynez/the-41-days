# 《第 41 天》(Day Forty-One)

一个 LLM 驱动的网页文字生存冒险游戏，致敬《这是我的战争》(This War of Mine)。
**v0.2 设定：建安二十四年（219）的江陵**——关羽围樊、白衣渡江、麦城，
你以为你熟知的三个月。你操纵一队被困在城里的平民（塾师、药婆、琴师、仓吏），
白天经营避难所，夜间冒险外出；LLM 负责当裁判和叙事者，
**数值内核**负责让你饿、让你冷、让你付出代价。
*江陵不陷落，江陵只交割。*

## 快速开始（本地）

```bash
npm run dev          # 开发模式：自动迁移 + 热重启（改 packages/*.js 即重启）
# 打开 http://127.0.0.1:3000
```

打开首页是 landing：**注册一个名字**即可进入游戏（多用户：对局、档案馆、续局进度各归各的）；
游戏 SPA 在 `/app`。管理员用 `ADMIN_USERNAME` / `ADMIN_PASSWORD`（环境变量）首次登录自动创建。

热重启基于模块图监视（不监视数据库文件，写库不会误触发）；
改了 `content/` 内容包后在终端按回车输 `rs` 手动重启（内容在启动时种子化）。

零依赖、零构建：Node 内置了测试运行器、SQLite（`node:sqlite`）与 HTTP 服务。
叙事引擎由管理员配置（见下）；未配置时以直读模式兜底运行——直读是测试与降级通道，不是玩家选项。

本地配置可复制 `.env.example` 为 `.env`（端口/库路径/口令/日志级别/限流，脚本自动读取）。

## Docker 部署

```bash
cd docker
ADMIN_USERNAME=admin ADMIN_PASSWORD=你的口令 docker compose up -d --build
# 打开 http://127.0.0.1:3000  · 数据持久化在 docker/data/game.db
```

容器启动序：`npm run migrate`（显式迁移，幂等，落后即拒启）→ 服务。
`docker stop` 走 SIGTERM 优雅关停（WAL checkpoint 后退出）。

## 运维手册

### 数据库迁移

schema 由 `packages/server/migrations/NNN-名称.sql` 管理（版本 = 序号，事务内执行，失败回滚）：

```bash
npm run migrate            # 应用待迁移（幂等）
npm run migrate:status     # 预检：落后时退出码 2（可做部署 gate）
```

新增 schema 变更：在 migrations/ 落一个递增序号的 .sql → PR → `npm run migrate`。
服务入口带 schema 守卫——库落后时拒启并提示待应用文件，不会带病运行。

### 备份

```bash
npm run backup             # WAL checkpoint + VACUUM INTO 快照 → data/backups/，默认保留 10 份
# cron 示例：0 4 * * * cd /app && npm run backup
```

### 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 3000 | 端口（非法值启动即失败） |
| `DB_PATH` | data/game.db | SQLite 路径（migrate 与 server 共用） |
| `ADMIN_USERNAME` | admin | 管理员用户名（首次登录自动创建 `is_admin` 账号；注册不可占用） |
| `ADMIN_PASSWORD` | war-admin | 管理员口令（生产环境弱口令会告警；改环境变量后再登录即生效） |
| `NODE_ENV` | development | production 时日志级别默认 info |
| `LOG_LEVEL` | debug/info | JSON 结构化日志 |
| `INPUT_RATE_PER_MIN` | 120 | 对局输入与认证接口限流（次/分/IP，0=关） |
| `SESSION_TTL_HOURS` | 24 | 会话有效期 |
| `BACKUP_KEEP` | 10 | 备份保留份数 |

### 健康检查

`GET /healthz` 汇报三版本（应用 / schema / 内容包）与运行时长，可接探针。

## 配置 LLM（管理后台）

管理员账号 = 环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD`（默认 `admin` / `war-admin`），
**首次在首页用它登录即自动创建管理员记录**；改了环境变量再登录一次即同步新口令。
登录后进入「管理」页（普通玩家看不到这个入口），配置只需三步：

1. **选方案**：`DeepSeek`（OpenAI 兼容 · api.deepseek.com）或 `GLM Coding Plan（国内版）`
  （Anthropic 兼容 · open.bigmodel.cn/api/anthropic）——endpoint 已内置，无需手填。
2. **填 Key 和模型**：模型有默认值（deepseek-chat / glm-4.6），按你的套餐改即可。
3. 点 **添加并测试**：后端真实调用一次（约 20 token），显示延迟 / 回显 / 错误原文，
   历史留档。添加成功即自动接入全部用途（裁判/叙事者/演员）——**配了 LLM，开局就是 LLM 模式**，
   玩家侧没有模式选择；LLM 故障时自动降级直读模板，游戏不中断。

高级（一般用不到）：「自定义端点」接任意 OpenAI/Anthropic 兼容服务；
「按用途分配主备」可给裁判单独指定便宜快模型、给叙事者指定文笔模型。

## 玩法（v2 决断意志模型）

没有要背的指令。玩家只有两种输入：

1. **自由文本**——随口说想法。「照常过吧」把今天交给管家；「以后省着吃」立一条持久的规矩；
   「今晚阿走去医棚，带把环首刀」是一次具体安排。LLM 模式下完全自由表达；直读模式认得大白话。
2. **选择题**——世界在关键处停下来问：序章五拍、敲门事件、黄昏指派（每晚必答）、
   夜间岔路（遇到人/薪束将尽/有人警觉）、交易建议（一键成交或自己开价）。

日常生计（吃饭/做饭/治疗/建造/搜家）由内核管家按你的规矩自动执行，晨报逐条交代；
账照样记在你头上——回忆录会分清"你下的令"与"你立的规矩"。

直读语法仍完整保留（测试与高级玩家可用）：`石大吃熟食` `建造炉灶` `今晚阿走去南市带铁撬`
`用2板材换1糙米` `状态`——输入「帮助」随时查看。

## 测试与平衡

```bash
npm test              # 202 个测试：单元 / 属性(确定性·守恒·fold) / 场景(含内容布线审计·封印·任务链·结局·决断意志全流程) / LLM桩 / 平衡门禁 / HTTP e2e
npm run sim           # 平衡模拟 CLI：300 局 × 4 策略，KPI 门禁（内容包 kpis.json 定义目标带）
node packages/sim/cli.js --runs 1000 --json   # 大样本 + JSON 报告
```

机器人策略与设计意图的对照（v0.2 实测，300 局/策略，交割日固定 D45）：

| 策略 | 行为 | 中位局 | 有人活到交割日 |
|---|---|---|---|
| 均衡 | 建灶/加固/药圃汤药/夜访/交易/配给 | 43 天 | ~38% |
| 赌徒 | 每晚冲最险地点 | 19 天 | ~0% |
| 守财奴 | 从不出门 | 26 天 | ~0% |
| 恶魔 | 见人就抢 | 31 天 | ~1%（道德惩罚生效） |

改任何数值（`content/base/*.json`）后跑 `npm run sim`，KPI 越带会红灯——调平衡的工作流是数据驱动的。

## 仓库结构

```
content/base/    内容包：物品/角色/地点/事件/文档/KPI/提示词（改平衡=改 JSON，PR 评审 diff）
packages/
  core/          纯函数内核：六轴状态机/日循环/夜访/袭击/交易/事件/战争/事件溯源（零 I/O）
  llm/           Provider 抽象（openai-compat + anthropic-compat）/ 裁判 / 叙事者 / 路由降级
  server/        HTTP + SSE + SQLite 持久层 + 管理面
  web/public/    无构建 SPA（阶段版式：晨报/白天/黄昏/深夜）
  sim/           无头平衡模拟器（机器人策略 + KPI 门禁）
test/            unit / property / scenario / llm / sim / e2e
docker/          单镜像部署
docs/            设计文档（游戏的"为什么"都在这里）
```
